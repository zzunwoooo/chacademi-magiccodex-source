# 차카데미 운영자 명령어 안내 (2026-10-20 개편)

처음이면 **`/관리`** 를 치세요. 대단원 목록이 나오고, 줄을 누르면 채팅창에 명령이 들어갑니다.
대단원만 쳐도(예: `/유저관리`) 그 아래 명령 목록이 나옵니다. 명령을 치는 동안 칸마다 다음에 넣을 것이 회색으로 보입니다.

## 기본 규칙
- 관리 명령은 **OP만** 씁니다. OP가 아니면 자동완성에도 안 보입니다.
- 유저는 **한글 닉네임**으로 적습니다. 접속하지 않은 유저도 닉네임 기록이 있으면 찾습니다.
- 띄어쓰기가 있는 이름(마법·칭호·물고기 등)은 **띄어쓰기를 빼고** 적습니다. 자동완성도 그렇게 보여 줍니다.
- 되돌릴 수 없는 명령(초기화·삭제)은 **끝에 `확인`** 을 붙여야 실행됩니다.
- 실패하면 오른쪽 아래 알림 카드 + 삐빅 소리로 이유가 나옵니다. "명령어 사용에 실패했습니다"가 나오면 개발자에게 알려 주세요(원인은 서버 콘솔에 남습니다).
- 설정 파일을 고쳤으면 `/서버관리 새로고침 <분야>` (모르면 `전체`).

## /뽑기판 — 운영자 행운의 뽑기판 100칸 (2026-10-26, FINAL_PATCHES §44)

- `/뽑기판` — 10×10 판 창 열기 (칸 클릭 = 공개, 다시 클릭 = 가림. 100칸 모두 공개되면 1.5초 뒤 같은 100개를 새로 섞어 다음 회차)

- `목록` · `등록`(주 손 아이템 그대로) · `삭제 <번호>` · `비우기 확인`(등록 전부 지우기)
- 정확히 100개가 등록돼야 판이 시작됨. 등록·삭제하면 판이 새로 섞임 (100개 미만이면 창에 "등록된 아이템 N/100개")
- 아이템 지급·티켓·비용·확률 없음 (보여 주기만). 모드 필요
