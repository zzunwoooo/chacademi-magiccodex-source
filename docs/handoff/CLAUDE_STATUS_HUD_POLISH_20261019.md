# 대상 체력바 다듬기 (Claude, 2026-10-19, 미빌드)

브랜치: `claude/status-hud-polish-20261019` (기준: `codex/operating-status-hud-20261019` @ `c5a2ccf`, 배포본)

오너가 실게임을 보고 요청한 것:

- 이름이 잘 안 보임
- 체력바가 밋밋함 → 그라데이션
- 끝 칸만 핑크색인 것 → 색 통일
- 체력바가 두꺼움 → 조금 얇게
- 장식을 조금 추가
- 전체 크기 80%

바뀐 파일은 클라 모드 2개뿐입니다(`TargetHudClient`, `TargetHudLayout`). 서버·프로토콜·에셋 변경은 없습니다.

| 항목 | 변경 |
|---|---|
| 크기 | `TargetHudLayout.width` 화면 폭의 38% → 30.4% (최소 184 / 최대 400 GUI px) |
| 두께 | 프레임 블록(프레임·체력·마나)을 세로 `BAR_Y = 0.74`로 눌러서 그림. 아이콘·하트·글자 위치도 같은 비율로 맞춤 |
| 체력 색 | 모든 칸이 같은 색. 끝 칸에 덧그리던 흰 덧칠은 없앰. 칸마다 위쪽 광택(흰색 0.36→0), 아래쪽 그늘(검정 0→0.44), 윗선 2px |
| 장식 | 프레임 위아래에 금색 실선(양 끝으로 갈수록 흐려짐), 프레임 양 끝에 금색 마름모 3겹 (`HudMesh.quad`/`star`) |
| 이름 | 이름 뒤에 어두운 띠(가운데가 진하고 양옆으로 흐려짐), 폰트 `section`(마루부리 Bold), 더 밝은 색, 그림자 + 외곽선 |
