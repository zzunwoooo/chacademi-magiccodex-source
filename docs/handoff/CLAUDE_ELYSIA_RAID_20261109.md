## 1. 동작 요약

- 소환 위치 = 경기장 중심(반경 16), 바라본 방향 = 정면. 30틱 뒤 석상 4개(반경 8, 대각). 체력 6000.
- 기믹 중 보스 무적. 그로기 없음. 빨간 예고 = 모드 예고, 판정 = 예고 모양 그대로.
- 머리 위 ✦ 표시 = TextDisplay (1페이즈 금색, 2페이즈 붉은색). 빚 +1 / -1 은 VFX + 소리만 (글 없음).

### 1페이즈 엘리시아 (100 → 50%)

| id | 패턴 | 모양 | 예고 | 피해 |
|---|---|---|---|---|
| spear | 빛의 창 3자루 | 직선 18 × 1.6 (±14°) | 0.6초 | 22 |
| judgment | 낙하 ×3 (그때 위치) | 원 r 2.5 | 0.9초 (0.6초 간격) | 24 |
| sweep | 날개 베기 | 부채꼴 r 6.5 · 140° | 0.5초 | 26 |
| radiance | 광휘 | 보스 중심 원 r 5.5 | 0.8초 | 28 |

- 상시 **치유의 성역**: 14초마다 무작위 위치 반경 2, 7초. 1초마다 최대 체력 6% 회복, 3번마다 **가호 빚 +1** (말 없음).
- 상시 **성가대 아기천사**: 25초마다 2마리(최대 3). 처치 시 은총의 깃털 → 주우면 10% 회복 + 성역 1번.
- 상시 **③ 구원의 제안** (1회): 치명상 순간 피해 취소·체력 1·5초 둔화, 앞에 천사의 손. 타이틀 “아직 그대의 때가 아니다 / 손을 잡겠느냐?”.
  5초 안에 손 우클릭 = 부활 VFX → 체력 가득 + **구원 빚 3**. 안 잡으면 사망.
- **① 85% 가호의 제안**: 중앙 → 대사 → 금빛 원(반경 2.3) 하나. 3파: 경기장 가장자리 하늘에 빛, 전체 예고 2초 → 낙하.
  금빛 원 안 = 무사 + **가호 빚 +1** (파마다, 원 위치 바뀜) / 빛→나 선을 석상이 가림 = 무사 / 둘 다 아니면 사망.
- **② 70% 축복의 제안**: 중앙 → 빛의 성벽(25초) + 앞에 금빛 깃털. 깃털을 주우면 **축복 빚 +2** + 축복(1페이즈 끝까지 피해 1.5배, 성벽에는 3배, 성벽 450).
  정공법: 빛의 핵 3개(반경 10)를 4초 안에 모두 치기. 25초+3초 지나면 사망.
- **④ 55% 계시의 제안**: 석주 3개(반경 11.5, 정면 ±40°) → 찬송 3음(무작위 순서) + 끝에 낮은 메아리 소리. 보스 앞 금빛 원에 서면
  타이틀로 답 표시 + **계시 빚 +1**. 정답 = 들은 순서의 **역순**으로 석주 치기. 틀리면 그 자리 심판의 빛으로 사망, 20초 초과도 사망.

### 50% 청구서 (정체 폭로)

- 잡몹 정리 → 중앙 → `reveal` 모션 + `Elysia_Reveal` → **2.8초**에 엘리시아를 지우고 `CA_Boss_belzar` 소환 (체력 50%, 빚 그대로) → `spawn`.
- 장부 낭독 (채팅): “○○. 가호 n, 축복 n, … 합계 빚 N.” → “이제 갚을 시간이다.” 축복 오라는 여기서 끝.
- **받은 게 하나도 없으면 (청렴)**: “…계약이 성립하지 않는군.” 체력 40%로, 회수 4개 전부 생략 → 15% 계약 파기로 바로.
  서버 로그 `[엘리시아] 청렴 클리어 조건 달성 후보: <이름>` — 칭호 지급 연결은 GPT 쪽에서 (칭호 시스템).

### 2페이즈 벨자르 (50 → 15%)

| id | 패턴 | 모양 | 예고 | 피해 |
|---|---|---|---|---|
| claw | 할퀴기 (뒤에 있으면 tail) | 부채꼴 r 7 · 150° | 0.45초 | 26 |
| tail | 꼬리 휩쓸기 | 뒤쪽 부채꼴 r 6.5 · 160° | 0.5초 | 24 |
| hellfire | 지옥불 ×3 | 원 r 2.5 | 0.9초 | 26 |
| collect | 수금 | 그 자리 원 r 3 | 1초 | 빚 있음 = 최대 체력 18% + **빚 1 상환** / 없음 = 24 |

- **빚의 사슬**: 빚이 있으면 보스와 링크. 길이 = max(5, 16 − 1.5 × 빚). 넘으면 끌려옴 + 1초마다 3%.
- 잡몹 21초마다: 임프 2(최대 3, 닿으면 빚 있는 종류에 +1) + 망령 1(최대 2, 처치 시 상환 증서 → 빚 -1).
- 회수 순서 = 가호 → 축복 → 구원 → 계시. 상환(수금·증서)은 **다음에 올 회수 종류부터** 깎임. 그 종류 빚이 0이면 한 줄만 하고 생략.
- **ⓐ 45% 그림자 몰수**: 가호 빚만큼 석상 무너짐(최대 4) → 지옥불 3파, 그늘만 피할 곳(금빛 원 없음). 끝나면 가호 빚 0, 석상 복구.
- **ⓑ 38% 빌린 힘의 반환**: 보호막(축복으로 더 넣은 피해량, 300~3000). 보호막이 먼저 맞고, 빛의 핵 3개 4초 안에 = 즉시 파괴.
  남아 있는 동안 패턴 간격 0.6배. 30초 지나면 터지며 최대 체력 40% (사망 아님). 축복 빚은 시작할 때 0.
- **ⓒ 30% 목숨 회수**: 구원 빚이 있으면 심장 연출 → 체력 1 + 13초 회복 불가 → claw·hellfire·tail 연속. 버티면 구원 빚 0.
- **ⓓ 22% 눈 몰수**: 계시 빚이 있으면 어둠(Darkness) 12초 + hellfire·claw·collect 연속. 끝나면 계시 빚 0.
- **15% 계약 파기**: 중앙 → 하늘에 장부(중심 위 6). 50초 동안 경기장이 반경 16→6으로 줄고 바깥은 0.5초마다 5%.
  빚이 남아 있으면 4초마다 수금. 빚 0 → “…다 갚았다고?” → 봉인진 3개를 하나씩(반경 5) 3초 서기 → 장부 불태움(2.2초 빛) →
  엘리시아의 목소리 “…고마워요. 이제야, 돌아갈 수 있겠네요.” → 처치. 시간 초과 = 사망 (체력 16%로 되돌려 다시 시도 가능).

## 3. 확인 못 한 것 / 주의

- **컴파일·실행 확인 없음.** API 는 MordianBoss·ReaperBoss 와 같은 것 + Paper `TextDisplay`, `EntityRegainHealthEvent`, `PlayerInteract(At)EntityEvent`, `PotionEffectType.DARKNESS/SLOWNESS`.
- 50% 교체: 엘리시아 엔티티를 `remove()` (죽음 이벤트 없음) → 벨자르를 MythicMobs 로 소환해 같은 Fight 에 붙임. 보스바는 미몹별(노랑 → 빨강).
- phased VFX(성역·성벽·축복·보호막)는 begin / sustain(Fx.held·Fx.follow, 멈출 때까지) / end 를 따로 시작. PortableVFX 가 sustain 시스템 단독 재생을 받는지 확인.
- 구원 가로채기는 `EntityDamageEvent`(HIGH) 에서 최종 피해 ≥ 현재 체력일 때. 다른 플러그인이 MONITOR 전에 피해를 바꾸면 어긋날 수 있음.
- 축복 피해 배율 = 보스 피해 이벤트 `setDamage ×1.5`. 공격자를 못 찾으면 경기장에 한 명뿐일 때 그 사람으로 본다 (1인 레이드 전제).
- 석상 그늘 판정 = 빛(하늘 점)→플레이어 수평 선분과 석상 거리 1.15 이내 + 석상에서 4.5칸 이내.
- 잡몹 이로치 VFX 는 기본과 같음 (색 변형 시스템 없음).
- 모델 `_shiny` 보스는 미몹에서 안 씀.

## 4. 시험 명령

```
/테스트 보스 엘리시아 패턴 spear|judgment|sweep|radiance|sanctuary   (엘리시아 때)
/테스트 보스 엘리시아 패턴 claw|tail|hellfire|collect                 (벨자르 때)
/테스트 보스 엘리시아 기믹 1~9   (1 가호 · 2 축복 · 3 계시 · 4 폭로 · 5 그림자 몰수 · 6 빌린 힘 · 7 목숨 회수 · 8 눈 몰수 · 9 계약 파기)
/테스트 보스 엘리시아 폭로 | 빚 <가호|축복|구원|계시> <개수> | 시험 켜기|끄기 | 초기화
```
`시험 켜기` = 즉사 대신 알림 + 단서 표시. 회수 기믹을 보려면 먼저 `빚` 으로 빚을 넣고 `폭로`.
