# 원소 반응 안내 (유저용 초안)

> 초안 (2026-10-25). 아래 1~3장은 유저에게 그대로 보여 줄 수 있는 글이고, **부록은 운영자용**(코드 근거, 오너 확정표와 다른 점)입니다.
> 수치는 지금 서버 코드·설정(magic-mythic-paper `config.yml`)에 들어 있는 값입니다. 설정을 바꾸면 이 글도 같이 고쳐야 합니다.
> 어떻게 전할지(책·NPC 대사·웹 등)는 아직 정하지 않았습니다.

## 1. 원소 반응이란?

마법에는 **화염 · 물 · 바람 · 대지 · 빛 · 어둠** 여섯 원소가 있습니다.

1. 원소 마법으로 적을 맞히면, 적의 머리 위에 그 원소의 **표식**이 **3초** 동안 떠 있습니다.
2. 표식이 사라지기 전에 **다른 원소** 마법으로 같은 적을 맞히면 **원소 반응**이 터집니다. 반응 이름이 머리 위에 잠깐 뜹니다.
3. 반응이 터지면 표식은 사라집니다.

알아 두면 좋은 점

- **같은 원소**로 다시 맞히면 반응 없이 표식 시간만 3초로 새로 채워집니다.
- 반응이 터진 적은 **3초 동안** 새 표식이 생기지 않습니다. 같은 적에게 반응을 연달아 터뜨릴 수는 없어요.
- 반응은 마법이 **적에게 피해를 줬을 때만** 생깁니다. 파티원(경기 중에는 같은 팀)에게는 표식도 반응도 생기지 않습니다.
- 표식을 남기는 건 적을 직접 때리는 공격 마법뿐입니다. 이동·생활·강화 마법은 표식을 남기지 않습니다.
- 친구와 둘이 해도 됩니다. A가 남긴 표식을 B가 다른 원소로 맞혀도 반응이 터집니다.

## 2. 반응 표 (15가지)

| 조합 | 반응 | 효과 |
| --- | --- | --- |
| 화염 + 물 | **증기 폭발** | 적 주변 3칸이 터지며 작은 피해를 주고, 맞은 적들을 살짝 띄웁니다. |
| 화염 + 바람 | **불씨 확산** | 적 주변 2칸의 적들에게 **화상 3초**. |
| 화염 + 대지 | **용암 분출** | 적에게 **회복봉인 3초** (체력·마나 회복이 막힘). |
| 화염 + 빛 | **태양 플레어** | 적이 **3초 동안 빛나고**(벽 너머로도 보임), **약화 3초** (적이 주는 마법 피해 감소). |
| 화염 + 어둠 | **잿불 낙인** | 적에게 **마나번** (플레이어라면 최대 마나의 10%를 잃음). |
| 물 + 바람 | **연쇄 번개** | 적에게 **무장해제 1초**, 번개가 가까운 적에게 최대 3번 더 튀며 작은 피해 + **무장해제 1초**. |
| 물 + 대지 | **진흙** | 적에게 **둔화 3초**. |
| 물 + 빛 | **무지개** | 나와 주변 4칸 안의 **파티원 체력 회복**. (유일하게 아군을 돕는 반응) |
| 물 + 어둠 | **심연** | 적에게 **독 3초**. |
| 바람 + 대지 | **모래 회오리** | 적 주변 4칸의 적들을 한가운데로 끌어모으고, 모두 **고정 1초** (이동 마법·비행 불가). |
| 바람 + 빛 | **섬광** | 주변 6칸의 몬스터가 노리던 플레이어를 놓칩니다. *(효과 확정 전)* |
| 바람 + 어둠 | **공허 균열** | 적에게 **공포 1초** (나에게서 도망감). |
| 대지 + 빛 | **수정화** | 적에게 **기절 1초**. |
| 대지 + 어둠 | **매장** | 적에게 **속박 1초** (제자리에 묶임). |
| 빛 + 어둠 | **일식** | 적에게 **수면 1초** (피해를 받으면 바로 깸). |

## 3. 보스에게는?

- 보스는 **기절 · 수면 · 공포** 대신 **둔화**에 걸립니다.
- 보스는 **속박**에 걸리지 않습니다.
- **증기 폭발의 띄우기**, **모래 회오리의 끌어모으기**는 보스에게 통하지 않습니다 (고정은 걸림).
- 섬광으로 보스의 표적을 뺏을 수는 없습니다.

## 부록 B. 오너 확정표(2026-10-20)와 코드 비교

코드는 바꾸지 않았습니다. 확정표와 **모두 일치**하고, 아래만 확인이 필요합니다.

| 조합 | 확정표 | 코드 | 비고 |
| --- | --- | --- | --- |
| 바람 + 빛 (섬광) | 미정 | 주변 6칸 몬스터의 플레이어 표적 해제 (예전 효과 그대로) | **오너 결정 필요.** 유저 표에는 "확정 전"으로 적어 둠 |
| 물 + 빛 (무지개) | 주변 아군 회복 | 회복량 **1** (체력 반 칸) | 수치가 매우 작음 — 의도인지 확인 필요 |
| 화염 + 어둠 (잿불 낙인) | 마나번 | 플레이어만 마나 감소, 몹에게는 아이콘만 (몹 마나 보류 결정 2026-10-19) | 몹 상대로는 사실상 효과 없음 |
| 화염 + 물 (증기 폭발) | 반경 3 작은 피해 + 살짝 띄움 | 피해 = 마법 피해의 15% (최소 기준 2 → 0.3) | 일치. 수치는 임시값 |
| 물 + 바람 (연쇄 번개) | 연쇄 번개 + 맞은 적 무장해제 1초 | 첫 대상은 무장해제만(번개 피해 없음), 튄 대상 최대 3명은 피해 + 무장해제 | 일치 (첫 대상은 원래 마법 피해를 이미 받음) |
| 대지 + 빛 / 바람 + 어둠 / 빛 + 어둠 | 기절·공포·수면 1초 | 보스에게는 둔화로 바뀜 | 상태이상 엔진 공통 규칙 (2026-10-19 결정) |

그 밖에 코드에 있는 공통 규칙(확정표에는 없음): 반응이 일어난 대상 3초 면역, 파티원 제외, 보스 띄우기·끌어오기 제외, 아티팩트(반응 장인의 인장 등)가 범위·시간·튕김·회복량을 늘릴 수 있음(`Reactions.java:92-98`).
