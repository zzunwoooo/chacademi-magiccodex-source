# 하우징 특수 가구 창 디자인 요청 (GPT 용 프롬프트, 메모 #108)

참고 그림으로 정보창 v4 시안(`docs/design/profile-ui-v4/reference/approved-v4.png`)과 그 패키지 PNG(패널·슬롯·버튼)를 같이 첨부.

---

마인크래프트 마법학교 서버 "차카데미"의 하우징(내 방) 특수 가구를 눌렀을 때 뜨는 작은 창 4개를 디자인해 줘. 첨부한 정보창 v4 와 같은 톤(짙은 남색 반투명 패널, 얇은 금색 테두리·모서리 장식, 금색 제목, Pretendard 계열 한글, 구분선 #35516D, 본문 #F4F7FF, 보조 #B6D9F4, 강조 #F5D18A)으로, 정보창 패키지의 패널·슬롯·버튼 PNG 를 최대한 재사용하고 새 장식은 최소로. 뒤 화면을 어둡게 가리지 않음, 창만 반투명. 1920×1080 기준.

공통: 제목 줄(왼쪽 금색 세로 막대 + 제목, 오른쪽 닫기 X), 아래에 "○○님의 방" 작은 보조 글씨. 방문자와 주인 모두 같은 창(읽기 전용).

## 1. 빗자루 거치대 — 빗자루 카드 (약 560×360)
- 큰 빗자루 그림 칸(가로로 긴 칸, 빗자루 3D 아이콘이 들어감) · 빗자루 이름(등급색) · 등급 · 짧은 설명 2줄 · 능력치 3줄(속도·가속·조작 같은 이름: 값). 숙련도 막대 1개(진행 막대 스타일, 정보창 v4 와 같음).

## 2. 아티팩트 진열장 — 장착 아티팩트 구경 (약 820×520)
- 아티팩트 칸 최대 6개(정보창 장비 슬롯 스타일, 칸 안에 아티팩트 아이콘), 칸 아래 이름(등급색: 일반 회색·고급 파랑·유일 보라·전설 금색).
- 칸을 고르면 오른쪽(또는 아래)에 상세: 이름 · 등급 · 설명 3줄 · 효과. 빈 칸은 "비어 있음".

## 3. 큐디치 트로피장 — 전적 카드 (약 760×420)
- 정보창의 1:1 대전/큐디치 카드 두 장을 나란히 크게(티어 PNG 는 기존 9종 그대로 사용) + 아래에 승·패·무, 승률, 최근 5경기 결과 점(승 파랑·패 분홍·무 회색).

## 4. 수조 — 물고기 구경 (약 980×600)
- 물고기 칸 격자(4×3 정도, 칸 안에 물고기 아이콘), 칸 아래 이름·등급색. 위쪽에 "수조 n / 최대" 와 페이지 화살표(◀ ▶).
- 칸을 고르면 상세: 물고기 이름·등급·크기(cm)·잡은 날·잡은 곳.

## 납품물
- 각 창의 패널 PNG(9-slice, 모서리 크기 표기), 새로 필요한 칸·버튼·화살표 PNG(정보창 패키지 것을 재사용하면 생략), 투명 PNG.
- 글씨는 PNG 에 넣지 말 것. 대신 창마다 `layout.json`: 요소 [x,y,w,h], 글씨 위치·크기·색(hex), 9-slice 값.
- 창마다 조립 미리보기 1장(예시 데이터 넣어서).
