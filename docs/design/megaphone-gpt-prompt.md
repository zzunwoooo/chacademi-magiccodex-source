# 확성기 UI 디자인 요청 (GPT 용 프롬프트, 메모 #102)

아래를 그대로 GPT 에게 붙여 넣고, 참고 그림으로 지금 게임 알림 카드 `toast_background.png`, 입력창 버튼 `dialogue/choice-button.png`, 정보창 v4 시안(`docs/design/profile-ui-v4/reference/approved-v4.png`)을 같이 첨부.

---

마인크래프트 마법학교 서버 "차카데미"의 **확성기** UI 를 디자인해 줘. 기존 UI 톤(짙은 남색 반투명 패널 + 얇은 금색 테두리·모서리 장식, 한글 Pretendard 계열 글씨)에 맞추고, 새 장식은 최소로.

## 기능
- 플레이어가 확성기 아이템을 우클릭 → **입력 창**이 뜸 → 한 줄 문장을 쓰고 보내면 → 모든 서버 플레이어 화면 **위쪽 가운데**에 **공지 카드**가 몇 초(6초) 뜸.
- 보낸 사람이 다른 손에 아이템을 들고 있었으면 그 아이템 아이콘이 공지 카드와 같이 뜸. 없으면 카드만.

## 화면 1 — 입력 창
- 화면 가운데. **뒤 배경을 어둡게 가리지 않음**(게임 화면 그대로 보임). 창 자체만 반투명.
- 들어가는 것만: 제목 "확성기", 닫기 X, 한 줄 입력칸(최대 80자), "보내기" 버튼. 안내 문구·글자 수·아이템 미리보기 없음.
- 기준 크기 예시: 창 1010×210 (1920×1080 화면 기준).

## 화면 2 — 공지 카드
- 화면 위쪽 가운데, 카드 폭 약 640, 높이 약 110 (1920×1080 기준).
- 카드 안: 1줄째 **보낸 사람 닉네임만**(가운데, 강조색 금빛 또는 흰색 굵게), 2줄째 **문장**(가운데, 본문색). 카드 안쪽 아래에 남은 시간 막대(가는 금색 줄, 왼쪽→오른쪽으로 줄어듦).
- **아이템 아이콘: 카드 테두리 바깥**, 카드 윗변보다 완전히 위쪽 가운데에 따로 떠 있음 (카드에 걸치거나 겹치지 않음). 원형 받침·테두리 없이 아이템만 크게(약 80px). 은은한 빛/그림자 정도는 가능. 아이콘 옆이나 아래에 아주 작게 "Ctrl 아이템 보기".
- 아이템 없는 공지: 아이콘·안내 없이 카드만.
- 마우스를 아이템에 올리면 마인크래프트 기본 아이템 툴팁이 카드 **아래**에 뜸(툴팁은 게임이 그림, 디자인 불필요 — 자리만 고려).

## 납품물 (투명 PNG, 1920×1080 기준 원본 크기)
1. `megaphone_input_panel.png` — 입력 창 패널 (9-slice 가능하게, 모서리 크기 알려 줘)
2. `megaphone_input_field.png` — 입력칸
3. `megaphone_send_button.png` / `megaphone_send_button_hover.png`
4. `megaphone_close.png` (24×24 정도)
5. `megaphone_notice_card.png` — 공지 카드 (9-slice, 모서리 크기)
6. `megaphone_notice_timer.png` — 남은 시간 줄 (또는 색 코드만)
7. (선택) `megaphone_item_glow.png` — 아이템 뒤 은은한 빛
8. 글씨는 PNG 에 넣지 말 것 (게임이 그림). 대신 `layout.json`: 각 요소 [x,y,w,h], 글씨 위치·크기·색(hex), 9-slice 값.
9. 조립 미리보기 3장: 입력 창 / 공지(아이템 있음) / 공지(아이템 없음) — 게임 화면 위에 올린 모습.
