차카데미 운영자 전용 100칸 뽑기판을 구현해줘.

운영자 전용 명령어로 여는 창이야. 명령어 이름은 기존 프로젝트 규칙에 맞춰 정하고 일반 유저는 사용할 수 없게 해줘.

아이템 100개를 미리 등록해두고, 그 100개를 무작위로 섞어서 10×10 칸에 하나씩 배치해줘. 처음에는 아이템이 보이지 않는 뒷면 상태로 시작해.

칸을 클릭하면 짧게 뒤집히면서 해당 칸의 아이템이 보이고, 다시 클릭하면 원래 뒷면으로 돌아가면 돼. 같은 라운드에서 뒤집었다가 다시 가려도 그 칸의 아이템은 바뀌면 안 돼.

100칸이 모두 공개된 상태가 되면 전체를 다시 가리고, 같은 등록 아이템 100개를 새로 섞어서 위치를 바꾼 뒤 다음 판으로 초기화해줘. 단순 누적 클릭 횟수로 초기화하지 말고 현재 공개된 칸 100개를 기준으로 판단해줘.

UI는 첨부 PNG와 레퍼런스의 차카데미 남색·금색 스타일을 사용해줘. 가장 중요한 조건은 모든 칸의 가로와 세로 길이가 정확히 같은 정사각형이라는 거야. 10열×10행을 한 화면에 보여주고 화면 크기나 GUI 배율이 바뀌어도 칸을 가로·세로 따로 늘리지 마. 공간이 부족하면 전체를 같은 비율로 축소해줘.

연출은 짧은 뒤집기와 약한 반짝임 정도면 충분해. 오른쪽 상태 설명 예시는 레퍼런스 설명용이라 실제 창에는 넣지 마. 제목·안내 문구·닫기 버튼은 기존 UI 방식으로 렌더링하고, 공개된 아이템은 실제 등록한 아이템을 렌더링해줘.

아이템 지급, 티켓 소모, 비용, 등급별 확률 등 별도 시스템은 추가하지 마. 아이템 설정, 랜덤 배치, 클릭 공개·숨김, 전체 공개 후 재배치 기능만 구현하면 돼.

전체 공개 후 잠깐 유지하는 시간은 마지막 아이템을 볼 수 있도록 둘 수 있지만 별도 확정 요구사항은 아니야. 기존 구현에 맞춰 최소한으로 처리해줘.
