차카데미 100칸 뽑기판 PNG 패키지

png/: 투명 배경 RGBA PNG 5종. 각 캔버스 1254×1254.
- panel.png: 메인 배경 패널
- tile_hidden.png: 숨김 칸
- tile_hover.png: 마우스 오버 예시 칸
- tile_revealed.png: 공개 아이템용 빈 칸
- reveal_fx.png: 짧은 반짝임 오버레이

docs/CLAUDE_PROMPT_KO.txt: 최신 운영자 전용 동작 요구사항
reference/style_reference.png: 승인 스타일 참고. 그림의 눌린 칸 비율은 사용하지 않는다.

정사각형 적용 필수:
PNG 캔버스는 정사각형이지만 생성 그림의 투명 여백과 테두리 위치는 상태별로 다르다. 그대로 전체 이미지를 교체하면 테두리가 움직일 수 있으므로 docs/SPRITE_LAYOUT.json의 테두리 UV 영역을 동일한 정사각형 목적지에 매핑한다. 숨김/공개/호버의 목적지 좌표와 크기는 완전히 동일해야 한다.
호버는 기본 숨김 칸에 밝기 또는 FX만 겹치는 방식을 권장한다. 별도 hover PNG는 대안이다.
아이템 그림, 제목, 설명, 닫기 버튼은 이미지에 굽지 않고 기존 게임 렌더러로 표시한다.
PNG는 바깥 투명 배경을 포함하며 내부 남색의 알파는 균일하지 않다. 패널은 필요 시 렌더링 opacity로 조절한다.

그리드 예: tileSize=64, gap=6, gridSize=694. 100칸 모두 같은 tileSize를 사용한다. 이 값은 배치 예이며 화면에 맞춰 균일 확대·축소 가능.

이 패키지는 이미지와 개발 프롬프트만 포함한다. 코드 구현, 서버 적용, 실제 게임 검증은 하지 않았다.
