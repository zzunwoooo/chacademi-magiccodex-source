차카데미 확성기 UI · 홀로그램 / 바람의 전언

1. 적용 범위
승인된 reference-v2의 색감·반투명 유리·절제된 바람선과 금색 모서리를 실제 UI 규격으로 재구성한 PNG 패키지입니다. 원본 픽셀을 그대로 추출한 결과가 아니라, 구현에 적합하도록 결정론적 벡터를 다시 렌더링한 시각적 재구성입니다. 실제 서버에 배포하거나 아이템을 변경한 패키지가 아닙니다.

2. 파일 역할
assets/: 글자가 없는 투명 PNG UI 자산.
SVG 소스: 자산의 수정·재렌더링용 벡터 원본.
layout.json: 기준 좌표, 크기, 텍스트 영역, 색상과 9-slice 설정의 기준.
reference/: 승인된 v2 레퍼런스.
previews/: 실제 PNG를 조립한 1920×1080 입력 / 아이템 있음 / 아이템 없음 미리보기.
QA 이미지 및 manifest: 밝고 어두운 배경에서의 반투명 확인, 크기·알파·SHA 검증 자료.
docs/: 이 안내와 한국어 개발 프롬프트. 이미지 생성·수정 프롬프트도 패키지에 포함됩니다.

3. 렌더링 주의
PNG는 RGBA straight alpha입니다. 패널 내부까지 반투명하므로 검정·남색 배경을 별도로 깔지 말고 이미지의 알파를 그대로 적용하세요. 엔진이 premultiplied alpha를 요구하면 업로드 과정에서 한 번만 변환하세요. 알파를 다시 곱하거나 불투명 RGB로 변환하면 테두리가 어두워지고 유리 느낌이 사라집니다. 전체 화면 암막이나 전체 화면 블러를 추가하지 마세요.
기준 캔버스는 1920×1080입니다. 화면 크기가 달라지면 UI 전체를 동일 비율로 조정하고 앵커를 유지하세요. 9-slice의 고정 코너는 입력 패널/공지 카드 16px, 입력 필드/전송 버튼/아이템 배경 12px입니다. 가는 바람선은 장식이며 가독성을 해치도록 강화하지 마세요.

4. 런타임 텍스트
제작 PNG에는 제목·닉네임·메시지·버튼 글자·힌트가 없습니다. Pretendard 계열 폰트로 게임에서 별도 출력하세요. 미리보기 문구는 동작 예시입니다. 입력은 한 줄, 최대 80 Unicode code point입니다. 한글 IME 조합 중에는 강제 잘라내지 말고 조합 확정 후 검증하세요. 줄바꿈은 허용하지 않습니다. 글자 수 표시·도움말·입력창 아이템 미리보기는 추가하지 마세요.

5. 배치와 상태
입력 패널: (455,435), 1010×210. 제목 (487,456), 닫기 (1409,456), 24×24. 필드 (487,516), 786×72. 보내기 버튼 (1289,516), 144×72.
공지 카드: (640,160), 640×110. 닉네임 중심 x=960 / y=177, 26px bold. 메시지 중심 x=960 / y=215, 24px. 텍스트 y는 상단 기준입니다.
타이머: (664,257), 592×3. 표시 시작부터 6초 동안 경과 시간 기준으로 폭을 줄입니다.
아이템 배경: (912,48), 96×96. 실제 아이콘: (920,56), 80×80. 배경 하단 144와 카드 상단 160 사이에 16px 간격이 있습니다. 아이콘과 배경은 카드에 겹치지 않습니다.
힌트: (1024,90), “Ctrl 아이템 보기”. 아이템이 없는 상태에서는 아이콘·배경·힌트를 모두 숨기고 카드 위치는 그대로 유지합니다.
툴팁: 기본 상태에서는 보이지 않습니다. 게임에서 조건이 충족됐을 때 카드 아래 y=282부터 표시하며 화면 밖으로 나가지 않도록 제한합니다. 툴팁 콘텐츠는 서버 아이템 데이터로 생성합니다.

6. 최종 통합 확인
레이아웃과 PNG 알파를 유지한 채 밝은 낮 배경과 어두운 밤 배경에서 확인하세요. 80자 메시지는 한 줄을 유지하되 공지 영역에 맞추어 축소하거나 말줄임 처리하세요. 데이터 원문은 손상시키지 마세요. 전송 유효성·쿨다운·권한 검사는 서버가 최종 책임집니다.
