차카데미 마인크래프트 마법학교 서버의 확성기 UI를 이 패키지 기준으로 구현해 주세요.

[디자인과 자산]
승인된 reference-v2의 홀로그램 같은 남색/청록 반투명 유리, 얇은 연금색 모서리, 절제된 바람의 흐름을 유지합니다. 제공 PNG의 반투명 내부 알파를 그대로 렌더링합니다. 장식을 추가하거나 전체 화면을 어둡게 하지 않습니다. 배경 전체 블러도 금지합니다. PNG는 텍스트 없는 자산이며 모든 텍스트는 Pretendard 계열로 런타임 출력합니다. 제공 SVG는 편집용 원본입니다. 본 자산은 승인 레퍼런스를 실제 규격에 맞게 결정론적으로 벡터 재구성한 것이며 픽셀 동일 추출물은 아닙니다.

[좌표]
기준 해상도 1920×1080, 좌상단 원점, 단위 px. layout.json을 구현의 기준으로 사용합니다.
입력 패널 x455 y435 w1010 h210. 제목 “확성기” x487 y456. 닫기 아이콘 x1409 y456 w24 h24.
입력 필드 x487 y516 w786 h72, 보내기 버튼 x1289 y516 w144 h72. 버튼 글자는 “보내기”.
공지 카드 x640 y160 w640 h110. 닉네임 x960 중심 정렬 y177, 26px bold. 메시지 x960 중심 정렬 y215, 24px. y는 텍스트 영역 상단 기준.
6초 타이머 x664 y257 w592 h3, 카드 내부 하단. 금색 가는 막대이며 숫자나 글자는 없습니다.
아이템 배경 x912 y48 w96 h96, 아이콘 x920 y56 w80 h80. 검정 계열 반투명 배경으로 대비를 확보합니다. 배경 전체가 카드 위로 분리되고 카드와 16px 틈을 유지합니다.
작은 “Ctrl 아이템 보기” 힌트는 x1024 y90에 놓습니다. 툴팁은 카드 아래 y282부터 게임 네이티브로 렌더링하고 화면 경계 안으로 보정합니다. 기본 프리뷰 상태에서는 툴팁을 열지 않습니다.

[9-slice]
입력 패널과 공지 카드는 상하좌우 16px 코너를 고정합니다. 입력 필드·전송 버튼·아이템 배경은 12px 코너를 고정합니다. 닫기 아이콘은 고정 24×24입니다. 타이머는 경과 시간에 따라 표시 폭을 직접 갱신하거나 마스킹합니다. UI 전체의 화면 배율을 적용할 때 코너와 글자도 같은 배율을 사용합니다.

[입력 상태]
열기 → 편집 → 전송 또는 닫기의 상태를 구성합니다. UI 요소는 제목, 닫기, 단일 입력 필드, 보내기 버튼만 허용합니다. 글자 수, 안내문, 아이템 미리보기, 두 번째 입력란을 만들지 않습니다.
입력 최대 80 Unicode code point, 한 줄만 허용합니다. 붙여넣기·줄바꿈·IME 조합을 처리하고, 조합 완료 후 길이를 검증합니다. 빈 값이나 공백만 있는 메시지는 서버로 전송하지 않습니다. 서버 측 최종 길이·권한·쿨다운 검증을 수행합니다. 보내기는 normal / hover 이미지 상태를 사용하고 이벤트 중복 전송을 막습니다.

[공지 상태]
닉네임은 굵게 첫 줄 중앙, 메시지는 둘째 줄 중앙입니다. 예시 닉네임 “준우”, 예시 메시지 “오늘 저녁 광장에서 만나요!”를 하드코딩하지 말고 실제 전송 데이터를 사용합니다.
표시 시작 시각 t0를 저장하고 매 프레임 remaining = clamp(1 - (now-t0)/6초, 0, 1)로 타이머 표시 폭을 계산합니다. 프레임 수를 세는 방식은 쓰지 않습니다. 6초가 지나면 카드·아이템·힌트·툴팁을 함께 숨깁니다.
아이템 있음: 검정 반투명 배경 + 80px 실제 아이템 아이콘 + 작은 Ctrl 힌트를 카드 위에 표시합니다. 아이템 이름이나 툴팁은 PNG에 굽지 않습니다. Ctrl 아이템 보기의 활성 조건과 입력 처리는 기존 클라이언트 조작 체계에 연결합니다.
아이템 없음: 아이콘·아이템 배경·힌트를 완전히 제거합니다. 빈 자리 표시나 유령 프레임을 만들지 않으며 공지 카드 좌표는 바꾸지 않습니다.
메시지는 한 줄만 사용합니다. 최대 80자를 수용하기 위해 공지 텍스트 영역 안에서 글자 크기를 줄이되 가독성 하한을 정하고, 그래도 넘치면 말줄임 처리합니다. 서버 원문은 보존합니다. 툴팁의 표시 조건이 충족되기 전에는 별도 툴팁 창을 만들지 않습니다.

[검수]
반투명 내부가 밝고 어두운 배경에 자연스럽게 합성되는지, 폰트와 얇은 테두리가 흐려지지 않는지, 전체 화면 암막이 없는지 확인합니다. 게임 화면에서 입력 / 아이템 공지 / 일반 공지 3상태를 각각 확인합니다. UI 배율 변경, 긴 닉네임, 80자 메시지, 한글 IME, 화면 가장자리 툴팁, 연속 전송을 검수하세요. 제공 프리뷰는 실제 PNG 조립 검수용이고 서버 적용 완료의 증거는 아닙니다.
