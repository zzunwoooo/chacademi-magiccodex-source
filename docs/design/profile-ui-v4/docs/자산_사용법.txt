자산 사용 규칙

경지 9개
assets/tiers/tier-mapping.json의 tier 0~8과 한글 이름을 그대로 사용합니다. 모든 파일과 매핑은 제공 원본을 변경 없이 복사했습니다. UI의 1:1 대전과 큐디치는 이 9종 PNG를 공유하되 각 플레이어 모드의 실제 tier 값을 따릅니다. ‘미집계’는 랭킹 상태이며 새 경지 PNG로 발명하지 않습니다.

능력치 6개
intelligence: 지능 / max-health: 최대 체력 / mana: 현재·최대 마나 / mana-regen: 마나 회복 / magic-haste: 마법 가속 / defense: 방어력.

동작 및 프로필 8개
class-attainment: 클래스 도달 단계. 졸업 모자 아님.
house-school: 기숙사 행의 공통 상징. 특정 기숙사 문장을 대신하는 자산이 아님.
popularity: 인기도 별.
housing-like: 하우징 좋아요 하트. 방 방문 버튼과 분리.
friend-add: 타인 정보의 친구 추가.
friend-list: 본인 정보의 친구 목록.
vote-up / vote-down: 인기도 증감. 실제 백엔드 연결 전에는 비활성.

패널 6개
01_main_window: 메인 창 배경과 테두리.
02_section_panel: 랭크 등 섹션 공용 카드.
03_equipment_slot: 아이템 슬롯 공용 배경. 정확히 9회 사용.
04_button_normal: 기본 동작 버튼 배경.
05 계열: 강조/호버 버튼. 정확한 파일명은 manifest.json을 따름.
06_quest_row: 추적 퀘스트 행 배경.

PNG는 글자·수치·초상·아이템을 포함하지 않습니다. 모든 데이터/라벨은 위에 따로 렌더링합니다. 원본 PNG에 투명 외곽이 있으므로 논리 배치 사각형과 파일 전체 크기는 다를 수 있습니다. manifest.json의 visibleBounds는 알파 > 0의 범위로, 안티앨리어싱 가장자리도 포함합니다. 내부 테두리와 의미 있는 아이콘 실루엣을 기준으로 여백을 보정합니다. 좌표를 맞추기 위해 기존 PNG 파일을 덮어쓰지 않습니다.

조립 미리보기에는 현재 타인 상태만 표시합니다. 본인 상태에서는 친구 목록 PNG 및 ‘내 방 가기’/‘친구 목록’ 문구로 전환합니다. 별도 전체 자산 목록 PNG에서는 본인 전용 아이콘과 호버 패널도 확인할 수 있습니다.

제작 방식: UI 패널/아이콘 20개는 깔끔한 코드 기반 SVG 도형으로 새로 제작하고 PNG로 렌더링했습니다. 생성형 이미지의 얼룩/노이즈를 지우는 후처리가 아닙니다. vector-sources에 확장 가능한 SVG 원본이 있으며, 실제 경지 9개는 제공 PNG 원본 그대로입니다.
