# 운명의 타로 — 제작 자산

승인된 전체 레퍼런스에서 분리 제작한 UI 자산 묶음입니다. 게임에 연결하는 작업은 별도로 필요합니다.

## 폴더
- `illustrations-01-10`, `illustrations-11-20`: 외형 랜덤 일러스트 20종
- `cards`: 공통 뒷면, 등급별 완성형 앞면 3종, 합성용 빈 프레임 3종
- `ui-parts`: 반투명 패널·힌트 바탕·등급별 별·버튼 기본/호버·제목 장식
- `reference`: 승인된 전체 레퍼런스 (레이아웃/색감 기준)
- `docs/DEVELOPER_PROMPT_KO.md`: 복사해서 개발자에게 전달할 구현 명세
- `manifest.json`: 개별 PNG 크기, 알파, 해시
- `docs/QA_KO.md`: 실제 파일 검수 결과
- `preview.html`: 실제 PNG를 조립한 오프라인 미리보기. 브라우저에서 열어 확인하세요.

## 사용 주의
그림 20종은 주문 힌트와 독립적인 외형입니다. 카드 속 그림과 힌트 의미가 반드시 맞아야 하는 구조가 아닙니다. 3성 확률만 10%로 확정되어 있으며 1·2성 비율은 미정입니다.

빈 프레임은 그림 위에 합성하는 용도입니다. 완성형 앞면과 혼동하지 마세요. 한글 제목·안내·힌트·확인 라벨은 런타임 글자이며, 버튼 이미지가 비어 있는 것은 정상입니다. 광선·금가루·페이드·뒤집기 애니메이션도 런타임으로 구현합니다.

원본 생성 파일은 수정하지 않았습니다. PNG 제작 에셋 수는 35개이며, 승인 레퍼런스와 검수용 조립 미리보기는 별도 참고물입니다. 정확한 최종 수량과 제한 사항은 검수 문서를 확인하세요.
