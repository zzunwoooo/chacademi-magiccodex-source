# 운명의 타로 — 개발 구현 프롬프트

이 패키지의 PNG와 `reference/approved-reference.png`를 사용하여 승인된 타로 UI를 구현해 주세요. 본 파일은 구현 명세이며 실제 게임에 배포되었다는 뜻이 아닙니다.

## 승인된 방향
- 16:9 화면 기준 메인 모달은 화면 가로 약 70% 크기로 중앙 배치합니다. 작은 화면에서는 안전 여백을 두고 축소합니다.
- 남청색·금색 판타지 타로 분위기를 유지합니다. 메인 패널 및 힌트 배경의 알파를 살려 게임 장면이 비치게 합니다. 투명도를 없애는 불투명 사각 배경을 추가하지 마세요.
- 카드 일러스트는 20종의 외형 랜덤 요소입니다. 선택되는 주문/힌트와 의미상 연결하거나, 일러스트로 주문을 확정하지 마세요.
- 한글 제목, 안내, 힌트, 별 개수, 버튼 라벨은 코드로 렌더링합니다. 무문자 버튼 PNG 위에 `확인`을 표시하는 것이 의도입니다.

## 상태 흐름
1. 선택: 동일한 뒷면 카드 3장을 부채꼴로 펼칩니다. 중앙 카드를 기준으로 좌우에 약한 회전을 주고, 카드끼리 적당히 겹칩니다. 제목은 `운명의 타로`, 안내는 `카드 한 장을 고르세요.`입니다. 마우스 호버/키보드 포커스 시 해당 카드를 약간 들어 올리고 금색 경계 강조를 적용합니다.
2. 공개: 한 장 선택 시 입력을 잠그고 선택한 카드를 중앙으로 옮깁니다. 나머지 두 카드는 코드로 페이드아웃합니다. 선택 카드는 중심축 기준 뒤집기로 앞면을 공개합니다. 90° 시점에 뒷면과 앞면 레이어를 전환하고 거울상 텍스처가 나타나지 않도록 합니다.
3. 결과: 중앙 카드 위에 등급에 맞는 별 1/2/3개를 표시합니다. 아래에는 힌트를 읽기 편하게 2~3줄로 자동 줄바꿈하고 `확인` 버튼을 둡니다. 확인 후 모달을 닫고, 기존 게임의 보상/주문 처리 계약에 연결합니다. 서버 권한이나 저장 규칙을 임의로 새로 만들지 마세요.

## 등급과 힌트
- 3성 확률은 **10%**입니다. 1성과 2성의 개별 확률은 **아직 미정**입니다. 임의의 45%/45% 등으로 확정하지 말고 설정값과 검증 항목으로 남기세요. 세 등급 확률의 총합이 100%가 되도록 검증하고, 1/2성 배분이 정해지기 전에는 운영용 추첨을 활성화하지 마세요. 미리보기에서는 등급을 직접 선택해 테스트할 수 있습니다.
- 1성: `어딘가 밤하늘과 관련된 마법이 잠들어 있다고 한다…`
- 2성: `보름달이 뜬 밤, 물가에서 무언가를 해 보면 좋을지도.`
- 3성: `보름달이 뜬 밤 호숫가에서 물에 비친 달을 바라보면 「달빛 화살」을 배울 수 있다.`
- 등급 추첨과 20종 일러스트 외형 추첨은 별도의 값/함수로 관리합니다. 일러스트의 확률 분포 역시 운영 설정이며, 힌트 내용과 결합하지 않습니다.

## 레이어와 리소스
- 최종 PNG 경로/해상도/알파는 `manifest.json`을 기준으로 합니다. `cards`의 빈 프레임 오버레이 3종은 가운데가 실제 투명한 합성용 테두리입니다. 선택 일러스트를 먼저 그린 뒤 등급 프레임을 그리세요.
- 카드 그림과 프레임의 비율이 다르면 프레임의 내부 안전 영역을 기준으로 `cover`/클리핑합니다. 이미지 자체를 억지로 늘리거나 금색 장식을 잘라내지 마세요.
- 완성형 카드 앞면과 빈 오버레이를 동시에 겹쳐 이중 테두리를 만들지 마세요. 랜덤 일러스트 조합에는 빈 오버레이를 사용합니다.
- 별은 등급별 단일 아이콘을 반복해 1/2/3개 표시합니다. 제목 장식과 텍스트는 별도 레이어입니다.
- 광선, 금가루, 트윙클, 플립, 페이드 등 움직임은 코드/엔진에서만 생성합니다. PNG에 애니메이션 장면이나 사각 광원 배경을 새로 굽지 마세요. 런타임 효과는 선택 사항이며 줄인 동작 설정에서는 생략합니다.

## 구현 품질
- 모든 PNG는 원본 알파를 유지해 로드하고 가장자리 검은 테두리/흰 헤일로가 없도록 엔진의 straight/premultiplied alpha 설정을 확인합니다.
- 입력 중복 방지, 비동기 이미지 로드 실패 대체 안내, 한글 폰트 폴백, 키보드 포커스/Enter/Space, 결과 확인 버튼 접근성을 적용합니다.
- 텍스트 줄바꿈은 글리프 폭 기준으로 처리하고 2~3줄이 넘을 경우 패널 높이를 확보합니다. 지나치게 작은 폰트로 숨기지 마세요.
- 배경은 게임 장면입니다. 패키지 조립 미리보기의 단색/색상 면은 투명도 확인용일 뿐 신규 게임 배경 자산이 아닙니다.

## 검수 체크리스트
- [ ] 선택 화면은 동일한 뒷면 3장이고 호버/포커스 카드만 올라온다.
- [ ] 클릭 1회에 공개 1회만 발생하고, 플립 시 나머지는 페이드된다.
- [ ] 등급 프레임/별 색과 별 개수가 일치한다.
- [ ] 3성 10%, 1/2성 미정 상태가 운영 설정에 명시된다.
- [ ] 힌트 세 문장을 정확히 표시하며 외형 일러스트와 독립적이다.
- [ ] 모달과 힌트 바탕 뒤의 실제 게임 화면이 비친다.
- [ ] 버튼 위에 코드로 `확인`을 표시한다.
- [ ] 이미지에 체커보드나 불필요한 텍스트/효과가 굽혀 있지 않다.
