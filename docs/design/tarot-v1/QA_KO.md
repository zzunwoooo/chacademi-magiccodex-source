# 제작 자산 검수 결과

## 수량 및 파일 검증
- 제작 PNG **35개**: 일러스트20 + 카드7 + UI8. 승인 레퍼런스와 조립 미리보기는 별도 참고 PNG입니다.
- 35개 전부 디코딩 성공. 치수, 색상모드, alpha 통계, SHA-256 해시를 manifest.json에 기록했습니다.
- 일러스트20개: 1024×1536 RGB 불투명. 카드 속 그림이므로 의도된 결과입니다.
- 카드7개: 1024×1536 RGBA. 빈 프레임3개는 중앙 영역 alpha 중앙값0, 실제 투명합니다.

## 반투명 검사
- `ui-parts/hint-panel-v3.png`: 2172×724, 중앙1/3 영역 alpha 최소193/중앙값213.0/최대249 (0=투명,255=불투명).
- `ui-parts/main-panel-v2.png`: 1585×992, 중앙1/3 영역 alpha 최소155/중앙값166.0/최대177 (0=투명,255=불투명).
- 메인 패널은 뚜렷한 반투명 유리 바탕입니다. 힌트 바탕은 가독성을 위해 더 진한 실제 반투명입니다. 게임에서 더 비치게 하려면 힌트 배경 레이어에만 opacity 약0.8을 적용하고 텍스트는100%로 유지하세요.
- 어두운 청록색과 밝은 베이지색 바탕 위 실제 원본을 합성하여 알파가 작동함을 확인했습니다. 체커보드 그림을 투명도 대신 사용하지 않았습니다.

## 시각 확인
- 제작 담당자가 각 일러스트의 주제와 무문자/무프레임 상태를 검수했고, 패키징 단계에서도 전체 조립 시트를 눈으로 확인했습니다.
- 빈 프레임3종에 실제 일러스트를 넣은 조립 예시를 확인했습니다.
- 버튼은 무문자가 정상이며, 미리보기의 확인 글자는 별도 텍스트 레이어입니다.
- 제목 장식을 제목과 분리했고, 확인 버튼을 모달 안으로 넣고, 힌트를 충분한 높이의 바탕 안에 배치했습니다.
- hover 최종본은 normal에서 편집한 같은 형상 버전입니다.

## 제한 및 개발 시 확인
- 생성형 그림 특성상 카드별 내부 여백과 장식 실루엣이 완전히 같지는 않습니다. 실제 엔진에서 프레임별 내부 안전영역을 정해 클리핑/정렬하세요.
- 일러스트는 승인 레퍼런스의 작은 예시보다 세밀한 회화 스타일입니다. 실제 납품 외형은 조립 미리보기와 개별 PNG를 기준으로 확인하세요.
- 광선/금가루/플립/페이드 애니메이션을 별도 PNG에 굽지 않았습니다. 일러스트 자체의 별빛·물결·빛 표현은 정적 그림 내용입니다.
- HTML은 오프라인 검수 시트입니다. 게임 UI 동작, 보상 저장, 운영 확률은 구현·검증하지 않았으며 배포 완료를 의미하지 않습니다.
- 3성10%만 확정, 1성/2성 개별 확률은 미정입니다.
- 원본 생성물은 변경하지 않고 최종 채택본만 복사했습니다. 구버전·중복 대형 원본·개별 생성 프롬프트는 최종 ZIP에서 제외했습니다.
