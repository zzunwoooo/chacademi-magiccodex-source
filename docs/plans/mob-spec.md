# 차카데미 몹 스펙 (메모 #109, 2026-10-26)

오너: "몹 이름·체력·공격력 검수 전에 전투 스펙부터" → 전투 스펙(§34)이 정해졌으니 그 플레이어 기준으로 야생 몹 수치를 맞춤. 오너가 수치는 Claude 에게 맡김.
- 규칙·적용: `tools/mob_spec.py` (표준 라이브러리만). 원래 값: `docs/plans/mob-spec/baseline.json`.
- 계산: `python3 docs/plans/mob-spec/model.py` (플레이어 = `docs/plans/combat-spec/model.py` 그대로), 바꾸기 전: `model.py current`.

## 2. 등급 규칙
| 등급 | 몹 수 (변색종 따로) | 체력 전 → 후 | 근접 전 → 후 | 몹 스킬 피해 |
|---|---|---|---|---|
| 1성 | 33 | 20 → **40** | 0 → 0 (공격 안 함) | 원래 × **1.0** |
| 2성 | 45 | 55 → **60** | 5 → **3** (원래 0 인 11마리는 0) | 원래 × **1.1** |
| 3성 | 59 | 195 → **380** | 12.15 → **8** (냥이 타락체는 0) | 원래 × **1.8** |
| 보스 (얼음핵 glacialcore) | 1 | 1050 → **2000** | 18.9 → **24** | 원래 × **3.5** |
| 소환수 CHA_MINION_* | 2 | 14·16 → **30** | 3 → **4** | — |

- 등급 = `creature-spawns-paper` `habitats.yml` 의 rarity. 변색종도 같은 수치.
- 몹 스킬 = `chacademi_mob_skills.yml` 의 `flat=` (chatelegraph·chamobshot). 원래 값 × 배율, 소수 첫째 자리 → 스킬끼리 세기 차이는 그대로. 393줄.
- 펫 스킬(`chacademi_pet_skills.yml`)은 그대로: `pet_companions.py` 가 원래 값(baseline)으로 계산.
- 근접(미몹 `Damage`)은 바닐라 방어구·보호 인첸트 그대로 → 좋은 갑옷이면 근접은 거의 안 아픔(2성 근접 3 → 적당 0.4).
- **몹 스킬은 이번부터 마법 방어** (§34 와 같은 min(45%, (방어력+보호 레벨)×1.25%)). 전에는 바닐라 방어라 다이아+보호면 80% 넘게 막혀 몹 스킬이 거의 0 이었음. `ChAcademiaMagicMythic/config.yml` `pvp.mob-magic-armor: true` (끄면 예전). 몹 스킬엔 PvP 배율·무적 시간 초기화 없음.
- 플레이어 → 몹 피해는 그대로 (combat-spec 결정).

### 1차 → 2차 조정 (같은 날)
처음 값(2성 80 · 근접 5 · ×1.3 / 3성 450 · 근접 14 · ×2.5)은 버팀 시간에 근접을 빼고 계산했음. 근접까지 넣으니
- 대충 vs 2성: 처치 24초 > 피하며 버팀 18초 → 초보가 2성을 못 잡음.
- 적당 vs 3성: 처치 29초 > 피하며 버팀 20초 → 피해도 짐.

→ 2성 60 · 근접 3 · ×1.1, 3성 380 · 근접 8 · ×1.8 로 낮춤. 보스는 그대로.

## 3. 계산 가정
- 플레이어 세 수준 = combat-spec 그대로: 대충 지능 25 · 체력 25 · 마법 방어 18.8% (수습 마법봉, 철 세트) / 적당 109 · 39 · 37.5% / 한계 143 · 49 · 45%.
- 몹 상대 피해 = 마법 base + ratio × 지능 (등급 평균, 지금 값). 손에 초급 3 · 중급 2 · 고급 1, 쿨타임·마나 지키며 센 것부터. 시전 간격 1초, 명중 70%. 고급은 몹 남은 체력이 그 한 방 4배 이상일 때만.
- 몹: 기본기 약 4초마다(평균), 큰 기술 약 20초마다, 근접 붙으면 1초마다.
- 피하며 = 기본기 70% · 큰 기술(빨간 예고) 40% · 근접 붙잡힘 25% 맞음. 서서 = 전부 맞음.
- 몹 1마리. 물약·회복·펫·원소 반응·몹 비전투 회복(10초 뒤 2초마다 5%)은 뺌.

## 6. 배포
- MythicMobs (학교·야생 같은 파일, 몹은 야생):
  - `deployment/operating-config/MythicMobs/Skills/chacademi_mob_skills.yml` → `plugins/MythicMobs/Skills/` 교체 (overlay 새로 추가).
  - `deployment/operating-config/MythicMobs/Mobs/chacademi_mob_minions.yml` → `plugins/MythicMobs/Mobs/` 교체.
  - 야생 몹 `plugins/MythicMobs/Mobs/chacademia_custom_wild.yml` 은 **통째로 바꾸지 말 것** (운영본에만 몹 스킬 연결 Skills 줄이 있음): 서버 파일에 `python3 tools/mob_spec.py apply-mobs <서버 파일>` → Health·Damage 줄만 바뀜. 저장소 사본 `reference/output/wildlife-ground-v3/chacademia_custom_wild.yml` 은 같은 규칙 적용됨.
  - `/mm reload`. 이미 살아 있는 몹은 예전 체력 → 다시 스폰되면 새 값.
- `ChAcademiaMagicMythic/config.yml` `pvp:` 에 `mob-magic-armor: true` (없어도 코드 기본값 true).
- jar: ChAcademiaMagicMythic (MagicArmor·MagicProtection 바뀜).
- 숫자 바꾸는 법: `tools/mob_spec.py` `TIERS` 고치기 → `python3 tools/mob_spec.py apply` → `python3 tools/operating_overlay.py regenerate` → `check` (차이 없음) → `python3 docs/plans/mob-spec/model.py` 로 표 다시 보기.
