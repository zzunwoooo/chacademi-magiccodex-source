## 3. 방어 — 마법 피해에 적용되는지

**코드로 보면 지금도 적용됨.** 플레이어가 쓴 마법 피해는 모두 `M/Targets.java:120-132` → `M/MagicProtection.java:64` `target.damage(amount, caster)`를 거침. 이건 Paper 기본 "플레이어 공격" 피해 종류라 바닐라 방어력·방어 강도·보호 인첸트(EPF, 최대 20 = 80%)·저항 효과가 모두 적용됨. 미몹 스킬 파일에는 `ignoreArmor`/`ignoreEnchantments` 옵션이 하나도 없음(grep 0건). 정보창 '방어력' = 바닐라 `ARMOR` 속성 값(`P/StatsBridge.java:126`). ※ 게임 안에서 한 번 확인 필요.

방어가 다르게 적용되거나 빠지는 경로:

| 위치 | 내용 | 제안 |
|---|---|---|
| `M/HitMech.java:69-76` 크로스 애로우 처형 | `현재 체력+1` 피해를 넣는데 방어로 줄어서 **처형이 실패함** | 처형은 방어 무시(아래 전용 피해 종류 + 방어 0)로 |
| `M/StatusEffects.java:365,478` 화상 폭발·독 틱 | 시전자가 없을 때 `t.damage(amount)`(일반 피해) → 방어구는 적용되지만 시전자 인첸트 판정은 없음 | 방어 공식을 하나로 맞춤 |
| `M/Guards.java:152,218,230` | 보호막 감소·피해 나눠 받기(`protector.damage`) | 나눠 받는 피해는 이미 줄어든 값이라 두 번 줄지 않게 함 |
| `M/HitMech.java:29`, `M/ArcanaMech.java:940` | 자기 체력 소모(setHealth / 자신 피해) | 그대로 (의도된 동작) |
| `kyudichi-paper/.../Match.java:516-518` 블러저 | 고정 피해, 방어 무시 (오너 결정) | 그대로 (마법 아님) |
| 바닐라 무적 시간 10틱 | `setNoDamageTicks` 초기화가 없음 → 0.5초 안에 들어간 다단 히트는 더 큰 값만 들어감(드래곤 브레스 6틱 간격 5타 등) | 마법 피해 뒤 플레이어 대상은 `setNoDamageTicks(0)`, 또는 다단 간격을 10틱 이상으로 |

바닐라 공식을 그대로 두면 생기는 문제 (현재 초급 피해 기준):

| 방어 쪽 | 장비 | 감소율 |
|---|---|---|
| 대충 | 철 세트, 인첸트 없음 (방어 15, 강도 0) | 12~39% (큰 피해일수록 덜 막음) |
| 적당 | 다이아 + 보호 III (20 / 8 / EPF 12) | 68~84% |
| 한계 | 네더라이트 + 보호 IV (20 / 12 / EPF 16) | 81~90% |

→ **마법용 방어 공식 + 상한을 제안**:
- 방어 감소율 = min(**45%**, (방어력 + 보호 EPF 합) × 1.25%). 방어 강도(toughness)는 마법에서 무시. 저항 포션은 상한 밖에서 곱하되 최대 20%.
  - 대충 철(15) → 18.75% · 적당 다이아 + 보호 II~III(20+10) → 37.5% · 한계 네더라이트 + 보호 IV(20+16) → 45%(상한)
- 구현: 데이터팩에 피해 종류 `chacademi:spell`(태그 `bypasses_armor` + `bypasses_enchantments`, 저항 효과는 유지)를 만들고, `M/MagicProtection.java:64`에서 `amount × (1 − 감소율)`로 줄인 뒤 `DamageSource.builder(그 종류).withCausingEntity(caster)`로 피해를 넣음. 화상·독(`StatusEffects`)과 처형(`HitMech`, 감소율 0)도 같은 경로로.
