# NPC 85명 일과표 (새 장소 34곳 기준, 2026-10-26, 메모 #84 후속)

오너 2026-10-26: "우리 바꾼 장소 기준으로 npc 행동 관련해서 다시 기획해서 넣어줘".
장소 34곳은 [npc-places.md](npc-places.md). 고친 yml 85개는 [npc-schedules/](npc-schedules/) (바뀐 건 `schedule:` 블록뿐, 나머지 줄·주석·순서 그대로).

## 먼저 할 일 — places.yml 에 34곳 등록

일과표의 장소가 `places.yml` 에 없으면 그 NPC는 **움직이지 않고** 서버 로그에 `[ChacaNPC] <id> 일과표의 장소 '<장소>'가 places.yml에 없습니다` 가 찍힌다 (MovementController). 그래서 순서가 중요하다.

1. [npc-places.md](npc-places.md) 의 34곳을 그 자리에 서서 `/NPC관리 장소 <영문이름> <반경> <표시이름>` 으로 등록 (표의 명령 그대로).
2. 테스트 때 만든 옛 장소는 `/NPC관리 장소관리 목록` 으로 보고 `/NPC관리 장소관리 삭제 <이름>` (전부 지우려면 `전부삭제 확인`).
3. PC `차카데미npc_claude/NPC_85_최신` 폴더의 yml 85개 → 서버 `plugins/ChacaNPC/npcs/` 에 덮어쓰기 (저장소 사본: `docs/plans/npc-schedules/`).
4. `/서버관리 새로고침 NPC` (ChacaNPC `reloadEverything` — 설정·캐릭터·장소·필터 다시 읽고 이동 상태 초기화).
5. 확인: `/NPC관리 목록`, 서버 로그에 위 경고가 없는지. 막히는 길만 `/NPC관리 경로 추가 <장소>` 로 길목 찍기.

`deployment/operating-config` 에는 ChacaNPC 폴더가 없어서(운영 덮어쓰기 대상 아님) overlay 는 손대지 않았다.

## 코드에서 확인한 동작 (chaca-npc-paper)

| 항목 | 실제 동작 |
|---|---|
| 시간 기준 | **마크 게임 시간** (NPC가 있는 월드의 `getTime()`, 0틱 = 06:00, 1000틱 = 1시간). 현실 시간 아님. 게임 하루 = 현실 20분, 게임 1시간 ≈ 현실 50초 |
| 어느 칸인지 | 지금 시각 이하인 칸 중 가장 늦은 칸. 오늘 첫 칸보다 이르면 **어제 마지막 칸이 이어짐** → 마지막 칸(밤 장소)이 다음 날 첫 칸까지 유지 |
| time 형식 | `'07:00'` 처럼 따옴표 문자열 (따옴표 없는 6:00 은 YAML 이 60진수 360 으로 읽는데 그것도 분으로 처리됨). 이번 파일은 전부 따옴표 |
| 이동 | 1초마다 검사. 칸이 바뀌면 NPC마다 0~`stagger-seconds`(20)초 흩어 출발. 출발점·도착점 둘 다 반경 `walk-radius`(48칸) 안에 플레이어가 없으면 **순간이동**, 있으면 Citizens 길찾기로 걸어감(등록한 길목을 가까운 것부터 거침). 길을 못 찾거나 한 구간에 `give-up-seconds`(40초)가 지나면 순간이동 |
| 도착 후 | 장소 반경 안 무작위 지점으로 8~15초마다 배회 — 장소 중심 32칸 안에 플레이어가 있을 때만 |
| activity | AI 대화 프롬프트에 "장소 표시이름 + 지금 하는 일"로 들어감(DialogueService), 버튼 대답 미리 만들기, 같은 장소에 같이 있는 NPC끼리 잡담(SocialService 장소별 묶음) |
| schedule 없음 | 이동 처리 자체를 건너뜀 → Citizens 가 둔 자리에 그대로 (스토리 NPC에 맞음). 프롬프트에는 장소·할 일 없이 시간대만 들어감 |
| 장소 id 없음 | 위 경고 로그, 그 칸 동안 이동·배회 안 함 (제자리) |

## 기획 원칙

- **학생** (st_* 35명 + 엘라·미나·린): 기숙사 → 09~12시 수업(1학년은 대강당 합동 수업, 2·3학년은 강의실 1~3, 넘치면 대강당) → 12시 카페테리아 → 14시 오후 수업 또는 자유(도서관·도서관 2층·학교 앞 쉼터·분수 광장·결투장·논밭 등 성격대로) → 18시 전후 카페테리아 → 19~23시 기숙사. 늦잠꾸러기(건호·로완·하루)·야간 독서회·별 보기(미향·로완, 나선형 계단) 같은 개성은 원래 일과에서 살림.
- **기숙사 배치**: 방 장소가 없어서 아르케온·베스티아즈 → `dorm_entrances`, 루미나·노크세르 → `dorm_hall`.
- **교직원·교수**: 브루노(관리인)는 계단·로비·대강당·벽화 계단·쉼터·지하 감옥 문단속·로비 문단속을 돈다. 도로테아는 카페테리아(오후에 물고기 판매점 장보기). 힐데는 병원 고정. 베르나는 연금술 공방 ↔ 강의실 2 ↔ 병원. 세드릭은 쉼터(비행 연습) ↔ 강의실 3 ↔ 빗자루 판매점. 교무실(staff_hall) 일은 대강당.
- **물건 파는 사람**은 영업 시간 내내 자기 가게, 자리 비우는 건 점심 1시간 이하: 그레타(상가 1 빵집 05~19시), 셀마(물고기 판매점 07~19시), 로사(분수 광장 꽃 좌판 07~20시), 클라라(가정집 1 재단소), 펠릭스(가구점), 오토·토비(지하 강화소), 디터(분수 광장 노천 이발), 베른트·니나(상가 1 주점 18~24시).
- **마을 사람**: 직업 장소 ↔ 메인 광장·퀘스트 게시판·분수 광장 ↔ 집. 집은 장소가 가정집 1·뒷마을 문뿐이라 나눔: 메인 광장 둘레 집(밤에 메인 광장 칸, 활동 "광장 옆 집에서 쉬는 중"), 항구 사람은 부두, 농가는 논밭, 가게 주인은 가게 뒷방/위층, 경비·점등원·짐꾼·약초꾼은 뒷마을 문.
- 하루 4~7칸, activity 는 원래 문구 톤 그대로 짧게.
