**읽는 법**

- **조건 없음 149개** = 서버 파일에 아예 없는 것 103개 + `manual-conditions.yml`(수동 목록)에만 있고 책·수업·스토리 어디에서도 `마법조건 주기`를 안 하는 것 46개. 수동 목록에 들어가면 `discoveries.yml`의 자동 판정이 꺼지므로(코드: `Definitions.manual`), 이런 마법은 관리자가 `/유저관리 <닉네임> 마법조건 주기`를 해 줘야만 얻음.
- 수동 목록 마법을 실제로 주는 곳은 `books.yml`의 수업 책·도서관 책 명령뿐 (60개). 스토리·NPC 퀘스트·일반 퀘스트에서 주는 곳은 없음.
- "책 연결 대기" = `books.yml`에 책은 써 뒀지만 명령을 주석으로 꺼 둔 것 (docs/plans/library-books.md). 켜려면 수동 목록에 먼저 등록해야 함.
- 등급 = `tools/spell_order.py` 가중치 1~10 (10 = 궁극).
- 전체 300개는 `discovery-review.csv` (분류 열에 정상 포함).

## 참고

- `discoveries.yml`과 `manual-conditions.yml`에 같이 있는 52개는 수동 쪽이 이김. `discoveries.yml` 쪽에 옛 판정 키가 남아 있는 것도 있음 (예: 폭풍의 지휘 `wind.hot_air_rotation`, 화염 채찍 `fish.monster_pulled`, 파이어 스트라이크 `practice.shield_completed`) — 실제 동작엔 영향 없음.
- `discoveries.yml`에만 있고 300종에 없는 것: `feather_step`, `wind_vault` (둘 다 미구현 표시).
- 깨달음의 빛 힌트는 `discoveries.yml` 문구만 읽음 → 수동 목록에만 있는 마법은 힌트가 안 나오고, 반대로 두 파일에 다 있는 마법은 실제로는 안 세는 조건(예: 바람바구니 "아이템 1000개 줍기", 윈드 프레스 "앵무새 공격")을 힌트로 알려 줌.
- 서버 자동 판정 83개 키는 모두 코드에서 실제로 세고 있음 (확인함).
