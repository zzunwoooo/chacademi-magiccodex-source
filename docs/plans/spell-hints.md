# 마법별 힌트 문장 (spell-hints.yml)

2026-10-26 · 오너 결정

## 무엇인가

`magic-codex-paper/src/main/resources/spell-hints.yml` 은 아직 발견하지 못한 마법의 힌트 문장이다.
마법 힌트권 타로 · 깨달음의 빛 · NPC 힌트가 같은 문장을 쓴다.

- `1` = 1성 힌트: 아주 막연하게. 원소와 행동의 느낌만 비유로.
- `2` = 2성 힌트: 무엇을 하면 될지 돌려서 암시. 생각 깊은 플레이어는 짐작할 수 있게.
- 3성은 파일에 없다. 코드가 발견 조건(`condition-text`) + 지금 진행도로 자동으로 만든다.

키 = 마법 id. 키 뒤 주석 = 한글 이름 (원소) — 지금 발견 조건. 순서는 원소(바람·화염·물·대지·빛·어둠) → 등급.

## 개수

299종 전부 (300종 중 처음부터 아는 아공간 수조 `fish_trap` 제외). 궁극(등급 10) 마법도 포함.
기준: `magic-discovery-paper/src/main/resources/discoveries.yml` + `manual-conditions.yml` (발견 조건 v2, `discovery-conditions-v2.md`).

## 문장 규칙

- 한국어, 점술가·소문처럼 따뜻한 말투. 끝은 "…" 또는 "요.". 한 줄 60자 안팎.
- 숫자 금지 (아라비아 숫자, "한 번·두 번·서른" 같은 수 낱말도 피함).
- 그 마법의 이름을 쓰지 않는다.
- 1성: 장소·아이템·NPC·책 이름 없이 이미지와 느낌만.
- 2성: 조건 문구를 그대로 옮기지 않고 돌려 말한다. 이름 대신 암시 ("하르바 교수의 바람 마법 기초 수업" → "바람을 가르치는 선생님의 첫 수업", 책 제목 → "도서관 어딘가 하늘을 나는 법을 적은 기록").
- 마법마다 문장이 달라야 한다 (같은 조건을 공유하는 마법도 서로 다른 문장).
- 오너 예시 `light_leap` 문장은 그대로 둔다.

## 조건을 바꿀 때

발견 조건(`discoveries.yml` / `manual-conditions.yml`)을 바꾸면 **그 마법의 1·2성 문장과 키 뒤 주석도 같이 고쳐야 한다.** 안 고치면 힌트가 엉뚱한 행동을 가리킨다.
마법을 새로 추가하면 여기에도 1·2성 두 줄을 추가한다.
