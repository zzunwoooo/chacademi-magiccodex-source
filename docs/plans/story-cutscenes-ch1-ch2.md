## 컷신은 어떻게 만드나 (공통)

- **형식**: 그림(PNG) 장면을 순서대로 보여 주고, 확대·이동(zoom)·전환(ink / fade / cut)·아래 자막·배경음을 붙이는 2D 컷신. 게임 카메라를 움직이는 방식이 아니다. 파일 형식은 [chacademy-story/FORMAT.md](../../chacademy-story/FORMAT.md), 예시는 `chacademy-story/example/ch1_ashen_night/`.
- **만드는 도구**: `chacademy-story/editor/cutscene-editor.html` (브라우저) → "zip으로 내보내기". 그림은 편집기가 PNG 로 바꾸고 긴 변 1600px 로 줄여 줌.
- **그림**: 16:9 (예시와 같은 1536×864). 같은 그림체(동화책 느낌의 일러스트)로 통일. NPC 얼굴·옷은 대화 초상화(오너 PC `Desktop\차카데미npc_claude\NPC_85_최신\portraits`)와 맞춘다. **플레이어는 얼굴을 그리지 않는다** (뒷모습·실루엣·손만) — 사람마다 모습이 다르기 때문.
- **배경음**: 폴더 안 `bgm.ogg` (ogg 만, 32MB 까지). 비우면 소리 없음.
- **놓는 곳**: 클라이언트(런처) `config/chaca_cutscene/<컷신ID>/` — 컷신은 대사와 달리 서버가 보내지 않으므로 **런처 배포에 넣어야 함**. 서버는 재생 신호만 보낸다.
- **서버 쪽**: 단계의 `컷신:` 에 ID (steps.yml 에 이미 들어 있음). 플러그인 `config.yml` `cutscenes:` 자동완성 목록에 6개 중 5개 넣어 둠 (`ch2_ashen_echo` 는 2장 단계 만들 때). 다 만든 뒤 `min-seconds` (2배속을 생각해 길이의 절반보다 조금 작게)를 운영 config 에 적기 — 아래 표의 값.
- **보는 규칙**: 처음 보는 컷신은 건너뛸 수 없음, 본 적 있으면 스페이스 2초로 건너뛰기, 2배속 버튼 있음. 본 기록은 서버에 저장.
- **아직 파일이 없을 때**: 클라가 "보여 줄 수 없음"을 보내면 서버가 3번 다시 시도한 뒤 건너뛰고 다음 단계로 넘어감 (콘솔 경고). 1장은 멈추지 않지만 장면이 빠지므로 오픈 전에 4개(1장 흐름)는 꼭 넣을 것.
