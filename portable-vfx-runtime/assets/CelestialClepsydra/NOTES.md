# CelestialClepsydra (천상의 물시계) — 물 종결 마법, 변환 메모

- 시스템 1개: `main` (static, 11.8 s, loop 없음, 96 layers). P = 대상 지점 바닥, 위 = +Y. 서버는 시전 시 1번만 시작 (단계 신호 없음).
- 런타임 입력: `areaRadius` (기준 7 m, 3.5~10 m). 바닥 마법진·물시계 높이(14 m)·해일 범위 전체가 같이 커지고 작아짐.
- 시간표 (s):
  - 0.0 바닥 마법진(반경 7 m) · 0.4 하늘이 깊은 물빛으로 (장막·심해 안개·기포·빛 반짝임)
  - 0.8 하늘 14 m 에 거대 물시계 등장 (문자판, 바늘 2개, 물 구슬 심장, 항아리 모양 틀, 물방울 왕관) · 1.4~ 물시계에서 바닥으로 물줄기
  - 2.0 1악장 비 (폭우·물보라·파문) · 4.2 2악장 얼음 (얼음 비·바닥 얼음 가시·서리) · 6.2 3악장 해류 (나선 물줄기·소용돌이·회전 물살)
    — 각 악장 시작에 문자판 섬광 + 왕관 파동 + 바닥 파문. 악장마다 지속 피해를 넣는다면 2.0~4.2 / 4.2~6.2 / 6.2~8.0 구간.
  - 8.0 예고: 바늘 폭주, 문자판 균열, 물이 모여듦 · **8.6 물시계 파괴 (1차 피해 권장)** · **9.1 쏟아진 물이 전장 전체를 휩쓸음 (2차 피해 권장, 해일 고리 ≈ 40 m)**
  - 9.5~11.8 이슬비·파문·잔광·바닥 문자판 잔상.
- 회전하는 층의 섬광 사본은 시작 회전을 ω·(시작−기준) 으로 맞춰 둠 (바늘, 다각형, 룬 띠, 바닥 문자판, 틀).
- 모든 항목이 클라이언트 지원 기능 안 (client_compat check OK). 고유 텍스처 RGBA 3.1 MiB (검사기 4.3 MiB 는 재질별 중복 집계).


- 2026-10-30 수정: `scale.min/max` 는 반경(m)이 아니라 배율(SCHEMA §5.3)이므로 0.5~1.429 배로 고침 (반경 3.5~10.0 m). 이전 값(m 단위로 적은 3.5~10 등)은 모든 시전을 3.5배 이상 크게 만들던 오류.
