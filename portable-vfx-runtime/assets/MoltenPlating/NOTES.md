# MoltenPlating (쇳물 갑주) — 화염 중급

## 시스템 / 역할
- `plating` (attached, 4.0 s, 25층): 시전자 발 위치 + 수평 방향을 매 프레임 따라감. 버프 지속 4초.
- `retaliate` (impact, 0.2 s + 입자 수명 ≈ 0.7 s, 8층): **나를 근접 공격한 적마다 1회** 재생. 
  - hitPoint = 공격자 가슴(발 + 약 1.1 m), surfaceNormal = (공격자 − 시전자) 수평 방향 정규화, incomingDirection = 같은 방향.
  - 로컬 +Y(= 시전자→공격자 방향)로 쇳물 방울·화염이 튀어 나감. 연기·화염 상승은 world 위쪽.

## 시간표 (plating)
| 시각(s) | 내용 |
|---|---|
| 0.00–0.45 | 발밑 방패 문양 마법진, 쇳물 줄기가 솟아오르고 철판 11장이 반경 1.6 m 에서 몸으로 모여듦, 가슴 고리가 조여듦 |
| **0.45** | 갑주 완성 섬광 + 불꽃 (← 반격 판정 시작 권장) |
| 0.45–3.6 | 격자 껍질(2겹 역회전) + 철판 궤도 회전, 쇳물 방울 낙하, 열기 불꽃·불티 |
| **3.6** | 철판이 식어 떨어지고 껍질 섬광 → 연기 (← 판정 종료 권장) |
| 4.0 | 종료 |

## 피해 권장 시점
- 반격(불붙이기) 판정: 0.45–3.6 s(버프 시작 기준). 실제 4초 버프면 0–4 s 그대로 써도 연출과 어긋나지 않음.
- 반격 화상 피해 자체: `retaliate` 재생 시점(t = 0).

## 메모
- 철판은 원형 방출 + 음수 시작 속도 + drag 로 몸 쪽(반경 ≈ 0.55 m)으로 모인 뒤 궤도 회전(orbitalY).
- client_compat check: OK. 고유 텍스처 RGBA ≈ 1.95 MiB.
