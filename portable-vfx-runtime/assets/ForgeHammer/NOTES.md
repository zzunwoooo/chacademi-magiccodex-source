# ForgeHammer (단조 망치) — 화염 중급

## 시스템 / 역할
- `main` (static, 2.1 s, 43층). P = **대상의 발 위치**, 기준 방향 +Z = 시전자 수평 방향(서버가 넘겨줌), +Y 위.
- 런타임 입력: `targetHeight` (scale: reference 1.8, 배율 min 0.6 / max 2.2 → 큰 대상일수록 망치·마법진·기절 고리가 같이 커짐).

## 시간표
| 시각(s) | 내용 |
|---|---|
| 0.00–0.40 | 대상 발밑 화염 마법진(링·육망성·룬 띠·모루 문양)이 그려짐, 4.65 m 위에 불망치가 생성되며 뒤로 치켜듦(불꽃 모임) |
| 0.42–0.62 | 내려찍기 (가속 스윙 2단, 불꽃 잔상 호 + 뒤에서 보이는 불막) |
| **0.62** | **타격** — 머리 위 섬광, 모루 불꽃 분수, 숯 덩어리, 공중/바닥 충격파 2겹, 바닥 균열, 화염 혀·불기둥·연기 |
| 0.66–1.66 | **기절 1초**: 머리 위(2.15 m)에 불별 3개 + 링 2개 회전 |
| 0.84 | 망치가 불씨로 흩어짐 |
| 1.7–2.1 | 마법진·균열 식으며 종료 |

## 피해 권장 시점
- 피해 + 기절 시작: **0.62 s** (기절 1초 = 0.62–1.62 s, 연출은 0.66–1.66 s).

## 메모
- 망치는 교차 사각형 메쉬(정면/측면 2장)로 모든 각도에서 보임. 회전은 rot3 + rotationOverLifetime(X축) 단계별 복사본으로 구현(손잡이 끝 4.65 m 가 회전축).
- 기절 별은 궤도 속도(orbitalY) + trails 사용.
- client_compat check: OK (fix 단계 0 change). 고유 텍스처 RGBA ≈ 2.31 MiB (16장).
