# EmberTongs (불티 집게, 화염 초급) — 변환 메모

- 시스템 1개: `tongs` (attached, 0.7 s, loop 없음, 28 layers). P = 시전자 발, +Z = 시전자 수평 정면. 시전 시 1번 시작.
- 연출: 시전자 앞 1.45 m·높이 1.15 m 지점(집게 끝, Q)에서 쇠 집게가 두 번 물었다 놓는다.
  - 0.04~0.14 좌우 집게날이 벌어진 상태에서 닫힘 → **0.14 1타 (피해 권장)**: 섬광·불꽃·불티·숯 조각, 바닥 그을음 + 열 고리
  - 0.34~0.44 위아래 집게날로 다시 닫힘 → **0.44 2타 (피해 권장)**: 같은 구성 + 바닥 소용돌이, 불티 더 많음
  - 0.5~1.1 연기·불씨가 피어올랐다 사라짐 (마지막 입자 약 1.4 s).
- 집게날 = 메쉬 리본(jawL/jawR/jaws). 어두운 쇠 몸체(알파, 밝은 테두리) + 뜨거운 날 가장자리(가산) + 은은한 후광. 닫히는 동작은 rotation3D 시작 각 + rotationOverLifetime(0.1 s) 으로 구워 둠.
- 런타임 입력: 없음 (scale 사용 안 함). 근접 판정 위치는 시전자 앞 약 1.2~1.6 m.
