# FullMoonDescent (만월 강림) v2 — 어둠 종결 마법, 변환 메모

- 시스템 1개: `main` (static, 11.8 s, loop 없음, 85 layers). P = 대상 지점 바닥, 위 = +Y. 서버는 시전 시 1번만 시작 (단계 신호 없음).
- 런타임 입력: `areaRadius` (기준 7 m, 3.5~10 m). 마법진·하늘 봉인·달 높이·충격파 전체가 같이 커지고 작아짐.
- 시간표 (s):
  - 0.0 바닥 마법진(반경 7 m) 그려짐 · 0.4 밤하늘(어두운 장막·높은 안개·별) · 0.8 보름달 등장(높이 20 m, 지름 8 m)
  - 1.3 하늘 봉인(두 번째 마법진, 높이 13.2 m) · 2.0~7.5 달빛 기둥 + 빛 기둥 8개 + 빛비 + 궤도 초승달, 달이 봉인 위로 천천히 내려옴
  - **7.5 달이 봉인을 깨고 낙하** (봉인 파편·섬광) · **8.1 착지 폭발 (중심 높이 4 m, 1차 피해 권장 시점)**
  - **8.6 거대 초승달 참격 + 2차 충격파 (2차 피해 권장 시점)** · 8.8~11.8 별똥비·잔광·바닥 시길 잔상.
- 달은 같은 크기·회전의 두 사본: 유지(0.8~7.5, gravityModifier ≈0.014 + linear −0.5 m/s) → 낙하(7.5~8.1). 이어받는 위치는 SCHEMA §4.2 고정 스텝 순서로 계산.
- 회전하는 층의 섬광 사본은 rotation3D 를 ω·(시작−기준) 으로 맞춰 둠 (바닥 다각형·룬 띠·시길, 하늘 봉인).
- 미리보기 전용: 카메라에서 약 30 m 넘게 떨어지면 미리보기에서 큰 빌보드가 사라지는 현상이 있어 전체 카메라를 27 m 로 둠 (게임 렌더와 무관).
- 모든 항목이 클라이언트 지원 기능 안 (client_compat check OK). 고유 텍스처 RGBA 3.3 MiB (검사기 4.3 MiB 는 재질별 중복 집계).


- 2026-10-30 수정: `scale.min/max` 는 반경(m)이 아니라 배율(SCHEMA §5.3)이므로 0.5~1.429 배로 고침 (반경 3.5~10.0 m). 이전 값(m 단위로 적은 3.5~10 등)은 모든 시전을 3.5배 이상 크게 만들던 오류.
