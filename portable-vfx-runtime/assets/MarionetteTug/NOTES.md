# MarionetteTug (꼭두각시 당김) — 어둠 초급, 변환 메모

- 시스템 2개 (둘 다 시전 시 동시에 시작, 단계 신호 없음):
  - `tug` (link, 0.9 s, 16층): source = 시전자 손, target = 대상 몸 중심(발 + 약 1.1 m). link 프레임은 **매 틱 갱신** — 모드가 대상을 끌어오는 동안 실이 그대로 짧아짐.
    - 실 = 손 → 대상으로 0.16 s 동안 흘러가는 입자를 계속 뿜어서 만든 연속선 (은백 + 진홍 + 라벤더 3가닥, 먹빛 매듭). 처음 0.18 s 는 실이 자라나는 모습.
  - `bind` (attached, 1.0 s, 9층): **대상**의 발 위치에 붙음 (+Z = 대상 → 시전자 방향). 대상 머리 위 꼭두각시 조종대(십자 막대) + 몸으로 내려오는 실 4가닥이 흔들림, 발밑 진홍 육망성 봉인, 끌려가는 동안 먹빛 안개·진홍 알갱이.
- 시간표: 0~0.18 실 발사 · **0.18 걸림 (명중 판정/피해 권장)** · **0.30 당김 시작 — 모드가 대상을 0.30~0.70 s 사이에 시전자 앞(약 1.5 m)으로 이동** (빛 펄스가 대상 → 손으로 달림) · 0.75~0.9 실이 풀려 흩어짐.
- 빗나감 버전은 없음 (빗나가면 tug 만 재생해도 실이 조준 지점까지 갔다가 풀림; bind 는 시작하지 않음).
- 런타임 입력: link (source, target 매 틱), attached (대상 발 + 방향). scale 미사용.
- 미리보기: 마네킹 = 대상 (6 m / 3.5 m 에서 끌려옴), 원점의 더미 = 시전자.
- client_compat check OK. 고유 텍스처 RGBA 1.02 MiB.
