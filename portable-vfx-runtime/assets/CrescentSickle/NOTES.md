# CrescentSickle (초승달 낫) — 어둠 초급, 변환 메모

- 시스템 2개 (둘 다 `attached`, loop 없음):
  - `slash` (1.0 s, 23층): 시전자 발 위치 + 수평 정면(+Z)에 붙음. 시전 시 바로 시작.
  - `bleed` (1.5 s, 9층): **맞은 대상**의 발 위치에 붙음 (+Z = 대상이 바라보는 방향, 아무 방향이어도 무방). 모드가 명중 판정 시 대상마다 1번 시작.
- 시간표 (slash 기준):
  - 0.00~0.12 오른손 쪽에 초승달 칼날이 맺힘 (작은 초승달·별 반짝임·먹빛 조각이 모여듦), 발밑 작은 마법진(육망성) 그려짐
  - 0.12~0.38 낫 휘두르기: 오른쪽 아래 → 정면 → 왼쪽으로 사선 베기 (반지름 약 1.75 m 메쉬 칼날 + 먹빛 잔상 + 달빛/진홍 궤적)
  - **0.20 s 명중 (피해 권장 시점)**: 정면 약 1.5 m 지점에 큰 초승달 섬광, 진홍 고리, 불꽃·피 튐, 먹빛/빛 초승달 조각, 바닥에 베인 자국 선
  - 0.3~1.0 안개·빛 알갱이 흩어짐
- bleed (명중 후, 대상 기준): 0 s 베인 자국(진홍 사선) + 피 분출 · **출혈 틱 0 / 0.5 / 1.0 s** (진홍 고리 + 피 분출 반복, 출혈 피해를 이 시점에 맞추면 자연스러움) · 계속 피 방울이 떨어지고 바닥에 핏자국이 생겼다 사라짐. 출혈 시간을 늘리고 싶으면 bleed 를 다시 시작하면 됨.
- 런타임 입력: 없음 (scale 미사용). attached 기본 입력(발 위치 + 수평 방향)만 사용.
- 색: 흰 → 은백 → 라벤더 → 보라 (달빛) + 출혈 진홍 포인트. 먹빛 칼날 잔상·먹빛 초승달은 알파 블렌드 + HDR 테두리.
- 미리보기: 시전자(원점, +Z)와 대상(1.9 m 앞)이 있고, 0.2 s 에 대상에게 bleed 가 시작되는 데모 (`events`, 미리보기 전용). 명중 후 대상이 살짝 밀려나는 것도 데모 연출.
- client_compat check OK. 고유 텍스처 RGBA 1.41 MiB.
