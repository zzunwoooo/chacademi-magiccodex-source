# SandCoffin (모래관) — 대지 고급

## 시스템 / 역할
- `main` (static, 3.6 s). P = **대상의 발 위치**. 기준 방향 무관(대칭).
- SCENE.scale `targetHeight` (reference 1.8, min 0.7, max 2.2): 관 크기가 대상 키를 따라감.

## 시간표
| 시각 (s) | 연출 |
|---|---|
| 0.0 | 발밑 마법진(반경 1.6 m) 그려짐, 모래 나선 두 겹이 대상을 감고 솟음, 모래 소용돌이 |
| 0.5 | 봉인: 육각 모래관(반경 0.78 m, 높이 2.35 m) 닫힘 + 섬광 + 먼지 고리. 위 뚜껑 문양 |
| 0.5–2.5 | 유지: 관 벽 모래가 흘러내림(플립북 순환), 룬 띠 2개 반대 방향 회전, 위에서 모래가 넘침, 주위 먼지 |
| 2.15–2.5 | 예고: 수축하는 빛 고리, 관 균열 빛 증가, 룬 띠 조여듦 |
| **2.5** | **압착**: 관이 0.16 s 동안 안으로 무너짐 → 2.62 s 폭발(모래·돌·불꽃·어두운 먼지·충격파·균열) |
| 3.6 | 종료 |

## 피해 권장 시점
- 가둠(이동 불가) 0.5–2.5 s, **압착 피해 2.6 s** (붕괴 끝 + 폭발 순간). 시전 직후(0 s) 이 시스템을 대상 발에 시작한다.

## 런타임 입력
- static: P(대상 발) + targetHeight.
