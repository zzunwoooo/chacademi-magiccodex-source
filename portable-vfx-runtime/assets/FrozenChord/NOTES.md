# FrozenChord (결빙 화음) — 물 · 비전

## 시스템 / 역할
- `main` — **static** 1개. P = 지정한 중심(바닥), +Z = 서버가 넘기는 시전자 수평 방향.
- 세 지점(얼음 기둥 위치)은 P 기준 고정 배치: **k = 0,1,2 → P + 4 m·(sin 120°k, 0, cos 120°k)** (k=0 이 정면 +Z). 피해 판정도 이 세 점 기준.
- `scale = {input:"areaRadius", reference:4, min:0.5, max:1.6}` → 지점 간격·기둥 크기가 함께 커짐.
- 기둥 = depthWrite 결정 메쉬(기둥당 높이 ≈ 7.5 m, 주위 결정 6개) + 가산 모서리 선. 세 기둥·세 마법진은 한 메쉬에 합쳐 정확히 동시에 움직임.

## 시간표 (s)
| 시각 | 연출 |
|---|---|
| 0.0–0.45 | 중심 화음 문장(세 원 삼각) + 세 지점 육각 마법진 그려짐 |
| 0.3–1.45 | 공명: 세 점을 잇는 빛 삼각형, 음파 고리 3박(0.5 / 0.85 / 1.15, 점점 강해짐) + 음표 반짝임, 냉기 상승, 서리 무늬, 0.95부터 세 마법진 수축 |
| **1.45** | 세 지점에서 동시에 거대 얼음 기둥 솟음(0.2 s, 살짝 넘침), 빛기둥, 중앙 섬광, 큰 충격 + 지점 충격, 파편·먹빛 파편·광선 |
| 1.45–3.4 | 화음 유지: 기둥마다 룬 고리 2개(3.2 m / 5.4 m) 깜박임, 낮은 맥동 고리 3회, 눈, 안개, 반짝임 |
| **3.4** | 세 기둥 동시 파쇄: 지점별 섬광·파편·광선·안개 + 전체 충격, 잔파편, 눈꽃 |
| 4.6 | 종료 |

## 피해 권장 시점
- **1.45 s** 세 지점 반경 ~1.7 m 주 피해(솟음, 띄우기 가능).
- **3.4 s** 파쇄 피해(세 지점, 작게).

## 런타임 입력
- static: P + 수평 방향 + `areaRadius`.
