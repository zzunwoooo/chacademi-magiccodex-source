# BatCloak (박쥐 망토) — 변환 메모

**원소/등급**: 어둠 · 중급. 달빛 보라 팔레트 + **진홍 포인트**(박쥐 테두리·흡혈 줄기, 브리프 허용). 먹빛 박쥐 몸체 + 밝은 테두리.

## 시스템 / 역할
| id | role | 길이 | 붙는 곳 | 시작 |
|---|---|---|---|---|
| `cloak` | attached | 0.46 s | **시전자** 발 위치. 기준 방향(+Z) = **이동(돌진) 방향** (GaleDash 와 같은 규칙) | 시전 순간. 모드가 0.36 s 동안 시전자를 4블록 앞으로 옮기고 몸을 숨긴다 |
| `drain` | link | 0.62 s | source = **지나친 적**의 가슴(발 + 1.1 m), target = **시전자** 가슴(발 + 1.1 m), 두 끝 매 프레임 갱신 | 적을 지나치는(흡혈 판정) 순간, 적마다 새 인스턴스 1개 |

- 몸 숨김(0.04–0.36 s)과 실제 이동은 모드 몫. 이 파일은 시각만.
- 이동 시간이 설정으로 달라지면: 무리(T01~T05, 지역 공간)는 0.36 s 기준 수명이라 길어지면 끝부분이 비게 된다 → 0.3~0.45 s 범위 권장. 도착 연출(R01~R09)은 cloak 시작 + 0.22~0.41 s 에 구워져 있다.

## 시간표 (cloak 시작 기준)
- 0.00 출발점(월드): 진홍-보라 섬광, 박쥐 20마리 + 빛 박쥐 7마리 사방으로 흩어짐, 진홍 안개, 잉크 파편, 바닥 충격 고리
- 0.00–0.36 몸 자리(로컬): 박쥐 무리 34+12마리가 몸 주위를 소용돌이, 어두운 핵 그늘 + 안개, 붉은 눈 깜박임, 진홍 리본 소용돌이 / 경로(월드, 거리 비례): 보라·진홍 줄기, 안개, 낙오 박쥐, 진홍 입자
- 0.22–0.36 도착점에서 박쥐가 안쪽으로 모여듦, **0.40 재결합 섬광** + 충격 고리 + 먹빛 초승달 망토 + 박쥐 몇 마리 흩어짐
- `drain` 0.00 적에게 송곳니 물기(섬광 + 진홍 초승달 2개 + 잉크·핏방울) — **흡혈 피해 권장 시점 = drain 0.00**, 0.00–0.6 진홍 생명 줄기·방울·먹빛 띠가 시전자에게 흐름, 0.32/0.50 시전자 가슴에서 회복 맥동

## 런타임 입력
- cloak: 시전자 발 위치 + 이동 방향(매 프레임)
- drain: source(적 가슴) + target(시전자 가슴) 월드 좌표 매 프레임 (link, SCHEMA §5)
- scale 입력 없음.
