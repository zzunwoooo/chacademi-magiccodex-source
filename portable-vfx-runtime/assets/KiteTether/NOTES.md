# KiteTether (연줄) — 바람 중급 · 변환 메모

## 시스템 / 역할
| id | role | 붙는 곳 | 길이 | 시작 |
|---|---|---|---|---|
| cast | attached | **시전자** 발(+Z = 시전자 정면). 오른손 기준점 local (0.35, 1.35, 0.45) | 0.6 s | 시전 순간 (t=0) |
| kite | attached | **대상(적)** 발. 연은 발 위 3.0 m (local (0,3,0)) | 4.0 s (+ 잔상 ~0.8 s) | 연이 걸리는 순간 (데모 t=0.15) |
| tether | link | source = 시전자 오른손 (발 + 시전자 기준 (0.35,1.35,0.45)), target = 대상 발 + (0, 3.0, 0) = 연 위치. **매 프레임 둘 다 갱신** | 3.85 s | kite 와 같은 순간 |

- 대상은 모드가 실제로 띄우고(데모: 0.15→0.7 s 사이 1.2 m 상승) 끌고 다닌다. 이펙트는 위치를 바꾸지 않는다.
- 대상 키가 1.8 m 와 많이 다르면 kite 오프셋(3.0 m)과 tether target 오프셋을 같이 (키 + 1.2 m) 로 맞추면 된다 (scale 미사용).

## 시간표 (kite / tether 기준 t)
- 0.00 연 등장: 섬광 + 링 + 발밑 충격파 + 상승 줄기 버스트, 줄이 손→연으로 0.22 s 만에 그려짐
- 0.00–3.85 유지: 연(본체·먹빛 그림자·후광·작은 문양), 꼬리 리본, 허리 결박 룬 고리 2개(서로 반대 회전), 발밑 마법진, 상승 기류(토네이도 띠·먹빛 띠·발밑 소용돌이·상승 줄기·먹빛 파편·부유 입자)
- 줄: 흰 심선 + 연청 헤이즈 + 먹빛 실 + 펄럭이는 바람 실, 0.3 s부터 0.45 s 간격으로 당김 펄스(연→손)
- 3.85 연이 찢어짐: 섬광, 연 확대 소멸, 먹빛 파편·불꽃, 돌풍, 발밑 링 (대상 낙하 시점)

## 피해 권장 시점
- 걸리는 순간 t=0.05 (1회), 유지 중 당김 펄스가 손에 닿는 t ≈ 0.62 + 0.45·k (선택), 끝 t=3.85 (낙하 피해 선택)

## 런타임 입력
- attached: anchor/facing (시전자, 대상 각각) · link: source/target 매 프레임 · scale 없음
