# MoltenGrasp (쇳물 손) — 변환 메모

- 시스템: `main` 1개, role **static**. P = 대상(적)의 발 위치, local +Y 위, +Z = 시전자 수평 방향(서버 기준) = 내던지는 방향.
- 런타임 입력: `targetHeight` (SCENE.scale reference 1.8, min 0.7, max 2.2 — 배율). 손 크기 4.3 m (빌보드), 손 중심 높이 2.0 m.
- 시간표 (s): 0.0 화염 마법진 + 빛나는 균열 · 0.4 쇳물 웅덩이 끓음, 진동 불티 · **0.8 분출: 거대한 쇳물 손이 솟음(편 손)** ·
  1.3~1.55 손이 오므라듦(2x2 플립북) · **1.55 움켜쥠 = 붙잡기 시작(이동 불가)** · 1.9 / 2.4 쥐어짜기 펄스(지속 피해 틱) ·
  **2.9 내던지기: 주먹이 +Z 앞·위로 휘둘러짐 (넉백은 모드가 대상에게 적용)** · 3.3 주먹이 쇳물 파편으로 폭발(주먹 위치 약 (0, 3.0, 3.0) m) · 3.3~5.6 손목 기둥이 웅덩이로 무너지고 식음 · 6.0 종료.
- 피해 권장: 0.8 분출 피해, 1.55~2.9 속박 + 1.9/2.4 틱, 2.9 내던지기(넉백 +Z 위쪽), 3.3 공중 폭발(던져진 대상 근처) 피해.
- 손은 카메라를 향하는 빌보드(텍스처 3장: 편 손 / 쥐는 동작 2x2 / 주먹). 3D 메쉬 손은 아님 — 모든 각도에서 정면 실루엣으로 보인다.
