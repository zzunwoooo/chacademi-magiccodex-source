# SundialSweep (해시계 바늘) — 빛 중급, 변환 메모

- 시스템 1개: `main` (static, 3.2 s). P = 해시계 중심(바닥; 시전자 발밑 또는 지정 지점), +Z = 시전자 수평 방향. 반경 4.5 m.
- 시간표 (s): 0.0 해시계(고리·눈금·룬·태양 시길) 그려짐 · 0.55 빛 바늘이 정면(+Z)을 향해 솟음
  · **0.9~2.4 바늘이 한 바퀴(1.5 s, 4.19 rad/s) 돌며 쓸어 냄** — 위에서 볼 때 시계 방향: 정면 → 오른쪽 → 뒤 → 왼쪽 · 2.4 마무리 섬광(고리·시길 번쩍, 테두리 빛줄기, 충격파) · 3.2 끝.
- 피해 판정: 0.9~2.4 s, 바늘 각도 θ(t) = 4.19·(t − 0.9) rad (정면 기준 시계 방향) 를 지나는 적에게 1회. 마무리 2.4 s 에 추가 피해를 원하면 같은 반경 전체.
- 바늘 끝 별·궤적 호는 orbitalY = 바늘 회전 속도와 같은 값으로 돌아 바늘과 정확히 맞물림 (trails 사용).
- 런타임 입력: `areaRadius` (기준 4.5 m, 배율 0.6~1.5 → 반경 2.7~6.75 m). 시간은 반경과 무관.
