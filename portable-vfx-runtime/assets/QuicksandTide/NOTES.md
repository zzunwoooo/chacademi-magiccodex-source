# QuicksandTide (유사 파도) — 대지 고급

## 시스템 / 역할
- `main` (static, 3.8 s, loop 없음). P = 시전자 발 위치, 기준 방향 = 서버가 넘겨주는 시전자 수평 방향(+Z 정면). scale 없음(고정 크기).

## 시간표
| 시각 (s) | 연출 |
|---|---|
| 0.00 | 발밑 마법진(반경 1.7 m) 그려짐, 모래가 안쪽으로 모임 |
| 0.35 | 발사: 섬광·먼지 고리·발 앞 균열. 모래 파도(폭 5.2 m, 높이 ~1.2 m) 가 z=1 m 에서 출발 |
| 0.35–2.15 | 파도가 +Z 로 5.55 m/s 전진 (z=1 → 11 m). 마루 섬광선, 모래 물보라, 뒤로 처지는 모래/어두운 먼지 |
| 파도 통과 시 | 경로 위 유사 웅덩이 4개(소용돌이 모래 + 어두운 꺼짐 + 고리 + 빨려드는 알갱이)가 열려 3.35 s 까지 유지 |
| 2.15 | 파도 붕괴 (z=11 m): 섬광, 물보라, 어두운 먼지, 먼지 고리, 충격파, 돌 조각, 균열 |
| 3.8 | 종료 |

## 피해 권장 시점
- 적의 전방 거리 d(m) 에 대해 `t = 0.35 + (d − 1) / 5.55` s (파도 앞면 도달). 범위 끝(11 m) 붕괴 피해는 2.15 s.
- 발목 묻힘(이동 불가/감속)은 피격 순간부터 ~1.2 s 또는 3.35 s 까지. 웅덩이 4개는 고정 위치 연출(경로 위 대표 위치)이며 실제 적 위치를 따르지 않는다.

## 런타임 입력
- static: P(발 위치) + 시전자 수평 방향. 그 밖의 입력 없음.
