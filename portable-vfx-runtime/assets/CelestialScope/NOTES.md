## 피해 권장 시점
- 명중 즉시 (hit 시작 +0.0 s), 단일 대상 큰 피해 + 관통 없음.

## 런타임 입력
- attached: 발 위치 + 수평 방향(매 프레임). projectile/impact 일반 규칙. scale 없음.
- 조준경은 수평 방향만 따른다 (위아래 피치는 attached 규약에 없음 → 높은 곳을 조준해도 조준경은 수평 정면). 머리 부착(headAttach)은 클라이언트 미지원이라 쓰지 않았다.
