# WindmillBlades (풍차 날개) — 바람 중급 · 변환 메모

## 시스템 / 역할
- `main` — attached (시전자 발, +Z = 시전자 정면), loop 없음, duration 6.0 s (+ 잔상 ~0.5 s). 시전 순간 시작.
- 날개 3장 = 메쉬 1개(`blades`, 반경 0.8→2.2 m, 높이 약 1.0 m, 바깥쪽이 살짝 들리고 뒤 가장자리가 내려간 낫 모양), 회전 ω = 7 rad/s (약 1.1 회전/초).
  잔상 복사 2장(0.2 / 0.42 rad 뒤처짐) + 먹빛 그림자 + 앞날 선(edges). 5.9 s 에 같은 각도의 "날아감" 복사본으로 이어진다 (rot3 = ω·5.9).
- 날개는 시전자 몸 방향을 따라 함께 돈다 (attached local).

## 시간표
- 0.00 소환: 섬광, 공중 충격파, 돌풍, 바닥 충격파 / 날개가 0.35 s 동안 펼쳐짐
- 0.35–5.90 회전: 날개·잔상·앞날 선, 허브 룬 고리, 휩쓸기 호(밝은/먹빛), 공전 줄기, 끝에서 튀는 절삭 불꽃,
  0.45 s 부터 0.3 s 마다 날개 원 위 베기 섬광 2개 + 먹빛 파편, 바닥 마법진(6각 별)·룬 띠·중앙 문양·소용돌이·먹빛 안개·부유 입자
- 5.90 해산: 날개가 바깥으로 커지며 사라짐, 충격파, 방사 줄기, 작은 돌풍
