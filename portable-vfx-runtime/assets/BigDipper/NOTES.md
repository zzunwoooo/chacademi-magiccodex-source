# BigDipper (북두칠성) — 빛 / 고급

## 시스템
- `main` (static, 4.8 s, 54층) — P = 지정 지점(바닥), 기준 = 서버가 넘기는 시전자 수평 방향(+Z). 별자리 배치는 P 기준 로컬 좌표(x −5 ~ +2.4, z −1.6 ~ +1.6), 국자 머리(bowl) 중심 = 로컬 (1.0, 0, −0.6).

## 시간표
| 시각 | 내용 |
|---|---|
| 0.0–0.7 | 바닥 마법진(링·칠각성 {7/3}·룬 띠) |
| 0.3–2.6 | 하늘(8.5 m)에 북두칠성 별자리 (기울어진 선+별 표식) |
| 0.6 + 0.3k (k=0..6) | 별 k 가 하늘 별자리 꼭짓점에서 떨어짐 → 0.35 s 뒤 착지(충격 고리·별 낙인 유지) — 착지 0.95, 1.25, 1.55, 1.85, 2.15, 2.45, 2.75 s |
| 2.4–2.6 | 바닥 별자리 선이 밝아짐 |
| 2.6–3.3 | 별 국자(선·별·채움)가 기울어진 채 떨어지며 평평해짐, 국자 머리 아래 수축 고리(예고) |
| 3.3 | 내리찍기: 섬광·파동 2겹·god ray·7개 별 위 빛기둥·잉크/빛 파편·먼지 파동 |
| 3.3–4.8 | 잔광·별가루 |

## 피해 권장 시점
- 별 착지: 각 별 위치 반경 ~1.2 m, 위 시각 (0.95 + 0.3k s).
- 내리찍기: 3.3 s, 국자 머리 중심 반경 ~5.5 m (가장 큰 피해).

## 런타임 입력
