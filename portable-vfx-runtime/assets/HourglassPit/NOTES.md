# HourglassPit (모래시계 구덩이, 대지 중급) — 변환 메모

- 시스템 1개: `main` (static, 4.9 s, loop 없음, 40 layers). P = 지정 지점 바닥, 위 = +Y. 서버는 시전 시 1번만 시작 (단계 신호 없음).
- 런타임 입력: `areaRadius` (기준 3 m, 배율 0.6~1.67 → 반경 1.8~5 m). 마법진·소용돌이·모래 둔덕 전체가 같이 커지고 작아짐.
- 시간표 (s):
  - 0.0~0.6 바닥 마법진(반경 3 m, 육망성·룬 띠·모래시계 시길) 그려짐, 바닥이 어두워지고 금빛 균열
  - 0.4~3.0 모래 소용돌이가 안쪽으로 빨려 들어가며 3단계로 빨라짐(0.4 / 1.4 / 2.3) — 안의 적 둔화 연출. 중앙에 모래시계 모래 줄기가 3 m 위에서 쏟아짐
  - 2.6 예고(안쪽 고리 수축, 룬·육망성 섬광, 모래 결이 중심으로 모임)
  - **3.0 매몰 (피해 권장 시점 1)**: 모래 둔덕(깊이 쓰기 메쉬)이 솟아 안의 적을 허리까지 덮고 1 s 유지, 모래 기둥·모래 먼지·떨어지는 모래
  - **4.0 해방 (피해 권장 시점 2, 선택)**: 둔덕이 터지며 모래 폭발·광선·바위 조각(메쉬) 비산, 충격 고리 · 4.0~4.9 정리
- 둔화 단계(0.4~3.0)는 모드 로직이 맡고, 연출은 고정 타임라인. 매몰 1 s = 3.0~4.0.
- 바위 조각·둔덕은 `depthWrite` 재질(불투명 메쉬). 둔덕은 아래 바닥 마법진을 가림(의도).
- 클라이언트 비지원 필드 사용 안 함 (client_compat check OK).
