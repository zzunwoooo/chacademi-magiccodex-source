# MirrorPane (거울판) — 빛 중급, 변환 메모

- 시스템 3개
  - `pane` (static, 6.3 s, loop 없음): P = 시전자 앞 바닥 지점(권장 1.6 m 앞), +Z = 시전자 수평 방향(적 쪽). 거울판은 P 위 0.15~2.75 m, 폭 2.0 m, XY 평면(앞면 +Z).
  - `reflect` (impact, 0.3 s): 적 투사체가 거울판에 닿아 되돌아갈 때, 닿은 지점마다 1개. hitPoint = 판 위 접점, surfaceNormal = 되돌아가는 방향(보통 판의 +Z).
  - `refract` (impact, 0.3 s): 내 빛 탄이 판을 지나며 꺾일 때 1개. hitPoint = 접점, surfaceNormal = **꺾인 뒤의 새 진행 방향**(빛줄기가 +Y 로 뻗음).
- 시간표 (s): 0.0 바닥 원·빛 모임 · 0.35 판이 펼쳐짐(섬광+세로 파문) · 0.4~5.75 유지(테두리, 광택 4회 스윕, 뒤쪽 회전 룬 고리, 가장자리 반짝임, 먹빛 조각) · **5.75 금 가고 산산조각** · 6.3 끝.
- 거울판 지속시간 6초는 마법 설명 기준(중급 기준 1.5~4 s 보다 김). 반사/꺾기 판정은 0.4~5.75 s 사이 권장. 피해 없음(반사된 투사체의 피해는 모드).
- 런타임 입력: static 기본(P + 시전자 수평 방향), impact 기본(hitPoint, surfaceNormal, incomingDirection). scale 없음.
