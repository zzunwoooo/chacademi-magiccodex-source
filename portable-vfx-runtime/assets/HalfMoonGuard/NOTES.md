# HalfMoonGuard (반달 방패) — 변환 메모

**원소/등급**: 어둠 · 중급. 달빛 팔레트(흰 → 은백 → 라벤더 → 보라 → 남보라), 반투명 먹빛 막 + 밝은 테두리, 먹빛 초승달·잉크 파편 강조.

## 시스템 / 역할
| id | role | 길이 | 위치 | 시작 |
|---|---|---|---|---|
| `guard` | attached | 2.3 s | **시전자** 발 + 바라보는 방향(+Z 정면) | 시전 순간 |
| `absorb` | impact | 0.5 s | 정면 피해가 막에 닿은 지점 hitPoint, up = 공격자 쪽(막 바깥) 법선 | 막이 피해를 흡수할 때마다 1개 |
| `blade` | projectile | 비행 중 유지 (loop) | 시작점 = 시전자 + (0, 1.1, 1.1) (시전자 기준), 진행 방향 = 시전자 정면 | **guard + 2.12 s** (반격 발사) |
| `bladeHit` | impact | 1.3 s | 칼날이 맞은 곳 (바닥/벽 = 표면 법선, 엔티티·사거리 끝 = 공중 규칙) | 칼날 충돌 시 |

- 반달 막: 시전자 앞 0.93~1.15 m, 반지름 1.5 m 의 세운 반원(아치), 가운데가 앞으로 살짝 볼록. 정면 반원만 막는 판정과 모양이 맞도록 설계.
- 모은 피해 양에 따른 칼날 크기 변화는 없음(시각은 시간 기준 충전). 필요하면 모드가 `blade`/`bladeHit` 를 그대로 쓰고 피해량만 바꾸면 된다.

## 시간표 (guard 시작 기준)
- 0.00–0.25 바닥 반원 룬이 그려지고 반달 막(먹빛 막 + 빛 막 + 테두리 3겹 + 바닥선)이 아래에서부터 커짐, 0.10 가운데 초승달 문장(먹빛 + 빛)
- 0.25–2.0 막 표면 반짝임, 0.6 문장 주위를 도는 작은 초승달 4개, 0.45/0.9/1.4/1.8 빛줄기가 문장으로 모임(점점 많아짐), 충전 빛이 점점 밝아짐
- 피해 흡수 때마다 `absorb`: 물결 고리 2겹 + 섬광 + 불꽃 + 작은 초승달 (**막기 판정 순간 = absorb 0.00**)
- 2.00–2.14 막과 테두리가 문장 쪽으로 수축(예고), 수축 고리
- **2.12 반격**: 섬광 + 세로 고리 + 잉크 초승달·불꽃, `blade` 발사 (세운 반달 칼날 1.2 m + 먹빛 그림자 + 테두리선, 줄기·안개·입자 꼬리)
- `bladeHit` 0.00 섬광, 충격 고리, 반달 물보라, 초승달 파편(빛/먹빛), 불꽃, 잉크 파편, 안개 — **반격 피해 권장 시점 = bladeHit 0.00**

## 런타임 입력
- guard: 시전자 발 위치 + 수평 방향 (매 프레임)
- absorb / bladeHit: hitPoint, surfaceNormal, incomingDirection (공중: surfaceNormal = −incomingDirection)
- blade: 위치 + 진행 방향 (매 틱). 충돌 시 로컬 층 제거, 월드 층(꼬리) 방출 중지.
- scale 입력 없음.
