# ZodiacWheel (황도 12궁) — 빛 종결 마법, 변환 메모

- 시스템 1개: `main` (static, 11.8 s, loop 없음, 96 layers). P = 대상 지점 바닥, 위 = +Y, 서버가 주는 시전자 수평 방향 기준(별자리 그림은 시전자 쪽을 향하는 세로 평면).
  서버는 시전 시 1번만 시작 (단계 신호 없음).
- 크기: 기준 바닥 마법진 반경 8 m, 황도 고리 반경 9 m·높이 14 m. 런타임 입력 `areaRadius` (기준 8 m, 반경 4~11 m = 배율 0.5~1.375). 연출 전체(높이 포함)가 같은 배율로 커지고 작아짐.
- 시간표 (s):
  - 0.0 바닥 마법진 · 0.4 밤하늘(장막·안개·청백 별) · 0.9 황도 고리 펼쳐짐 · 1.4 고리 중심 태양 시길·코로나 · 1.8 태양 빛기둥
  - 2.4 ~ 6.8 별자리 12개가 0.4 s 간격으로 점등 → 각자 별빛 창을 바닥으로 발사. **착탄 k = 2.65 + 0.4·k (k=0..11), 별자리 피해 권장 시점**
  - 7.4 붕괴 예고 (고리·마법진 점등, 빛 모임) · **8.2 고리 붕괴: 빛 기둥 낙하 + 기둥 12개 + 태양 폭발 (1차 큰 피해)**
  - **8.75 고리가 바닥에 내리꽂힘: 12각 별 폭발·수평 광선·충격파 (2차 큰 피해)** · 8.9 ~ 11.8 별똥비·잔불·시길 잔상
- 착탄 지점(P 기준, m): 별자리 k 의 목표 = (cos(2.399k)·r, 0, sin(2.399k)·r), r = 1.6 + 1.35·(k mod 4).
- 회전 층의 섬광 사본은 rotation3D 를 ω·(시작−기준) 으로 맞춤. 낙하 고리(Y01/Y02)는 linear 속도로 0.5 s 에 14 m 이동.
- 클라이언트 지원 기능 안 (client_compat check OK). 고유 텍스처 RGBA 1.9 MiB.
