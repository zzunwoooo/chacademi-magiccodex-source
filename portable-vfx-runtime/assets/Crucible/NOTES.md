# Crucible (도가니 붓기) — 변환 메모

- 시스템: `main` 1개, role **static**. P = 대상(적)의 발 위치, local +Y 위, +Z = 시전자 수평 방향(서버 기준).
  도가니는 대상 뒤(시전자 쪽, z = −2.76 m), 높이 7.6 m 에 생겨 +Z 쪽(대상 쪽)으로 기울어 주둥이가 대상 바로 위(약 6.1 m)에 온다.
- 런타임 입력: `targetHeight` (SCENE.scale reference 1.8, min 0.75, max 2.0 — 배율, 전체가 P 기준으로 함께 커짐).
- 도가니 = 회전체 메쉬(외벽, 철 텍스처, alpha) + 내부 쇳물 면(메쉬). 단계별 사본: 등장(0.3, 위에서 내려와 자리잡음) → 기울기(1.2~1.9, X축 1.05 rad) → 유지(1.9~4.6) → 바로 서며 사라짐(4.6~5.3).
- 시간표 (s): 0.0 대상 아래 마법진 + 하늘 마법진 · 0.3 도가니 등장 · 1.2~1.9 기울어짐 · 1.75 첫 쏟음 · **2.2~4.6 쇳물 줄기가 대상에 쏟아짐(튀김, 웅덩이 확장, 불길, 증기) = 지속 피해** ·
  4.6 붓기 끝 · **5.2 웅덩이 분출(폭발) = 마무리 피해** · 6.6 종료.
- 피해 권장: 2.2~4.6 s 매 0.3~0.5 s 틱(대상 반경 1.2 m), 웅덩이 반경 2.3 m 화상, 5.2 s 분출 피해(반경 2.4 m).
- 쇳물 줄기 = 교차 사각형 메쉬 + 2x2 흐름 플립북(flipbookCycles).
- 고유 텍스처 RGBA: 2.46 MiB. client_compat check: OK (fix 0 change).
