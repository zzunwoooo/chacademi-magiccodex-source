# LunarMark (달빛 표식) — 변환 메모

**원소/등급**: 어둠 · 중급. 팔레트 흰 → 은백 → 라벤더 → 보라 → 남보라 (만월 강림 계열), 먹빛 초승달·잉크 파편 강조.

## 시스템 / 역할
| id | role | 길이 | 붙는 곳 | 시작 |
|---|---|---|---|---|
| `mark` | attached | 4.0 s | **대상(TARGET)** 발 위치 + 대상 몸 방향 | 표식이 붙는 순간 (t = 0) |
| `strike` | attached | 1.5 s | 같은 대상 | **표식 + 4.0 s** (모드가 달빛 피해를 줄 때 시작) |

- 둘 다 대상에 붙는다 (CharcoalConversion 과 같은 규칙): 대상이 움직이면 표식·달·빛기둥이 따라간다.
- 대상이 4초 안에 죽거나 사라지면: `mark` 정지(로컬 층 제거), `strike` 시작 안 함.
- 표식 지속 시간이 설정으로 바뀌면 `strike` 는 그 시점에 시작하면 되지만, `mark` 의 카운트다운 점(1초마다 1개, 4개)·달 등장(3.0 s)·조임(3.4 s)은 4초 기준으로 구워져 있다.

## 시간표 (mark 시작 기준)
- 0.00 바닥 달 위상 봉인진(링·6각 별·꼭짓점 원·룬 띠·위상 문양)이 그려지며 회전, 머리 위 초승달 낙인(먹빛 + 빛 + 코로나) 등장, 카운트다운 점 #1
- 1.00 / 2.00 / 3.00 카운트다운 점 #2 / #3 / #4 + 바닥 봉인 맥동, 0.2/1.2/2.2/3.2 몸을 타고 오르는 스캔 고리
- 3.00 대상 머리 위 5.6 m 에 작은 달 등장 (먹빛 그늘 + 코로나)
- 3.35–4.0 빛줄기가 안쪽으로 모이고 바닥 충격 고리가 수축(예고), 3.4 달 → 대상 안내선
- 4.00 = `strike` 0.00: 달 섬광, 빛이 낙하 (0.00–0.12)
- **4.12 = strike 0.12: 착탄 — 피해 권장 시점** (섬광 ≤ 0.24 s, 충격 고리 2개, 코로나 파동, 공중 고리, 봉인 플레어, 초승달 파편 빛/먹빛, 잉크 파편, 불꽃, 리본 호, 안개 파동)
- 4.12–5.5 기둥이 사라지며 미광·먼지 상승

## 런타임 입력
- attached: 대상 발 위치 + 몸 방향 (매 프레임)
- `scale.input = targetHeight` (reference 1.8, min 0.6, max 2.5): s = clamp(대상 키 / 1.8, 0.6, 2.5). 달 높이·기둥 길이도 같이 비례.

## 클라이언트 호환
