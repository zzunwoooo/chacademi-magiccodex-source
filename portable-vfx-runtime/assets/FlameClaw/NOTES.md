# FlameClaw (불꽃 손톱, 화염 초급) — 변환 메모

- 시스템 2개
  - `claw` (attached → 시전자, 0.4 s, 13 layers): P = 시전자 발, +Z = 시전자 수평 정면. 시전 시 시작.
    - 0~0.1 손에 불씨가 모이고 손톱 끝 3개 반짝 · 0.04~0.34 세 갈래 불꽃 손톱이 오른쪽 위 → 왼쪽 아래로 할퀴며 그려짐(시전자 앞 1.15 m 수직면)
    - **0.16 손톱이 대상을 지나감 (피해 권장)**: 뜨거운 손톱 자국 + 어두운 상처 자국, 섬광, 불티·불혀·불꽃·불씨·연기
  - `burn` (attached → **맞은 대상**, 1.6 s, 6 layers): P = 대상 발, +Z = 대상 수평 정면(데모에선 시전자 쪽). **명중 시점(시전 후 약 0.16 s)에 서버가 대상마다 시작.** 가슴 높이 세 줄 화상 자국 + 몸을 핥는 불꽃·불씨·연기 (짧은 화상, 1.5 s).
- 피해: 0.16 s 1회 + 화상 틱(0.2~1.5 s) 선택.
- 런타임 입력: 없음 (scale 사용 안 함; 큰 대상에서도 몸 불꽃은 1.8 m 기준 박스).
