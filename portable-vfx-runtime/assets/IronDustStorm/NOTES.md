# IronDustStorm (쇳가루 폭풍) — 대지 고급

## 시스템 / 역할
- `main` (static, 4.2 s). P = 지정 지점(바닥). 기준 방향 무관.
- SCENE.scale `areaRadius` (reference 4 m, 배율 min 0.6, max 1.6 → 반경 2.4–6.4 m).

## 시간표
| 시각 (s) | 연출 |
|---|---|
| 0.0 | 마법진(반경 4 m) 그려짐, 바깥에서 쇳가루·빛줄기가 빨려 들어옴 |
| 0.4–3.4 | 폭풍 3 s: 회전하는 모래 장막 2겹, 쇳조각(어두운 몸체 + 금빛 테두리) 두 높이로 공전, 어두운/금빛 줄기, 회전 띠, 반짝임, 가운데로 당기는 줄기 |
| 0.75–3.06 | 충돌 연출: 0.33 s 간격 8회, 안쪽 무작위 위치에 섬광 + 불꽃 + 작은 고리 |
| 3.4 | 해산: 섬광, 쇳조각·줄기·먼지가 바깥으로 튐, 충격파·먼지 고리·마법진 섬광·균열 |
| 4.2 | 종료 |

## 피해 권장 시점
- 0.4–3.4 s 동안 0.33 s 간격(0.75, 1.08, … 3.06 s) 충돌 피해 (안의 적끼리 부딪힘), 마지막 3.4 s 해산 피해(선택).
- 충돌 섬광 위치는 무작위 연출 — 실제 충돌 위치와 맞출 필요 없음.

## 런타임 입력
- static: P + areaRadius.
