# DeepTentacles (심해 촉수) — 물 · 비전

## 시스템 / 역할
- `main` — **static** 1개. P = 지정 지점(바닥), local +Y = 위, +Z = 시전자 수평 방향. 저작 반경 4 m, `scale = {input:"areaRadius", reference:4, min:0.5, max:1.6}`.
- 촉수 4개 위치(고정): P + 2.2 m·(cos a, 0, sin a), a = 45°, 135°, 225°, 315°. 촉수 = 관(tube) 메쉬(높이 ≈ 5 m), 가산 물빛 몸체 + 짙은 심해 속심(알파).

## 시간표 (s)
| 시각 | 연출 |
|---|---|
| 0.0–0.8 | 심연이 열림: 짙은 웅덩이, 심해 문장(촉수 나선), 안쪽으로 모이는 파문 3번, 소용돌이 2겹, 기포, 먹빛 안개 |
| 0.8 / 0.88 / 0.96 / 1.04 | 촉수 4개가 차례로 솟음(살짝 넘침), 각 위치 물보라 + 물줄기, 섬광 + 충격 |
| 1.1–4.1 | 촉수가 제자리에서 서로 반대 방향으로 휘감듯 휘두름(약 2.2–2.7 rad/s), 끝 반짝임, 떨어지는 물 |
| 1.6 / 2.4 / 3.2 | 강타 물결: 촉수마다 휘두름 물살 호, 물방울 투척, 바닥 내리침 충격 + 물보라 링 |
| 4.1–4.5 | 촉수가 가라앉음, 4.45 물보라 붕괴 |
| 4.5 | 웅덩이 닫힘(수렴 고리) → 5.0 중앙 물기둥 + 섬광 + 물방울 |
| 5.2 | 종료 |

## 피해 권장 시점
- 0.8–1.04 솟을 때 각 촉수 반경 1.2 m 피해(띄우기).
- **1.75 / 2.55 / 3.35 s** 휘두름 피해(반경 4 m 전체, 강타 물결 착지 +0.15 s).
- 5.0 s 마무리 물기둥(선택, 작게).

## 런타임 입력
- static: P + 수평 방향(대칭이라 영향 적음) + `areaRadius`.
