# SkyMill (천공의 방아) — 바람 종결 마법, 변환 메모

- 시스템 1개: `main` (static, 12.0 s, loop 없음, 81 layers). P = 대상 지점 바닥, 위 = +Y, +Z = 시전자 정면 (풍차 바퀴는 XY 면 → 시전자 쪽을 향함). 서버는 시전 시 1번만 시작.
- 런타임 입력: `areaRadius` (기준 8 m, 4~11 m). 마법진·풍차 높이/크기·충격파 전체가 같이 커지고 작아짐.
- 시간표 (s):
  - 0.0 바닥 마법진(반경 8 m) · 0.3 폭풍 하늘(소용돌이 구름, 어두운 장막) · 0.8 거대 풍차 바퀴(반지름 7 m, 날개 8장)가 20 m → 11.5 m 로 강하 (2.8 도착)
  - 2.8~8.0 바퀴 회전 가속 (0.5 → 0.9 → 2.0 → 4.5 rad/s, 단계마다 같은 각도에서 이어받는 사본) · 3.0~8.0 바닥 바람 날개 8장이 전장을 갈아냄, 바람 줄기·먼지·먹빛 파편이 점점 빠르게 공전
  - 7.2 중앙 회오리 형성·흡입 · **8.0 띄워 올리기 (1차 피해 권장 시점: 적을 위로 띄움)**
  - 8.8 바퀴가 허브로 접혀 사라짐 · **9.0 내리꽂기 (2차 피해 권장 시점: 위에서 압력 창이 떨어지며 반경 45 m 충격파)** · 9.2~12.0 잔풍·먼지 가라앉음.
- 회전 단계 사본은 rotation3D Z 를 누적 각도로 맞춰 둠 (끊김 없이 가속하는 것처럼 보이게). 바닥 날개 2단계도 같은 방식 (Y 축).
- 미리보기 전용: 카메라에서 멀리 떨어진 큰 물체가 사라지는 미리보기 현상 때문에 전체 카메라를 23 m 로 둠 (게임 렌더와 무관).
- 모든 항목이 클라이언트 지원 기능 안 (client_compat check OK). 고유 텍스처 RGBA 2.5 MiB.


- 2026-10-30 수정: `scale.min/max` 는 반경(m)이 아니라 배율(SCHEMA §5.3)이므로 0.5~1.375 배로 고침 (반경 4.0~11.0 m). 이전 값(m 단위로 적은 3.5~10 등)은 모든 시전을 3.5배 이상 크게 만들던 오류.
