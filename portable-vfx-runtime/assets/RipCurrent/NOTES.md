# RipCurrent (이안류) — 물 · 고급

## 시스템 / 역할
- `main` — **static** 1개. P = 시전자 발 위치, **+Z = 서버가 넘기는 시전자 수평 방향**(해류 진행 방향). 해류 폭 3 m, 길이 14 m (z 0.6 → 14).
- 크기: `scale = {input:"areaRadius", reference:14, min:0.5, max:1.4}` — 여기서 areaRadius 는 **해류 길이(m)** 로 넘긴다 (폭도 같은 비율로 커짐).

## 시간표 (s)
| 시각 | 연출 |
|---|---|
| 0.0 | 시전자 앞 1.2 m 에 작은 물 마법진 |
| 0.3 | 해류 분출: 물보라 + 섬광 + 충격 고리 |
| 0.3–1.2 | 물마루(높이 ≈ 2 m 파도 벽, 앞면 빛 + 뒷면 짙은 물) 가 z 1 → 14 m 를 0.9 s 에 달림 (속도 14.4 m/s), 물보라·물줄기 동반 |
| 0.3–2.4 | 해류 유지: 짙은 물 바닥 + 흐르는 물빛 띠 + 흐르는 물살(스트로크 플립북) + 빠른 물줄기 + 거품 + 양옆 물보라 + 먹빛 안개 + 테두리 선 |
| 0.9–2.4 | 끝(z 14)에서 소용돌이 3겹 회전, 수렴 파문, 회전 물줄기 |
| 2.4 | 소용돌이가 물기둥으로 터짐(섬광, 충격, 물방울, 물줄기) |
| 3.2 | 종료 |

## 피해 / 끌기 권장
- 물마루가 지나갈 때(적 위치 z → t ≈ 0.3 + (z − 1)/14.4 s) 피해 + 해류에 붙잡음.
- 붙잡힌 적은 2.4 s 까지 +Z 로 끌어 끝점(z 14)으로 이동, **2.4 s 끝점 물기둥 피해**.

## 런타임 입력
- static: P + 수평 방향(필수, +Z 정면) + `areaRadius`(= 해류 길이).
