# FossilWyrm (화석 뱀뼈) — 대지 고급

## 시스템 / 역할
- `main` (static, 3.4 s). P = 시전자 발 위치, +Z = 시전자 수평 방향. scale 없음.
- 뱀뼈 = 해골(stretched billboard) + 척추뼈 사슬. 척추뼈는 같은 지점·같은 속도로 0.04 s 간격으로 하나씩 생성되어 해골과 똑같은 포물선을 뒤따른다(트레일 대신 결정적 사슬, 클라이언트 구현 차이 없음). 뱀뼈 입자들은 world 공간.

## 시간표
| 시각 (s) | 연출 |
|---|---|
| 0.0 | 발밑 마법진(1.5 m), 정면으로 빛나는 균열선(z 1→13 m)이 뻗고 갈라진 땅 5개가 차례로 생김 |
| 0.5 | 분출 (z=2 m): 섬광, 돌, 모래/어두운 먼지, 먼지 고리, 충격파 |
| 0.5–1.83 | 뱀뼈가 z=2 → 12.7 m 로 돌진, 최고 높이 ~1.9 m (vel z 8, y 7, gravity 1) |
| 0.875 / 1.25 / 1.625 | 물어뜯기: z = 5 / 8 / 11 m 에서 송곳니 섬광 + 파편 + 불꽃 |
| 1.83 | 땅속으로 잠수 (z≈12.7 m): 큰 분출 + 균열 |
| 3.4 | 종료 |

## 피해 권장 시점
- 전방 거리 d(m) 의 적: `t = 0.5 + (d − 2) / 8` s (머리 통과). 대표 물기 시점 0.875 / 1.25 / 1.625 s, 끝 분출 1.83 s.

## 런타임 입력
- static: P + 시전자 수평 방향. 그 밖의 입력 없음.
