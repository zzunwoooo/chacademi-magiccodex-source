# RainBarrage (폭우) — 물 · 고급

## 시스템 / 역할
- `main` — **static** 1개. P = 지정한 구역 중심(바닥), local +Y = 위. 서버가 넘기는 시전자 수평 방향 기준(방향성 없음).
- 크기: `scale = {input:"areaRadius", reference:5, min:0.5, max:1.6}` → s = clamp(반경/5, 0.5, 1.6). 저작 반경 5 m.

## 시간표 (s, 시스템 시작 = 0)
| 시각 | 연출 |
|---|---|
| 0.0–0.8 | 바닥 마법진(팔각 성형·룬띠·물방울 문장) 그려짐, 10 m 위 먹구름 + 출렁이는 '물의 천장'(물결 빛 면 2장) + 하늘 고리진이 열림 |
| 0.55 | 첫 빗방울 |
| 0.8 | 폭우 시작(하늘 섬광 + 하늘 충격파, 마법진 플레어) |
| 0.8–6.8 | 굵은 빗줄기 6 s (흰 줄기 + 가는 줄기 + 먹빛 줄기 + 경계 장막). 바닥: 물보라 왕관, 파문, 튀는 물방울, 반짝임, 물웅덩이 물빛, 낮은 물안개 |
| 2.2 / 3.7 / 5.2 | 큰 물결(빗줄기 증가) → +0.38 s 착수 시 바닥 충격 고리 + 경계 물보라 링 |
| 6.2 | 마지막 폭우(최대) → 6.58 착수 시 빛기둥 + 섬광 + 충격 |
| 6.8 | 비 그침, 구름 흩어짐, 물방울 입자 상승 |
| 7.6 | 종료 |

## 피해 권장 시점
- 0.8 + 0.38 = **1.18 s 부터 6.8 s 까지 0.5 s 간격** 구역 안 적에게 피해 (빗방울 착수 기준).
- 강타 틱(선택): 2.58 / 4.08 / 5.58 / 6.58 s (큰 물결 착수).

## 런타임 입력
- static: 위치 P + 수평 방향(방향 영향 없음), `areaRadius`.
