# BellowsBlast (풀무질, 화염 초급) — 변환 메모

- 시스템 1개: `blast` (attached, 0.6 s, 15 layers). P = 시전자 발, +Z = 시전자 수평 정면. 시전 시 1번 시작. 손 위치(앞 0.55 m, 높이 1.2 m)에서 앞으로 원뿔(길이 약 5 m, 좌우 ±30°) 열풍.
- 시간표: 0~0.15 공기를 손으로 빨아들임(소용돌이·당겨지는 선·손 불빛) · **0.15 분출 (피해·밀치기 시작 권장)** · 0.15~0.55 열풍 지속(동심 바람 고리 3겹, 회전 바람 호, 불꽃 분사, 열 선, 재·연기·불씨, 바닥 먼지) · 1.2 잔연기 끝.
- 피해/넉백: 0.15~0.5 s 원뿔 안 대상 (한 번만 맞히려면 0.2 s 기준).
- 런타임 입력: 없음 (scale 사용 안 함).
