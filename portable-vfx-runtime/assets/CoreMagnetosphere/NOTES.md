# CoreMagnetosphere (지핵 자기장) — 대지 종결 마법, 변환 메모

- 시스템 1개: `main` (static, 12.4 s, loop 없음, 86 layers). P = 대상 지점 바닥, 위 = +Y. 서버는 시전 시 1번만 시작 (단계 신호 없음).
- 런타임 입력: `areaRadius` (기준 7 m, 3.5~10 m). 마법진·자력선·구체 높이·충격파 전체가 같이 커지고 작아짐.
- 시간표 (s):
  - 0.0 바닥 균열이 달아오르고 자기 마법진(반경 7 m) 그려짐 · 0.3 하늘이 잿빛으로 어두워짐(재 구름·재 낙하)
  - 0.6~2.4 땅속 지핵 맥동 4회 · 1.2 금빛 자력선 24가닥 솟음(두 겹, 반대 회전) · 1.8~7.6 바위가 뜯겨 나와 나선을 그리며 위로 빨려 올라감
  - 2.6 지핵 분출 빛기둥 → 3.0 높이 9 m 에 바위·용암 구체 형성 (자이로 고리 3개, 궤도 파편)
  - 7.7 예고 (자력선·마법진 점등, 파편 흡입) · 8.2 구체 내리꽂기 시작 (자력선 수축)
  - **8.55 착지 폭발 (중심 높이 1.6 m, 1차 피해 권장 시점)** · **9.15 전장 곳곳 용암 간헐천 분출 + 2차 충격파 (2차 피해 권장 시점)** · 9.5~12.4 연기·불씨·식어가는 균열.
- 구체는 같은 회전의 두 사본: 유지(3.0~8.2) → 낙하(8.2~8.55, gravityModifier ≈ 4.9, 고정 스텝 계산으로 정확히 1.6 m 도착).
- 바위는 depth 를 쓰는 단단한 메쉬 (rockgen.py 로 만든 ROCK_MESH/CHUNK_MESH, T_Rock 아틀라스). 떠오르는 바위는 orbital + radial + linear 로 9 m 의 구체 쪽으로 모이고 끝에 크기 0 으로 흡수됨.
- 회전하는 층의 점등 사본은 rotation3D 를 ω·(시작−기준) 으로 맞춰 둠.
- 모든 항목이 클라이언트 지원 기능 안 (client_compat check OK). 고유 텍스처 RGBA ≈ 3.97 MiB (검사기 5.2 MiB 는 재질별 중복 집계).


- 2026-10-30 수정: `scale.min/max` 는 반경(m)이 아니라 배율(SCHEMA §5.3)이므로 0.5~1.429 배로 고침 (반경 3.5~10.0 m). 이전 값(m 단위로 적은 3.5~10 등)은 모든 시전을 3.5배 이상 크게 만들던 오류.
