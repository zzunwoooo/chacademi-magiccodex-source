# MagnetPalm (자석 손, 대지 중급) — 변환 메모

- 시스템 1개: `cast` (attached, 1.75 s, loop 없음, 26 layers). P = 시전자 발 위치, +Z = 시전자 수평 정면. 매 프레임 시전자를 따라감.
- 손 위치(마법진 중심) = 로컬 (0, 1.25, 0.8). 끌어오는 범위 연출은 정면 약 1.5~5.5 m.
- 시간표 (s):
  - 0.0~0.3 충전: 손 앞에 세로 자석 시길 + 고리 + 룬 띠, 손 주변 리본 소용돌이, 빛 결이 손으로 모임
  - 0.3~1.2 **끌어오기 (끌어당김 판정 구간)**: 자기력선 리본이 손 쪽으로 오그라들고(반복), 수축하는 고리가 앞쪽 4 m 에서 손으로 다가옴(0.22 s 간격),
    모래 알갱이·쇳가루(어두운 줄)·조약돌·바닥 먼지가 손으로 빨려 듦, 앞쪽 바닥 금빛 균열
  - **1.2 결착 (피해 권장 시점)**: 섬광, 세로 충격 고리 2겹, 광선, 모래 폭발, 쇳덩이 조각(메쉬) 튀김, 앞쪽 바닥 충격 고리 · 1.2~1.75 잔광
- 적을 끌어오는 이동은 모드가 맡음 (연출은 시전자 기준 고정). 0.3 시작 시 끌어오기 시작, 1.2 에 피해 권장.
- 바위(쇳덩이) 조각은 `depthWrite` 재질. 클라이언트 비지원 필드 사용 안 함 (client_compat check OK).
