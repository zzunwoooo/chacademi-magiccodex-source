# GustPalm (돌풍 장타) — 바람 초급, 변환 메모

## 시스템 / 역할
| id | role | duration | 시작 |
|---|---|---|---|
| `strike` | attached — **시전자** (발 위치 + 수평 방향) | 0.2 s (보이는 ~0.45 s) | 시전 t=0 |
| `knock` | attached — **맞은 적** (적 발 위치, 방향 = 넉백 방향 = 시전자→적 수평 방향) | 0.5 s (보이는 ~0.9 s) | 손바닥 접촉 순간 (미리보기 0.1 s) |

- `knock` 의 로컬 +Z 는 적이 날아가는 방향(시전자에서 멀어지는 쪽). 적의 바라보는 방향이 아니다 — 시전 시 고정해서 넘긴다.
- 적이 3블록 날아가는 동안 `knock` 이 적 발 위치를 따라가며 월드 공간 꼬리(바람 줄기·말림·빛 입자·먹빛 조각, rateOverDistance)를 남긴다. 미리보기: 0.45 s 에 3 m.
- 착지 연출(`K11/K12`)은 넉백 시작 +0.42~0.45 s 에 고정. 실제 착지가 더 늦으면 그 두 층만 착지 시점에 맞춰 늦추면 된다.

## 시간표
- 0.00 발밑 고리 + 앞쪽 갈매기 표시, 손에 바람 소용돌이
- 0.06 손바닥 문양(바람 손자국) 펼쳐짐 → 0.08 섬광, 손바닥 파동이 앞으로 밀려남, 압력 고리 3개(0.08/0.12/0.16) 앞으로 날아감, 원뿔 바람 줄기 18개, 먹빛 조각
- 0.10 (knock 0.00) 적 몸에 섬광 + 손바닥 자국 + 뒤로 뚫고 나가는 충격 고리 2개 + 관통 줄기 22개 + 먹빛 조각
- 0.10~0.55 적이 날아가는 길을 따라 바람 꼬리
- 0.52~0.55 (knock 0.42~0.45) 착지 충격 고리 + 미끄러지는 먼지 줄기

## 피해 권장 시점
- 손바닥 접촉 순간 1회 (`knock` 시작 = 시전 +0.1 s) 와 동시에 넉백 3블록.

## 런타임 입력
- strike: 시전자 발 위치 + 수평 방향 (매 프레임). knock: 적 발 위치 (매 프레임) + 넉백 수평 방향 (시작 시 고정). scale 없음.
