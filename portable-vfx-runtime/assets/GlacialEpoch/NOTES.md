# GlacialEpoch (영겁의 빙하) — 물(얼음) 종결 마법, 변환 메모

- 시스템 1개: `main` (static, 11.8 s, loop 없음, 83 layers). P = 대상 지점 바닥, 위 = +Y. 서버는 시전 시 1번만 시작 (단계 신호 없음).
- 런타임 입력: `areaRadius` (기준 15 m). scale min 0.55 / max 1.35 → 실제 반경 약 8~20 m. 연출 전체(마법진·빙하 기둥·하늘)가 같이 커지고 작아짐.
- 시간표 (s):
  - 0.0 얼음 마법진(반경 15 m) 그려짐 · 0.3 하늘 변화(남색 장막·눈보라·오로라 커튼·높은 안개)
  - 0.7~2.7 결빙 확산: 서리판 + 균열 빛 + 서리 가시 전선 + 냉기 안개가 15 m 까지 퍼짐 (빙결/둔화 판정 권장 구간)
  - 2.9 / 3.5 / 4.2 빙하 기둥 솟음 (안쪽 6군 → 바깥 9군 → 중앙 첨탑 12.5 m). 기둥은 depth 를 쓰는 단단한 결정 메쉬(정확한 drag 상승, 위치 고정)
  - 4.5~7.3 동결 유지: 기둥을 타고 오르는 빛, 반짝임, 눈보라
  - 7.3 예고: 기둥·균열 점등, 하늘 12 m 에 거대 눈꽃 표식, 빛이 안으로 빨려듦, 바닥 고리 수축
  - **8.0 산산조각 (1차 피해 권장 시점)**: 모든 기둥이 파편·결정 조각으로 폭발, 섬광, 빛줄기, 충격파 2겹(최대 약 50 m)
  - **8.75 절대영도 (2차 피해 권장 시점)**: 눈꽃 표식이 내리꽂히고(8.55 낙하 시작) 바닥 눈꽃 섬광 + 서리 칼날 고리 + 사방 얼음 가시 + 충격파
  - 8.9~11.8 다이아몬드 더스트, 낮은 안개, 서리 소멸.
- 기둥 메쉬는 고정 시드로 만든 3묶음(glA/glB/glC). 깨질 때 조각은 무작위 위치로 퍼지는 근사(기둥 위치와 1:1 대응 아님).
- 모든 항목이 클라이언트 지원 기능 안 (client_compat check OK). 고유 텍스처 RGBA 3.77 MiB (검사기 5.8 MiB 는 같은 텍스처를 재질마다 중복 집계한 값).
