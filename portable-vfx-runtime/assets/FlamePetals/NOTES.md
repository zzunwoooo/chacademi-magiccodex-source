# FlamePetals (화염 꽃잎) — 화염 중급

## 시스템 / 역할
- `bloom` (attached, 1.6 s, 34층): 시전자 발 위치 + 수평 방향을 따라감(로컬 층은 같이 움직임). 꽃잎 높이 1.1 m(가슴).
- 꽃잎 8장 = 장마다 2층(나감 / 돌아옴). 모두 궤도 회전(orbitalY 2.2 rad/s) + 반경 속도(radial)로 소용돌이 궤적, trails 사용.

## 시간표
| 시각(s) | 내용 |
|---|---|
| 0.00–0.15 | 가슴 앞 불꽃 봉오리 모임, 발밑 꽃 문양 마법진(팔망성·룬 띠) |
| **0.15** | 개화 섬광 + 불꽃 파동 → 꽃잎 8장 45° 간격으로 출발 |
| 0.15–0.65 | 반경 0.45 → **4.0 m** 로 소용돌이치며 퍼짐 (범위 고리가 같이 커짐), 길에 불티·숯·불꽃·연기 |
| 0.65–1.20 | 다시 소용돌이치며 시전자에게 돌아옴 |
| 1.20 | 흡수 섬광 + 모이는 고리, 불티 상승 |
| 1.6 | 종료 |

## 피해 권장 시점
- 나가는 길 0.15–0.65 s, 돌아오는 길 0.65–1.20 s (반경 4 m 원 안, 같은 적은 왕복 최대 2회 권장). 판정 높이 0.3–2 m.

## 메모
- 꽃잎 각도 k·45°(시전자 기준), 시각 t 의 각도 = k·45° + 2.2·(t − 0.15) rad (위에서 볼 때 반시계).
- client_compat check: OK. 고유 텍스처 RGBA ≈ 1.72 MiB.
