# DipolePrison (쌍극 감옥) — 대지 비전

## 시스템 / 역할
- `main` (static, 6.2 s). P = **대상의 발 위치**, 기준 방향 = 시전자 수평 방향(+Z). 기둥은 대상 좌우(±X 2.6 m)에 선다.
- scale 없음(고정 크기: 기둥 간격 5.2 m, 높이 2.3 m).

## 시간표
| 시각 (s) | 연출 |
|---|---|
| 0.0 | 대상 밑 마법진(반경 3.4 m) + 양쪽 기둥 자리 작은 마법진 |
| 0.35–0.9 | 자철 기둥 2개가 솟음(돌·먼지), 0.85 s 기둥 머리 극(N 금색 / S 주황-적색) 점등 |
| **0.95** | **자기장 가동**: 섬광 + 세로 고리, 두 극 사이에 흐르는 자기력선 새장 4겹이 X축(극을 잇는 축, 높이 2.15 m) 둘레로 회전 |
| 0.95–5.0 | 감금 유지: 대상 둘레 회전 고리·룬 띠, 떠오르는 입자, 쇳가루 공전, 극 사이 불꽃, 발밑 그림자 |
| 4.6–5.0 | 예고: 수축 고리 |
| **5.0** | **자기장 붕괴**: 섬광, 새장 섬광, 충격파, 빛줄기, 쇳가루 폭발, 기둥 무너짐(돌·먼지) |
| 6.2 | 종료 |

## 피해 / 상태 권장
- 0.95 s 부터 5.0 s 까지 대상을 공중(발 0.6–1.0 m 정도)에 띄워 고정 — 실제 띄우기는 모드가 처리(연출은 대상 이동을 하지 않음). 필요 시 5.0 s 해제 피해.

## 런타임 입력
- static: P(대상 발) + 시전자 수평 방향.
