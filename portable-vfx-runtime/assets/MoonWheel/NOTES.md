# MoonWheel (월광 회전륜) — 어둠 비전, 변환 메모

- 시스템 1개: `wheel` (attached, 6.4 s, loop 없음, 45 layers). P = 시전자 발 위치, +Z = 시전자 수평 방향. 시전자를 따라 이동 (local 공간). 시전 시 1번만 시작.
- 런타임 입력: `areaRadius` (기준 2.0 m = 칼날 회전 반경, 배율 0.6~1.6).
- 시간표 (s):
  - 0.0 발밑 마법진(반경 2.7 m), 허리 높이로 빛이 모임 · **0.35 소환 섬광: 칼날 8개 + 먹빛 그림자 + 리본 꼬리 펼쳐짐 (피해 판정 시작 권장)**
  - 0.35~6.0 회전륜: 칼날 8개(반경 2 m, 높이 1.05 m, 바깥으로 기운 초승달 칼날)가 7 rad/s(약 1.1 바퀴/s)로 회전, 반대로 도는 허브 룬·코로나 원반, 접선 불꽃, 바닥 칼날 그림자
  - **타격 섬광 0.75 + 0.5k s (k = 0..10)**: 서버의 0.5 s 틱 피해와 맞춘 베기 호·별·바닥 고리 (틱이 다르면 섬광만 어긋남)
  - 6.0 칼날이 사방으로 날아가며 사라짐 (섬광·충격파) · 파티클 수명 포함 약 7.3 s 에 완전 종료
- 칼날·꼬리는 메쉬 한 장에 8개를 합쳐 rotationOverLifetime(Y) 로 돌림 (8개 위치가 항상 정확히 등간격).
- 모든 항목이 클라이언트 지원 기능 안 (client_compat check OK, fix 0 changes). 고유 텍스처 RGBA 2.42 MiB.
