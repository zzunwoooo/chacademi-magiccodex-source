# Lighthouse (등대) — 빛 / 고급

## 시스템
- `main` (static, 7.2 s, 57층) — P = 지정한 바닥 지점, 기준 = 서버가 넘기는 시전자 수평 방향(+Z). 등대는 P 중앙에 선다.

## 시간표
| 시각 | 내용 |
|---|---|
| 0.0–0.8 | 바닥 마법진(선 링·팔각성 {8/3}·룬 띠·태양 문장) 그려짐 |
| 0.25–0.85 | 등대 솟음 (선 골조·나선 줄무늬·내부 빛기둥) |
| 0.9 | 등불 점화 (섬광·고리) |
| 1.0–6.0 | 빛줄기 2개가 등불(높이 5 m)에서 바닥(반경 ~7 m)으로 비스듬히 뻗어 1.8 rad/s 로 회전, 빛줄기 아래 바닥이 탄다 (함께 도는 불꽃·잔광 호·그을림) |
| 2.25 / 3.5 / 4.75 | 맥동 고리 |
| 5.45–6.0 | 등불로 빛 모임 (예고) |
| 6.0 | 등불 폭발 (섬광·파동·god ray·파편·바닥 충격파·빛기둥) → 7.2 소멸 |

## 피해 권장 시점
- 지속: 1.0–6.0 s, 빛줄기가 대상 방위각을 지날 때 (빛줄기 각도 = 시작각 + 1.8 rad/s × (t − 1.0), 두 줄기는 180° 반대). 시작각은 로컬 +X 와 −X (시전자 기준 오른쪽/왼쪽), +Y 회전 방향(위에서 보면 시계 반대가 아니라 +X → −Z 방향).
- 마무리: 6.05 s, 반경 6 m 범위 폭발.

## 런타임 입력
- `areaRadius` (scale: reference 6 m, 배율 min 0.6 / max 1.5).
