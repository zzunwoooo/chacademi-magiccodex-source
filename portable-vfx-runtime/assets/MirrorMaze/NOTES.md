# MirrorMaze (거울 미궁) — 빛 / 고급

## 시스템
- `main` (static, 5.0 s, 50층) — P = 가둘 대상의 발 위치(바닥), 기준 = 서버가 넘기는 시전자 수평 방향(+Z). 거울판 4장은 P 둘레 반경 2.6 m, 45°/135°/225°/315° 방향, 높이 3 m, 폭 1.8 m.

## 시간표
| 시각 | 내용 |
|---|---|
| 0.0–0.5 | 바닥 마법진 |
| 0.2–0.7 | 거울판 4장이 땅에서 솟음 (0.7부터 고정) |
| 0.9–3.55 | 중앙 감옥 빛기둥 |
| 1.0 / 1.25 / 1.5 / 1.75 | 반사광이 거울→거울로 꺾여 사각형을 그림 (각 거울에 반사 섬광) |
| 2.1 | 대각선 반사광 2줄이 중앙을 가로지름 |
| 2.1 / 2.6 / 3.1 | 중앙 타격 (섬광·고리·불꽃) |
| 3.55–3.9 | 네 거울이 중앙으로 빛을 모음 (수축 고리) |
| 3.9 | 중앙 폭발 + 거울 산산조각 → 5.0 끝 |

## 피해 권장 시점
- 가두기(이동 제한): 0.7–3.9 s, 반경 2.6 m 안.
- 반사광 타격: 2.1, 2.6, 3.1 s (중앙 반경 ~1 m).
- 마무리: 3.9 s, 반경 ~3 m.

## 런타임 입력
- `areaRadius` (scale: reference 2.6 m, 배율 min 0.7 / max 1.6).
