# ShadowPlay (그림자극) — 변환 메모

**원소/등급**: 어둠 · 중급. 달빛 팔레트(흰 → 은백 → 라벤더 → 보라 → 남보라) + 먹빛 그림자·잉크 커튼·잉크 파편.

## 시스템 / 역할
| id | role | 길이 | 위치 | 시작 / 정지 |
|---|---|---|---|---|
| `stage` | static | 3.0 s (타격 가능 시간) | P = 대상 뒤 **벽면 위, 바닥 높이** 지점. 기준 방향 = 시전자 수평 방향(+Z = 벽 안쪽). 층은 벽면 앞 3~9 cm 의 XY 평면 | 시전 시 시작. **그림자를 맞히면 모드가 stop** (onStop 꼬리 0.3 s: 그림자가 번쩍이며 사라짐). 안 맞히면 3.0 s 뒤 저절로 사라짐 |
| `cut` | impact | 1.4 s | 벽의 타격 지점 hitPoint, up = 벽 법선(시전자 쪽) | 그림자 타격 순간 |
| `echo` | attached | 1.2 s | **대상(TARGET)** 발 + 몸 방향 | 그림자 타격 순간 (cut 과 같은 프레임) |

- stage 의 그림자 모양은 일반 인간형 실루엣(높이 2.4 m × 폭 1.2 m, targetHeight 로 비례). 몹 모양을 그대로 비추는 것은 아님.
- 벽이 없으면(모드 판단) stage 를 대상 뒤 바닥 지점에 세워도 되지만 그림자가 공중에 뜬 판처럼 보인다.

## 시간표
- stage 0.00 잉크 커튼이 닫힌 채 나타남 → 0.05–0.35 좌우로 열림, 달빛 스포트라이트 원 + 무대 문양(회전) + 고리, 0.05 작은 섬광
- stage 0.20 대상의 그림자가 발부터 솟아오름(0.2–0.6), 0.35 흔들리는 잔상 테두리, 0.6~ 잉크 방울이 떨어지고 빛 입자·투사광 줄기가 벽으로 흐름
- 타격(데모 1.3 s): stage stop → 그림자 번쩍 후 0.3 s 내 사라짐
  - `cut` 0.00 섬광 + X 베기 1획, 0.04 벽 균열 확산, 0.08 X 베기 2획, 잉크 초승달·파편·불꽃·안개
  - `echo` 0.02 몸통 앞 X 베기 1획 + 섬광(**피해 권장 시점 = 타격 + 0.02 s**), 0.04 그림자가 몸에서 뒤로 튕겨 나감(먹빛 + 테두리), 잉크·파편·바닥 충격 고리, 0.10 X 베기 2획

## 런타임 입력
- stage: P(벽면 바닥 지점) + 시전자 수평 방향, stop 신호
- cut: hitPoint, surfaceNormal, incomingDirection
- echo: 대상 발 위치 + 몸 방향 (매 프레임)
- `scale.input = targetHeight` (reference 1.8, min 0.6, max 2.0): 세 시스템 모두 같은 배율 → 그림자 크기가 대상 키를 따라감

## 클라이언트 호환
