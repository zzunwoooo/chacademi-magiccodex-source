# LanternChain (등롱 사슬) — 화염 중급

## 시스템 / 역할
- `main` (static, 4.0 s, 37층). P = **시전자 발 위치**, +Z = 시전자 수평 방향(서버 기준 방향), +Y 위. 스케일 입력 없음(고정 크기).
- 등불 3개 위치(로컬): 왼쪽 (−2.6, 1.15, 4.0), 가운데 (0, 1.15, 4.0), 오른쪽 (2.6, 1.15, 4.0) → 시전자 정면 4 m 앞을 가로지르는 5.2 m 불줄.
  (불줄은 등불 사이에서 0.2 m 처짐)

## 시간표
| 시각(s) | 내용 |
|---|---|
| 0.00 / 0.08 / 0.16 | 가운데 → 왼쪽 → 오른쪽 등불을 손(0.35, 1.45, 0.4)에서 던짐 (포물선 0.42 s, 꼬리 trail) |
| 0.42 / 0.50 / 0.58 | 각 등불 착지(매달림) 섬광 |
| 0.62 | 가운데 등불이 타오르며 불길이 양쪽 등불로 달려감 |
| **0.85–3.40** | **불줄 유지** (불띠 3겹 깜박임 + 불꽃 혀·불티·바닥 그을음/빛줄) |
| 3.40 | 불줄 사그라듦 · 3.50 등불 3개 터짐(불꽃·숯·불티) |
| 4.0 | 종료 |

## 피해 권장 시점
- **0.85–3.40 s**: 선분 (−2.6, *, 4.0)–(2.6, *, 4.0) 을 지나는(교차하는) 적에게 피해. 판정 높이는 지면~2 m 권장.

## 메모
- 지속 방출은 rate 대신 시간창 burst(cycles)로 구현 → 불줄 점화 전에는 불꽃이 나오지 않음.
- client_compat check: OK. 고유 텍스처 RGBA ≈ 1.50 MiB.
