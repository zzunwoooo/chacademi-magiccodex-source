# IcicleEaves (고드름 처마) — 물(얼음) / 중급

## 시스템
- `main` — role **static**, 1개. P = 시전자 발 위치, +Z = 서버가 넘겨주는 시전자 수평 정면 (static 기본 규약, `orientation` 필드 없음). duration 3.0 s.
- 앞쪽 한 줄(z = 2.0 ~ 8.2 m, 높이 5 m)에 서리 처마(룬 띠·고드름 장식·서리 구름)가 생기고, 고드름 5개(길이 1.8 m)가 앞에서부터 차례로 떨어져 부서진다.
- 런타임 입력: P + 수평 방향만. scale 없음(사거리 고정 8.2 m). 거리를 바꾸려면 모드에서 static 배율을 쓰지 말고 ZS/DZ 값을 바꿔 다시 뽑는 것을 권장.

## 시간표
| t (s) | 연출 |
|---|---|
| 0.00–0.40 | 처마 선·룬 띠, 서리 구름(어두운 안개 + 연청 빛), 냉기 모이는 선, 바닥 경고선·표식(0.25) |
| 0.25–0.70 | 고드름 5개가 처마 아래로 자라남(앞쪽부터 0.06 s 간격) |
| 0.70 / 0.87 / 1.04 / 1.21 / 1.38 | 고드름 1~5 낙하 시작 (v0 3 m/s + 중력 1.6배) |
| **1.175 / 1.345 / 1.515 / 1.685 / 1.855** | **착탄** z = 2.0 / 3.55 / 5.1 / 6.65 / 8.2 m: 서리 고리(반경 1.7 m) + 얼음 왕관 물보라 + 얼음 파편 + 서리 균열 자국 |
| 1.9–3.0 | 균열 자국·처마 서서히 소멸, 눈송이 |
