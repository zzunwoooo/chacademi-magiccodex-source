# IcebergDrop (빙산 낙하) — 물 · 고급

## 시스템 / 역할
- `main` — **static** 1개. P = 지정한 낙하 지점(바닥), local +Y = 위. 저작 반경 4 m, `scale = {input:"areaRadius", reference:4, min:0.5, max:1.6}`.
- 빙산·얼음 고리 = depthWrite 메쉬(면별 명암을 T_IceShade 에 구움) + 가산 모서리 선.

## 시간표 (s)
| 시각 | 연출 |
|---|---|
| 0.0 | 육각 경고 마법진 + 커지는 그림자, 냉기 줄기 하강 |
| 0.3–0.5 | 16 m 위 하늘 문(고리·육각·룬·안개) 열림, 0.48 섬광 |
| 0.5–1.2 | 빙산(높이 ≈ 5 m)이 문에서 나와 수직 낙하(등속 22 m/s, 천천히 회전), 빛 꼬리 + 안개 꼬리, 0.75 부터 바닥 압력 고리 수축 |
| **1.2** | 착탄: 섬광, 충격 2겹 + 공중 고리, 광선, 먹빛/빛 얼음 파편, 눈보라 파도, 균열·서리 무늬, 반경 2.7 m 얼음 고리 12개 솟음, 빛기둥 |
| 1.2–2.2 | 빙산이 박힌 채 유지(바닥 안개, 반짝임) |
| **2.2** | 빙산 파쇄: 섬광, 큰 파편(먹빛·빛), 잔파편, 얼음 고리도 부서짐, 충격, 눈꽃, 안개 |
| 3.4 | 종료 |

## 피해 권장 시점
- **1.2 s** 착탄 주 피해(반경 4 m, 중심일수록 강하게).
- **2.2 s** 파쇄 추가 피해(작게).

## 런타임 입력
- static: P + 수평 방향(무관) + `areaRadius`.
