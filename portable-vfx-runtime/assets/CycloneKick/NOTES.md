# CycloneKick (회오리 발차기) — 바람 중급 · 변환 메모

## 시스템 / 역할
- `main` — attached (시전자 발, +Z = 시전자 정면), duration 0.6 s (+ 잔상 ~0.9 s, 전체 약 1.5 s). 시전 순간 시작.
- 발차기 호는 오른다리 쪽(x ≈ +0.1~0.18 m) 세로(YZ) 평면 메쉬 3장(먹빛/넓은 바람/밝은 심) — 2×8 와이프 플립북이라 앞-아래 → 머리 위로 그려진다.
- 회오리(띄우기 연출)는 시전자 앞 z = 1.6 m 바닥 기준.

## 시간표
- 0.00–0.15 준비: 오른발 빛, 발밑으로 모이는 줄기, 발밑 마법진(회전) + 소용돌이
- 0.15–0.40 발차기: 먹빛 호 → 넓은 바람 호 → 밝은 심 호 → 잔향 호, 발끝 불꽃
- 0.22 **접촉/띄우기**: 섬광, 바닥 충격파 2개, 회오리 토네이도 띠(밝은 4 + 먹빛 2, 상승), 기둥 줄기, 위로 오르는 고리 3개, 세로 베기 호 3개, 돌풍, 먹빛 파편, 빛 파편, 먼지(먹빛 안개), 부유 입자, 바닥 소용돌이
- ~1.5 s 끝

## 피해 권장
