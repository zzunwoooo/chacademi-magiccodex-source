# ClepsydraCage (물시계 감옥) — 물 · 고급

## 시스템 / 역할
- `main` — **static** 1개. P = 갇히는 적의 발 위치(바닥), local +Y = 위. 구 지름 2.8 m, 중심 높이 1.15 m.
- 크기: `scale = {input:"targetHeight", reference:1.8, min:0.6, max:2.0}` → 대상 키에 맞춰 구·마법진 전체가 커짐.

## 시간표 (s)
| 시각 | 연출 |
|---|---|
| 0.0–0.35 | 물줄기 나선 3+3개가 감겨들고 물방울이 모임, 12분할 물시계 마법진(시계 문장) 그려짐 |
| 0.35 | 물방울 구가 닫힘(섬광 + 물보라 왕관) |
| 0.35–3.35 | 구 안 수위가 바닥 → 꼭대기로 차오름(16프레임 플립북 2겹), 회전 물 고리 3개, 상승 기포, 꼭대기에서 떨어지는 물방울, 땅의 시곗바늘이 3 s 에 한 바퀴 |
| 1.35 / 2.35 | 맥동(점점 강해짐): 구 수축-팽창, 파동, 물 가시, 마법진 플레어 |
| 3.35 | 구가 터짐: 섬광, 파동 2겹, 바닥 충격, 물보라 링, 물방울·물줄기 사방, 물 리본, 물안개 |
| 4.2 | 종료 |

## 피해 권장 시점
- 가둠(이동 불가) 0.35–3.35 s. 피해 틱 **1.35 / 2.35 / 3.35 s** (물이 찰수록 증가: 예 1×, 1.5×, 2× + 터짐).
