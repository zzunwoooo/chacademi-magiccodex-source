# MoonPull (달의 인력) — 변환 메모

**원소/등급**: 어둠 · 중급. 달빛 팔레트(흰 → 은백 → 라벤더 → 보라 → 남보라), 먹빛 물결 그림자·잉크 파편 강조.

## 시스템 / 역할
| id | role | 길이 | 붙는 곳 | 시작 |
|---|---|---|---|---|
| `pull` | attached | 1.9 s | **시전자** 발 위치 + 수평 방향 | 시전 순간 |
| `grip` | attached | 0.9 s | **끌려오는 적** 각각의 발 위치 + 몸 방향 | 모드가 그 적을 끌어당기기 시작할 때 (데모: 0.33 s), 적마다 1개 |

- 실제 끌어당김(이동)은 모드 몫. 데모에서는 적이 0.35–1.0 s 사이에 반경 5 m → 1.4 m 로 끌려온다. 밀물 고리가 시전자에게 닿는 시점(≈1.05)과 맞추는 것을 권장.

## 시간표 (pull 시작 기준)
- 0.00–0.3 시전자 발밑에 달 봉인진(링·8각 별 2겹·룬 띠·위상 문양)이 그려지며 회전, 반경 6 m 경계 고리 + 바깥 룬 띠
- 0.10 머리 위 3.3 m 에 작은 달이 떠오름(먹빛 그늘 + 코로나 + 후광)
- **0.20 / 0.40 밀물 고리 2개**가 경계에서 나타나 안쪽으로 밀려들어옴(먹빛 물결 그림자 + 빛 물마루 + 물보라). 동시에 줄기·안개·나선 리본·초승달·잉크 파편·입자가 시전자 쪽으로 빨려 들어감(뒤로 갈수록 많아짐), 0.6~ 빛이 달로 솟음
- 0.70–1.05 바닥 충격 고리가 수축(예고)
- **1.05 수렴**: 섬광 + 달 플레어 + 바닥/공중 충격 고리 + 봉인 플레어 + 잉크 초승달·불꽃 — **끌어당김 판정은 0.2–1.0 구간, 피해가 있다면 1.05 권장**
- 1.05–1.9 미광·입자 상승, 봉인 소멸
- `grip` 0.00 발목 고리(조여듦) + 머리 위 초승달 표식, 0.0–0.9 먹빛 기운 + 이동 경로를 따라 보라 줄기·잉크 파편(월드, 거리 비례)

## 런타임 입력
- pull: 시전자 발 위치 + 수평 방향, `scale.input = areaRadius` (reference 6 m, min 0.5, max 1.5 배): s = clamp(반경 / 6, 0.5, 1.5) — 달 높이도 같은 배율
- grip: 적 발 위치 + 몸 방향 (매 프레임). 같은 배율이 적용되므로 반경 설정이 아주 작거나 크면 발목 고리 크기도 따라 변한다(0.5~1.5배).
