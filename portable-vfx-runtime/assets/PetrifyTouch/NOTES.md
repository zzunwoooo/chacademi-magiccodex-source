# PetrifyTouch (석화의 손) — 대지 고급

## 시스템 / 역할
- `strike` (attached, 0.6 s): 시전자 발 + 수평 방향. 손 앞(0.1, 1.15, 0.85 m)에서 손바닥 일격. 적중 시각 0.12 s.
- `petrify` (static, 4.3 s): **대상의 발 위치**에 놓는다. 시작 = 적중 순간 (시전 + 0.12 s). 기준 방향은 아무 쪽이나 무방(대칭).
- SCENE.scale `targetHeight` (reference 1.8, min 0.7, max 2.2): 대상 키에 맞춰 두 시스템 모두 균일 배율. (strike 도 함께 커지므로 큰 대상을 칠 때 일격도 커진다.)

## 시간표 (petrify 시작 기준)
| 시각 (s) | 연출 |
|---|---|
| 0.0 | 적중 섬광 + 세로 충격 고리, 발밑 균열·마법진(반경 1.1 m) |
| 0.0–0.6 | 돌 껍질이 발부터 머리까지 차오름(8칸 플립북 와이프), 올라가는 빛 고리·모래 |
| 0.6–3.0 | 석화 유지(돌 기둥 껍질 높이 1.95 m), 균열 빛이 점점 강해지고 1.4/2.1/2.5/2.75/2.9 s 맥동 |
| 2.6–3.0 | 수축하는 빛 고리(예고) |
| **3.0** | **파쇄**: 껍질 사라짐, 큰 돌덩이·파편·불꽃·모래/어두운 먼지·충격파·균열 섬광 |
| 4.3 | 종료 |

## 피해 권장 시점
- 일격 피해: 시전 + 0.12 s. 석화(이동/행동 불가) 0.0–3.0 s. **파쇄 큰 피해: petrify + 3.0 s (= 시전 + 3.12 s)**.

## 런타임 입력
- strike: 시전자 발 위치 + 수평 방향(매 프레임). petrify: 대상 발 위치(P) + targetHeight.
