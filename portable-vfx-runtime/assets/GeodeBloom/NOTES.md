# GeodeBloom (정동 개화) — 대지 비전

## 시스템 / 역할
- `main` (static, 5.6 s). P = 지정 지점(바닥 중심). 기준 방향 무관.
- SCENE.scale `areaRadius` (reference 6 m, 배율 min 0.6, max 1.5 → 반경 3.6–9 m).

## 시간표
| 시각 (s) | 연출 |
|---|---|
| 0.0 | 마법진(반경 6 m) 그려짐, 중앙에 정동(돌)이 솟음, 돌 파편·먼지 |
| 0.6–2.6 | 모임: 바깥에서 빛줄기가 단계적으로 늘며 빨려듦(0.6/1.8/2.3 s), 룬 불꽃, 작은 결정 새싹, 정동 균열 빛 점점 강해짐 |
| 2.15–2.6 | 예고: 정동 주위 빛 고리 2개가 수축 |
| **2.6** | **개화**: 섬광, 정동 두 반쪽이 날아감(결정 단면), 중앙 결정 송이, 충격파 2겹·공중 고리, 신광 줄기, 결정/어두운 파편, 돌, 모래/어두운 먼지, 마법진 섬광, 균열 |
| 2.65 / 2.8 / 2.95 / 3.1 | 결정 가시 고리 4겹이 차례로 솟음 (r = 1.6 / 3.0 / 4.4 / 5.8 m), 각 고리마다 모래 분출 + 불꽃 |
| 3.2–4.4 | 유지: 반짝임, 바닥 빛 |
| 4.4 | 가시 파쇄: 섬광, 결정 파편 비, 먼지, 반짝이 |
| 5.6 | 종료 |

## 피해 권장 시점
- 개화 2.6 s 중심 피해, 가시 고리 피해: 반경 r 의 적은 `t ≈ 2.6 + 0.15·k` (k=0..3, 고리 r=1.6/3.0/4.4/5.8 m) — 간단히는 거리 d 에 대해 `t = 2.6 + 0.107·(d − 1.6) + 0.05` s. 파쇄 4.4 s 추가 피해(선택).

## 런타임 입력
- static: P + areaRadius.

## 비고
- 가시는 땅 아래 높이만큼에서 0.16 s 만에 솟아오른다(drag 로 정확히 지면에서 멈춤). 지면이 가려 주는 마인크래프트에서는 땅에서 돋는 모습. 미리보기 바닥은 아래를 가리지 않아 첫 0.1 s 정도 땅 밑 부분이 비칠 수 있다.
