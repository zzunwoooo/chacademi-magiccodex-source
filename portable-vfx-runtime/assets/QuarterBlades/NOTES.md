# QuarterBlades (상현·하현 칼) — 변환 메모

**원소/등급**: 어둠 · 중급. 달빛 팔레트(흰 → 은백 → 라벤더 → 보라 → 남보라), 칼날 뒤 먹빛 그림자 칼날 + 먹빛 초승달·잉크 파편.

## 시스템 / 역할
| id | role | 길이 | 붙는 곳 |
|---|---|---|---|
| `main` | attached | 1.3 s | **시전자** 발 위치 + 바라보는 방향(+Z 정면). 칼날 높이 1.15 m, 반지름 약 1.65 m |

## 시간표
- 0.00 오른손 쪽 작은 초승달 반짝임
- 0.10–0.38 **1타 상현(왼 → 오른쪽)**: 반달 칼날(빛) + 뒤따르는 먹빛 칼날 + 날 끝 선 + 잔상, 오른쪽이 살짝 올라가는 기울기 — **1타 피해 권장 시점 0.24** (정면 1.5 m 타격 섬광·불꽃·초승달·잉크), 바닥에 초승달 자국
- 0.36 왼손 쪽 반짝임
- 0.44–0.72 **2타 하현(오른 → 왼쪽)**: 거울 반대 칼날, 반대 기울기 — **2타 피해 권장 시점 0.58**
- 0.60 두 초승달이 교차하는 마무리 섬광 + 고리 + 바닥 충격 고리, 안개·잉크 파편·입자 (월드에 남음) → 1.3 s 소멸

## 런타임 입력
- attached: 시전자 발 위치 + 수평 방향 (매 프레임). 칼날은 시전자를 따라간다 (로컬), 마무리 안개·파편·입자는 월드에 남는다.
- scale 입력 없음.
