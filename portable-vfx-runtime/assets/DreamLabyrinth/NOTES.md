# DreamLabyrinth (꿈의 미로) — 어둠 고급, 변환 메모

- 시스템 1개: `dream` (static, 4.3 s, loop 없음, 42 layers). P = 갇히는 적의 발 위치 (몸 중심 1 m 위). 시전 시 1번만 시작.
- 런타임 입력: `targetHeight` (기준 1.8 m, 배율 0.6~2.2). 큰 몹이면 미로 구체 전체가 같이 커짐.
- 시간표 (s):
  - 0.0 꿈 안개·거품, 발밑 미로 마법진(반경 1.6 m) 그려짐 · 0.2~0.36 세로 미로 원반 3장이 자이로스코프처럼 맞물려 회전하는 구체 감옥 완성 (행동 불가 시작 권장)
  - 0.5~2.6 꿈 유지: 미로 원반·룬 고리 회전, 진홍 꿈 안개, 궤도 초승달, 거품, 별빛 · 2.58~3.0 감옥이 오므라들며 빛이 모임 (예고)
  - **3.0 깨어남 = 큰 피해 권장 시점 (3.0~3.05)**: 감옥이 유리 파편으로 깨짐, 섬광, 보라+진홍 X자 베기, 파동 2겹, 빛줄기, 바닥 충격파
  - 3.0~4.3 잔광 (파티클 수명 포함 약 5.6 s 에 완전 종료)
- 서버의 "3초 속박"과 맞추려면 이 효과를 속박 시작과 동시에 1번 재생하면 됨 (깨어남 연출이 3.0 s 에 고정).
- 모든 항목이 클라이언트 지원 기능 안 (client_compat check OK, fix 0 changes). 고유 텍스처 RGBA 2.64 MiB (검사기 WARN 4.5 MiB 는 재질별 중복 집계).
