# 카탈로그 런타임 연결

- 일반 시전은 기존 MagicCodexBridge의 `/마법 <영문ID>`와 HUD 단축키가 같은 마나/쿨다운 트랜잭션을 사용합니다.
- PortableVFX는 그 트랜잭션에서 승인된 VFX만 재생합니다. 별도의 마나를 만들거나 두 번 차감하지 않습니다.
- 일반 시전 성공 시 UUID/디버그 메시지를 채팅에 보내지 않습니다.
- 로컬 디버그는 `/pvfxdebug`, 서버 디버그는 `/pvfxserverdebug`, 기존 효과음 확인은 `/codexsounddebug`입니다.
- 카탈로그 시전은 새 클라이언트 능력 확인을 요구합니다. 오래된 클라이언트에 새로운 모델/연결/단계 효과를 일부만 근사해 보내지 않습니다.

시작 패킷 opcode 12는 고정된 인스턴스 크기 입력과 연결 길이를 원자적으로 전달합니다. 크기 입력 0은 팩의 기준 크기, 연결 길이 -1은 미지정입니다. 연결 길이 0은 유효하며 그 외 음수는 거부됩니다. 링크 pose opcode 13은 위치·기저·길이를 하나의 순서 번호로 전달합니다. 엔티티 부착은 서버가 지정한 실제 엔티티 UUID를 따라가고 발 위치/몸 방향을 사용합니다.

일반 종료와 충돌 종료는 다릅니다. 일반 종료는 로컬 입자도 `onStop`/수명에 따라 마무리합니다. 충돌·일제 발사는 로컬 입자를 지우되 이미 월드에 방출된 꼬리는 남깁니다. 모든 종료는 같은 권위 있는 수명 주기 순서 번호로 검증합니다.

시스템 수명 상한은 12,000 tick(600초)이며 서버 설정으로 더 낮출 수 있습니다. 저작 데이터의 최대 hold 범위가 더 길더라도 실행 설정은 이 운영 상한을 지켜야 합니다. 피해량·상태이상·MythicMobs 스킬·마법 획득 조건의 실제 구현은 VFX 재생과 별도입니다.
