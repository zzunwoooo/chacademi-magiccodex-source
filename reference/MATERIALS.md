`output/index.html`은 자료 첫 화면입니다. HTML끼리의 상대 경로를 유지하기 위해 기존 폴더 이름을 보존했습니다.

## 최신 설정과 과거 기록

- 최신 마법 기획은 `output/spell-finalization-300-v1/catalog.json`, `combined-edits-300.json`, `implementation-backlog.json`과 `review.html`입니다. 최신 300종 YAML 스냅샷도 `release` 아래 보존했습니다. 목록 등록과 스킬 구현 완료는 다릅니다.
- `spell-revision-v2`에는 사용자 작성분과 반영 기록을 보존했습니다.
- `spells-finalization-v1` 및 `discovery-editor-v1`은 이전 200종 기준입니다. `spell-classification-editor-v2`는 238종 기준입니다. 새로운 300종 편집기를 의미하지 않습니다.
- 도감·스폰 조건표·생물 서버 YAML은 기획 및 설치 후보 스냅샷입니다. 현재 학교·야생 서버에 설치된 상태를 의미하지 않습니다.
- 기능 안내는 해당 기능을 만들 당시의 기록입니다. `docs/handoff/SERVER_HANDOFF.md`의 최신 확인 상태와 사용자 수정 지시를 우선하세요.
- `mariadb-migration`의 스크립트와 SQL은 초기 이전 작업 자료입니다. 현재 전체 테이블을 포함한다고 가정하거나 실행하지 마세요. 최신 플러그인 스키마와 비교해야 합니다.

## 편집기 실행

호스팅 RDP에서 각 편집기 폴더의 `start-editor.ps1`을 실행하면 호스팅 Python으로 자동 저장 도우미를 시작합니다. `-NoBrowser`는 브라우저를 열지 않습니다. 도우미는 `127.0.0.1`에만 바인딩합니다.

HTML만 직접 열어도 편집·내보내기는 가능하지만 파일 자동 저장은 도우미 연결 시에만 됩니다. 노트북에서는 직접 서버를 실행하지 마세요. 필요한 경우 호스팅 도우미의 포트 하나만 SSH로 전달합니다. 포트를 인터넷에 공개하지 않습니다.

원본 고해상도 마법 아이콘은 중복 포함 약 600MB라 이번 전송에서 제외했습니다. 원본 파일은 노트북에 보존되어 있습니다. 편집기에는 미이전 안내 이미지가 표시되며 이름·수치·설명·조건 편집은 가능합니다.

## 포함한 자료

- 마법 편집 화면, 저장 도우미, 기준 목록, 사용자 수정본 및 YAML 비교 기준
- 마법 300종 검토, 사용자 수정 기록, 62종 효과 정리
- 생물 모델 도감의 일반/이로치 뷰어 파일, 생물 이름·설명·포획 확률·서식지 기획
- 야생 출현 조건, 계절 규칙, 대형 구조물 목록과 미리보기, 생물/스폰 YAML
- 의뢰·NPC 대화·칭호·친구·마나·교화·이로치 시스템 안내
- 서버 기획 HTML, 콘텐츠 소개 HTML, 최종 포스터
- DB 초기 이전 스크립트/SQL과 두 인수인계 문서

## 이번에 제외한 자료

원본 대형 마법 아이콘, ModelEngine용 전체 BBModel/텍스처 원본, 월드·스키메틱·데이터팩, 런처·클라이언트 JAR, ZIP 배포본, 오래된 테스트 서버·빌드 캐시·로그·백업·DB 실데이터·인증 정보는 포함하지 않았습니다.

`source-manifest.json`은 가져온 원본의 경로·크기·SHA-256을 기록합니다. 호스팅에서 실행 경로/아이콘 안내 등을 조정한 파일의 현재 해시는 별도 `migration-verification.json`에 기록합니다.
