# 차카데미아 마법 분류·내용 편집기

기존 200종 중 사용자가 검토 완료한 **62종은 제외**했습니다. 이 편집기에는 기존 미검토 **138종**과 이후 제작한 신규 아이콘 마법 **100종**, 합계 **238종**만 표시됩니다.

## 사용법

1. `마법 분류 편집기 열기.cmd`를 두 번 클릭합니다.
2. 왼쪽에서 기존 138종/신규 100종, 원소, 작업 상태로 목록을 거릅니다. 이름과 효과 등도 검색할 수 있습니다.
3. 아이콘을 보며 원소, 이름, 마나, 쿨타임, 정렬 순서, 권한, 시전 명령어, 효과, 연구 기록, 획득 조건을 수정합니다.
4. 검토를 마친 항목은 **검토 완료 후 다음**으로 넘깁니다.
5. 상단에 **파일에 저장됨**이 표시되면 자동 저장된 상태입니다. 전체 수정이 끝나면 **수정본 내보내기**로 JSON을 보관하고 Codex에 전달할 수 있습니다.

수정 중인 내용은 약 0.5초 뒤 `data/edits.json`에 저장됩니다. `data/history/`에는 최근 저장 이력이 남습니다. 실행 파일은 인터넷 없이 이 폴더의 로컬 서버만 엽니다. `index.html`만 직접 열어도 편집할 수 있지만, 그 경우 브라우저 임시 저장만 사용하므로 작업을 끝낼 때 JSON을 내보내야 합니다.

**신규 100종**은 아이콘, 이름, 원소, 효과 설명만 만들어진 기획안입니다. 획득 조건·연구 기록은 비어 있고, 마나·쿨타임 0 및 권한·정렬 순서는 편집용 초기값입니다. 해당 100종의 실제 YAML과 스킬은 아직 없으므로, 조건이 비어 있어도 분류 검토를 완료할 수 있습니다. 이 값들을 완성된 게임 설정으로 간주하지 마세요.

이 편집기는 실제 게임 YAML이나 사용자가 완성한 62종을 수정하지 않습니다. 수정본 JSON을 받아 검토한 뒤 별도로 반영해야 합니다. `excluded-62-ids.json`은 제외된 ID 검증용이며, 기존 62종의 원본은 `../spells-finalization-v1/`에 그대로 있습니다.

아이콘 238개는 `icons/`에 복사했고 출처·해시는 `icon-manifest.json`에 기록했습니다. `catalog.json`은 기존 적용 데이터와 신규 마법 목록을 합친 편집 기준 스냅샷입니다. `build_catalog.py`는 최초 제작용으로, 나중에 다시 실행하면 기준 목록이 바뀌어 저장된 수정본과 호환되지 않을 수 있습니다.
