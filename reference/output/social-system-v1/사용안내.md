# 친구 · 바람의 전언 사용 안내

클라이언트: Magic Codex UI 0.17.0 / Fabric 1.21.4
서버: MagicCodexBridge 0.9.0 / Paper 1.21.4

## 설치
서버를 종료한 뒤 기존 MagicCodexBridge JAR을 0.9.0 JAR로 교체하세요.
기존 MagicCodexBridge 설정 폴더와 mana-spells.yml은 유지합니다.
MagicDiscovery 0.1.0은 친구 추가에 따른 마법 획득 조건을 연결할 때 함께 사용합니다.
친구 데이터는 plugins/MagicCodexBridge/friends.db에 저장됩니다.

## 친구창
상단 메뉴의 친구 아이콘, /친구, /친구창, /codexfriends로 엽니다.
친구 추가에 접속 중인 상대의 정확한 마인크래프트 닉네임을 입력합니다.
상대 수락 없이 내 목록에만 등록하는 방식이며 최대 50명입니다.
상대 스테이터스창의 친구 추가 버튼도 같은 목록에 연결됩니다.
목록을 직접 드래그하거나 마우스 휠·오른쪽 스크롤바로 이동할 수 있습니다.
검색, 현재 인원수, 온라인 상태를 표시합니다.
각 행의 버튼은 바람의 전언 / 정보 확인 / 친구 삭제입니다.
정보 확인은 기존 /스텟창 기능에 연결되며 접속 중인 상대만 가능합니다.
삭제는 확인창을 거칩니다. 오프라인 친구도 삭제할 수 있습니다.
현재 기숙사 배정 시스템이 없으므로 서버에서 미지정한 유저는 '기숙사 미정'으로 표시합니다.

## 기숙사 연동
기존 Bukkit StatsService 서비스의 Additional.dormitory 값을 읽습니다.
정확한 이름에 따라 깃발·행·이름 색이 바뀝니다.
- 아르케온: 빨강
- 루미나: 파랑
- 베스티아즈: 초록
- 노크세르: 노랑

접속 중에는 최신 StatsService 값, 오프라인에서는 저장된 이름·기숙사 정보를 사용합니다.
기숙사 배정 자체는 이 업데이트에서 새로 만들지 않습니다.

## 바람의 전언
접속 중인 친구의 깃털 버튼을 누르면 서버가 wind_message 마법을 확인합니다.
서버 mana-spells.yml의 활성 여부·권한·마나 비용·쿨타임이 그대로 적용됩니다.
제공된 기본 설정은 magic.learned.wind_message 권한, 마나 1, 쿨타임 1초입니다.
기존 서버 설정을 별도로 수정했다면 그 값이 우선합니다.
성공하면 기존 바람의 전언 사운드가 재생되고 화면 아래 편지봉투 입력창을 엽니다.
1~240자 입력, Enter 또는 보내기로 전송, Esc로 닫기, Ctrl+A/C/V 등 기본 편집을 지원합니다.
전언은 상대의 일반 채팅창에 '[바람의 전언] 보낸 사람 → 나: 내용'으로 표시됩니다.
모드가 있는 수신자에게는 도착 효과음도 재생합니다.
문자는 명령어로 실행되지 않으며, 마크 색상 코드·제어 문자는 허용하지 않습니다.

마법은 입력창을 여는 순간 사용됩니다. 작성 취소 시 비용·쿨타임은 되돌리지 않습니다.
한 번의 사용으로 전언 한 건을 보낼 수 있으며 입력 권한은 최대 2분입니다.
단축키나 기존 마법 명령으로 wind_message를 사용하면 친구 선택창이 먼저 열립니다.
이어서 친구를 고를 때는 이미 사용한 마법을 다시 차감하지 않습니다.
친구 선택창에서 시작한 전언은 별도 MythicMobs 명령 없이 내장 기능으로 처리합니다.

## 서버 부담과 검증 범위
친구 목록은 접속할 때 비동기로 불러오고, 저장도 단일 작업 스레드에서 처리합니다.
친구창이 열려 있을 때만 5초 간격으로 최대 50명의 접속·기숙사 정보를 요청합니다.
메시지 길이·요청 빈도·친구 소유권·50명 제한을 서버에서 검사합니다.
전언 전송권은 사용자·대상에 묶인 일회용 값이며 재사용할 수 없습니다.
상대가 접속을 종료하거나 숨김 상태이면 정보 확인·전언을 제한합니다.
실제 서버의 친구 추가·전언 통합 플레이는 설치 후 두 계정으로 최종 확인해 주세요.
