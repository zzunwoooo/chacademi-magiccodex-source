# 차카데미 몹·펫 에셋 분류

검토일: 2026-09-30. 제공한 15개 압축파일과 관련 내부 압축파일의 모델·MythicMobs·MCPets 설정을 조사했다. 서버 설치 및 실행 검증은 하지 않았다. ‘우선 후보’는 구성 파일과 서버 기획에 따른 분류이며 현재 버전에서 즉시 정상 작동한다는 의미는 아니다. 아래 수량은 별도 표시가 없으면 이펙트·투사체·아이콘을 제외한 본체 기준이다.

## 중복·보완할 부분

- 동물의숲 내부 Nature Mobs와 Lunar Aquatic은 별도로 받은 팩과 겹친다. 한 벌만 채택한다.
- Wilderness 2.1도 동물의숲에 있으므로 별도 제공된 2.2를 우선 검토한다.
- RibbitPack 두 벌과 Rubber Ducks의 ME3 버전은 중복·구버전 후보다.
- 동물의숲에 포함된 오래된 플러그인 JAR는 적용 대상에서 제외한다. 가구·차량·모자·HUD 역시 이번 생물 목록에서는 제외했다.
- Wilderness의 `BearPolarPet`은 실제로 `model{mid=bear_black...}`을 참조한다. 북극곰 펫 모델 연결 수정 필요.
- Itty Bitty Kitties는 고양이 모델 19개에 비해 펫 설정이 21개다. Angel/Tortoiseshell 펫 설정이 있으나 해당 이름의 본체 모델이 없어 참조 확인 또는 제외가 필요하다.
- glacialcore에는 MythicMobs 기본 설정·예제까지 들어 있다. 보스 관련 파일만 분리해야 한다.
- 기존 생성 리소스팩을 서버팩 전체에 덮어쓰지 않고, 채택한 모델을 현재 ModelEngine으로 빌드하여 합치는 방향이 적합하다.
- MCPets 설정 포함 여부와 교화 연동 완료 여부는 다르다. 등록 ID, 소유권 지급, 별 등급, 포획 확률, 도감 표시를 기존 시스템에 연결해야 한다.
- 꾸밈·라이딩 기획에 맞춰 펫 공격·버프·레벨 보너스·기존 먹이 시스템은 선별 제거한다. 야생 전투용 설정과 소환 펫 설정은 분리한다.
- 탑승 팩의 색상 변형은 이로치 외형 후보지만, 기본 스킨 전부 해금과 희귀 개체 포획은 별도 설계가 필요하다.

## 추천 적용 순서

1. **학교·숲:** Kingdom Cats, Pug, BULB VOL2, LostAssets 요정, Wilderness 작은 동물.
2. **야생 전투:** Nature Mobs, 오우거, Necron 해골.
3. **탑승:** 카피바라·유니콘·키츠네·히포그리프 등부터 선별.
4. **지역 확장:** 수중 생물, 겨울 펫, 워든 계열, Glacialcore 보스.

첫 적용은 대표 10~15종으로 시작해 모델 크기·따라오기·교화·소환·라이딩을 확인한 뒤 확대하는 것을 추천한다. 이 문서는 파일 구성 검토 결과이며, 모델 외형을 전부 렌더링하거나 성능을 실측한 결과는 아니다.
