# 커스텀 바이옴 생물 기획안

차카데미 Terralith 1.21.4 데이터팩의 실제 생성 설정(커스텀 95개)을 기준으로 한 138개 항목 제안. 모델은 137개이며 우두머리 버팔로는 일반 버팔로 모델을 공유한다. 한국어 바이옴명·생물명·설명은 서버용 제안 이름이다. 현재 운영 서버 적용 상태나 이미 생성된 청크의 위치를 확인한 것은 아니다.

## 확률 기준

- 기존 TamingRules: 기본% + 체력보너스%p × (1 − 현재체력/최대체력).
- 표의 두 확률은 체력 100% / 체력 10% 기준. 체력 0%는 일반 개체에게 실사용 가능한 최대값이 아니므로 표시하지 않는다.
- 별은 기존 MCPets ID→1~3성 시스템에 연결할 제안값이다. 별 자체가 확률을 자동 계산하는 것은 아니다.
- 보스는 사망 유예 중 고정 0.4%, 체력 보너스 없음. 반복 시도 횟수에 따라 최종 획득 확률은 증가한다. 예를 들어 3회 독립 시도면 약 1.195%다.
- 스폰 희귀도와 포획 확률은 별개다. 구체적인 스폰 가중치·개체 상한·재시도 제한은 아직 설정하지 않았다.
- 펫은 꾸밈·라이딩 용도. 야생 몹 전투 능력을 소환 펫에게 그대로 주지 않는다.
- 화염·공허 변형도 우선 현재 확인된 오버월드 커스텀 지형에 배치 제안. 확인되지 않은 커스텀 네더·엔드 바이옴을 만들어 적지 않았다.

## 적용 전 연결 작업

모델 ID는 MCPets/MythicMobs 등록 ID와 동일하다고 가정하지 않는다. 별 매핑·교화 대상·펫 소유권·스킨별 해금 정책을 연결해야 한다. Royal 변형은 이벤트 교화로 제안했다. 학교의 장식·NPC 소유 동물은 포획 불가이며 외곽 야생 개체만 대상으로 한다. 기존 검토에서 보류한 ALL MOB, 구형 팩, 추가 수중·곤충 팩은 이번 138개 항목에 추가하지 않았다.
