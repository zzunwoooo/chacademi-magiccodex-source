# 전체 마법 정리

사용자 작성 62종은 서클 관련 문구 3곳과 정렬 순서를 제외하고 그대로 보존했습니다. 나머지 138종은 검토할 수 있는 제안 상태입니다.

정렬: 바람 → 화염 → 물 → 대지 → 빛 → 어둠, 각 그룹은 기존 배치 순서를 유지하고 10~2000의 고유 번호를 붙였습니다.

획득 조건은 기획 문구입니다. 조건 판정·수업·계절·마나·실제 스킬 동작을 새로 구현한 작업은 아닙니다.

메테오 스트라이크의 「모든 화염 마법 습득」 판정은 자기 자신을 제외해야 합니다. 사용자가 만든 수치·패시브·즉사 효과 문구는 그대로 보존했으며 별도 서버 스킬 연결이 필요합니다.
