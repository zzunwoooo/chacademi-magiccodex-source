# 차카데미아 · 마법 내용 편집기

## 사용 방법

1. **획득조건 편집기 열기.cmd**를 두 번 클릭합니다. 브라우저에 편집기가 열립니다.
2. 왼쪽에서 마법을 고릅니다. 이름·효과·조건 검색, 원소·작업 상태 필터를 사용할 수 있습니다.
3. **이름·원소·마나·쿨타임 등 기본 설정과 마법 효과·모험일지(연구 기록)·획득 조건**을 수정합니다. 여러 조건은 줄을 나누어 작성해도 됩니다.
4. 확인을 마쳤으면 **검토 완료 후 다음**을 누릅니다. Ctrl+Enter로도 이동합니다.
5. 화면 위에 **파일에 저장됨**이 표시된 것을 확인한 뒤 Codex에 **“수정 끝났어. YAML에 반영해줘.”**라고 말합니다.

수정하는 즉시 약 0.5초 뒤 `data/edits.json`에 저장됩니다. 브라우저를 닫았다 다시 열어도 이어서 작업할 수 있습니다.
최근 20번의 저장 이력은 `data/history/`에 남습니다. 브라우저에도 복구용 임시 사본을 보관합니다.
서버가 꺼진 뒤에는 실행 파일을 다시 열면 됩니다. 인터넷 연결이나 별도 계정이 필요하지 않습니다.

## 내보내기 / 이어하기

- **수정본 내보내기**: JSON 사본을 내려받습니다. 나중에 Codex에 전달하거나 별도 백업으로 보관할 수 있습니다.
- **수정본 가져오기**: 같은 기준 목록에서 내보낸 수정본을 가져옵니다. 포함된 마법만 갱신하고 다른 마법의 수정은 유지합니다.
- `index.html`만 직접 열어도 편집할 수 있습니다. 이 경우에는 브라우저에만 임시 저장되므로 수정본 JSON을 내보내서 전달해야 합니다.
- 여러 창에서 동시에 같은 마법을 편집하다 저장 충돌이 나면 한 창으로 정리하세요. 충돌한 입력은 자동 덮어쓰지 않습니다.

## 저장 범위

현재 게임에 설치된 200종 YAML을 2026-09-21에 읽어 기준 목록으로 사용했습니다.
편집기는 기본 설정 7개와 설명 3개 및 검토 상태를 별도 수정본에 저장합니다.
마법 ID는 연결 유지를 위해 고정합니다. 리소스·사운드·VFX 항목은 제외하며 게임의 실제 YAML은 아직 변경하지 않습니다.
조건 문구는 실제 획득 판정 로직과 별개입니다. 이후 서버 기능을 구현할 때 해당 조건과 연결해야 합니다.
효과 설명은 최대 1024자, 연구 기록은 최대 512자이며 빈 문구도 가능합니다. 조건은 모드에서 1~512자까지 허용합니다. 작성 중 빈칸과 긴 문구도 임시 저장되지만 검토 완료에는 올바른 조건이 필요합니다.

## Codex 반영 작업 안내

편집 완료 요청 시 `data/edits.json`과 `catalog.json`을 읽습니다.
각 마법 ID의 수정본에 있는 편집 항목만 아래 매핑에 따라 최신 실제 YAML에 반영하고, 나머지 필드와 사용자의 다른 수정은 보존합니다.
현재 YAML의 해당 필드가 catalog의 기준 문구와 달라졌다면 자동 덮어쓰지 말고 양쪽을 비교합니다.
반영 전 최신 파일을 백업하고, 저장 후 실제 모드 SpellYamlLoader로 검증합니다.
검토 상태는 편집기용 정보이며 게임 YAML에 추가하지 않습니다.

## 구성

- `index.html`, `style.css`, `app.js`: 편집 화면
- `catalog.json`, `catalog.js`: 최신 게임 파일에서 읽어 온 기준 목록
- `source-yaml/`: 기준 YAML 사본. 편집 중 변경하지 않음
- `data/edits.json`: 사용자가 수정한 조건과 검토 상태
- `server.py`: 내 컴퓨터에서만 동작하는 자동 저장 도우미
- `start-editor.ps1`: 도우미 실행 및 브라우저 열기

웹 서버는 127.0.0.1에만 연결되며, 저장에는 실행별 토큰과 버전 검사를 사용합니다.
외부 서비스를 사용하거나 수정 내용을 네트워크로 업로드하지 않습니다.

기존 조건 전용 수정본도 그대로 읽습니다. 수정본에 description 또는 research가 없으면 해당 필드는 변경하지 않습니다. 현재 원본 YAML 스냅샷은 유지하며 연구 기록 필드만 기준 목록에 추가했습니다.
