# 던전 기믹 모델 (bbmodel)

차카데미 던전 수수께끼용 기믹 모델 43종, 속성 변형 포함 63개 파일. Blockbench Modded Entity(Box UV), 텍스처 내장.
게임 안 동작(마법이 닿으면 작동, 퍼즐 상태)은 아직 없다. 다음 작업에서 `magic-mythic-paper` 에 붙일 예정.

## 폴더

| 경로 | 내용 |
| --- | --- |
| `models/<id>/<id>.bbmodel` | 모델 파일. ModelEngine 등록용 |
| `index.json` | 모델 목록 (id, 한글 이름, 분류 A~E, 속성, 설명, 애니메이션 설명) |
| `hitboxes.json` | 모델별 히트박스 폭·높이·눈높이 (블록 단위) |
| `viewer.html` | 브라우저로 여는 3D 도감 (애니메이션 재생, 히트박스 표시) |
| `tools/` | 모델 생성 스크립트. `python3 build.py` (출력 경로는 `build.py` 의 `O` 변수) |

## 분류

- A 입력 장치 (원소가 닿으면 켜짐): 원소 화로, 얼음 봉인 결정, 풍차 터빈, 바람 종, 물레방아, 수위 기둥, 씨앗 화분, 대지 압력판, 빛 수신 수정, 해시계 석판, 그림자 촛대, 잠든 석상, 원소 비석(6속성), 스위치 레버, 회전 다이얼
- B 연결 장치: 마력 도관(직선·코너·분기), 마력 축전기, 논리 받침대(AND), 분배 수정, 회전 반사 거울, 프리즘
- C 출력 장치: 원소 텔레포트 게이트, 봉인문(대형·소형), 부유 발판, 승강 석주, 봉인 보물상자(6속성), 바람 분출구, 물길 수문, 빛의 다리
- D 조각·수집: 원소 조각(6속성), 조각 받침 제단, 숨겨진 조각 보관함(6속성), 부서진 석판, 영혼 등불
- E 협동 전용: 쌍둥이 공명석, 증기 밸브, 천칭 저울, 연결 사슬 기둥, 거울 감옥, 시간차 문

## 애니메이션 규칙

- 공통: `spawn`(once), `idle`(loop, 꺼진 상태), `activate`(hold, 켜지는 동작), `active`(loop, 켜진 상태), `deactivate`(hold)
- 장치별 추가: `pos_0~3`/`rot_0~3`/`turn`(다이얼·거울), `level_1~3`(수위), `in_1~3`(AND 입력), `insert_<속성>`(제단), `place_1~4`(석판), `fire_in`/`water_in`(증기 밸브), `tilt_left`/`tilt_right`(천칭), `point_n/e/s/w`(해시계), `hit`(공명석), `pickup`(조각), `extinguish`/`relight`(등불)
- 켜졌다 꺼지는 부분(불꽃, 포탈 면, 발광 문양)은 크기 0으로 숨기는 방식. Blockbench에서 애니메이션 없이 열면 모두 켜진 모습.
- 조각 제단처럼 단계가 쌓이는 장치는 애니메이션 여러 개를 동시에 재생해야 한다 (ModelEngine 레이어).

## 배치 주의

- 승강 석주(idle 땅속), 시간차 문(창살이 바닥으로 내려감), 거울 감옥(문이 바닥으로 내려감)은 바닥 블록 위에 놓아야 가려진다.
- 히트박스는 정사각 바닥이라 천칭·게이트처럼 큰 장치는 가운데만 덮는다.
- 히트박스는 모델 안에 숨김(`visibility:false`) 그룹으로 들어 있다.
- 기믹 미몹 id는 `GM_` 로 시작하게 하면 마법 피해 대상에서 자동 제외된다 (`magic-mythic-paper` config `excluded-mythic-prefixes`).
